# AppAgent

**エージェントで ServiceNow アプリを構築・保守。Chrome 拡張機能として。**

AppAgent は ServiceNow 開発のパートナーです。アプリの作成と保守、そしてそのテストの実行ができます。テストはフォームへの入力やスクリーンショットの撮影によって行います。技術的な知識は必要ありません。

必要なのは自分の API キー (BYOK) だけです！ OpenAI、OpenRouter、Claude API、さらには Claude Code のプランにも対応しています (個別にお問い合わせください)。

チャットはすべてブラウザー内に保存される Chrome 拡張機能です (ブラウザーの外に出ることさえありません)。やり取りするのは ServiceNow インスタンスとモデルの API プロバイダーだけです。

![AppAgent の例](AppAgentExample.png)

API キャッシュ、ツールのキャッシュ、ツールチェーンを標準で積極的に活用するため、Claude Code よりも少ないトークンで動作します。

スキルを追加でき、タブを通じたブラウザー操作ができ、インスタンスに加えたすべての変更に対して確実に元に戻せる「元に戻す」ボタンがあります。

> **注:** 現時点では、AppAgent は開発用インスタンスでのみ使用することを想定しています。

## 機能

| 機能 | できること |
|---------|--------------|
| **好きなモデルを使える** | Claude、GPT、Gemini、Grok などから選べます |
| **Claude でサインイン** | OAuth フロー — 既存の Claude Code Personal または Enterprise プランを使えます。API キーは不要です |
| **画像と PDF** | スクリーンショット、図、ドキュメントを添付してエージェントに分析させられます |
| **コード編集** | 完全なバージョン追跡のもとでスクリプトを読み取り、変更します |
| **ブラウザー操作** | 自分の作業を自分でテスト: タブの移動、クリック、フォーム入力、スクリーンショット撮影 |
| **ライブダッシュボード** | インスタンスからリアルタイムのデータを取得するウィジェットを作成します |
| **エージェントスキル** | 独自のスキルを作成して、エージェントの能力を拡張できます |
| **スキルアクション** | スキルはホームページに、定型のワークフローを開始するワンクリックボタンを表示できます |
| **ライブ進捗** | エージェントの作業をリアルタイムで確認 — 実行中/停滞/完了/エラーの状態が切り替わる進捗ピル |
| **ワークスペース** | チャットごとのファイル作業領域 — GitHub リポジトリのクローン、読み取り、書き込み、編集、差分表示、ブランチの切り替え。1 つのチャットで複数リポジトリに対応し、チャット間の所有権保護も備えています |
| **Git と GitHub へのプッシュを統合** | エージェントはチャットから直接 GitHub との pull / push、ブランチの作成、プルリクエストの作成ができます — ターミナルも IDE も不要です |
| **スマートドキュメント** | エージェントが編集でき、チャットをまたいで参照できる、永続的でバージョン管理された Markdown |
| **マルチインスタンス** | ブラウザーで開いているすべての ServiceNow インスタンスを自動検出し、エージェントは 1 つのチャットからそのすべてを確認・操作できます |
| **サブエージェント** | 重い作業や並列作業をバックグラウンドのワーカーエージェントに任せ、結果をメインのチャットに報告させます |
| **25 言語** | インターフェースとヘルプを英語に加えて 24 言語で提供。右から左に書くアラビア語とヘブライ語にも対応しています |
| **一時停止と中断** | ストリーミング中に一時停止したり新しいメッセージを送ったりすると、進行中の呼び出しがすぐに中止されます |
| **Web 検索** | Google と DuckDuckGo による無料・キー不要の Web 検索 |
| **確実な「元に戻す」** | すべての変更を追跡し、ワンクリックでロールバック |
| **XML へのエクスポート** | すべての変更をエクスポートして、他のインスタンスにデプロイできます |
| **ツールの権限** | 組み込みのセキュリティで、エージェントがインスタンスでできることを制御します |
| **オープンな標準** | [OpenRouter](https://openrouter.ai) と [AgentSkills.io](https://agentskills.io) に対応 |
| **モデルのキャッシュ** | プロンプトキャッシュでコストを最大 10 分の 1 に削減します |
| **スマートコンテキスト** | 大きなファイルは必要な部分だけを読み込み、モデルに負荷をかけすぎません |
| **依存関係ゼロ** | ライブラリもフレームワークも使わない、純粋なバニラ JS |

## 仕組み

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent は、エージェントループを内蔵した Chrome 拡張機能です。やりたいことを伝える → エージェントがモデルに問い合わせる → ブラウザー内でツールを実行する → 現在のユーザー権限で ServiceNow にアクセスする、という流れです。エージェントはオンプレミスでもオンラインでも、モデルの API プロバイダーと直接通信します。

## セットアップ

1. **インストール** — Chrome ウェブストアから AppAgent 拡張機能をインストールします (開発用にはパッケージ化されていない拡張機能として読み込みます)
2. **API キーを取得** — [OpenRouter](https://openrouter.ai) に登録するか、Anthropic/OpenAI を直接使うか、Claude Code のサブスクリプション (Enterprise または Personal) を接続します
3. **設定** — 拡張機能を開き、設定 → API プロバイダー で API キーを追加します (または Claude でサインインします)
4. **構築を開始** — ServiceNow インスタンスをタブで開き (自動的に検出されます)、チャットを始めます

## 使用例

### 「チームのタスクを管理するシンプルなアプリを作って」
AppAgent はテーブルを作成し、フィールドを追加し、フォームとリストのレイアウトを作り、ナビゲーターにモジュールを設定します。1 つのプロンプトで、アプリが完成します。

### 「このインスタンスを全面的に監査して」
AppAgent はセキュリティ上の問題、使われていない管理者アカウント、古いレコード、構成のベストプラクティスをスキャンし、推奨事項を含むレポートを提出します。

### 「このページをテストして、見つかった問題を報告して」
AppAgent はブラウザータブでページを開き、フォームに入力し、ボタンをクリックし、スクリーンショットを撮り、見つかったことをすべてレポートにまとめます。

### 「このフォームにバグがあるんだけど、直せる？」
AppAgent はフォームを開き、その背後にあるスクリプトを調べ、バグを特定し、コードを修正して、何が変わったかを正確に示します。必要ならワンクリックで元に戻せます。

### 「未解決チケットのダッシュボードウィジェットを作って」
AppAgent はインスタンスからリアルタイムのデータを取得するライブウィジェットを作成し、ダッシュボードに表示します。

### 「この Excel ファイルをユーザーテーブルにインポートして」
AppAgent はファイルを読み取り、列をフィールドに対応付けて、データをインスタンスにインポートします。

### 「アップグレード履歴を確認して、カスタマイズの問題を直して」
AppAgent はアップグレードで何が変わったかを確認し、壊れたカスタマイズを見つけて修正します。

### 「P1 インシデントが作成されたらチームに通知して」
AppAgent は P1 インシデントで起動し、チームにアラートを送る通知ルールを作成します。
