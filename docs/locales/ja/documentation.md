# はじめに {#getting-started}

AppAgent は、Chrome 拡張機能として動作する ServiceNow 向けの AI エージェントです。やりたいことを普段の言葉で伝えるだけで、エージェントがデータの照会、レコードの編集、アプリやウィジェットの作成、ブラウザーでのページのテストを行い、結果を報告します。

:::tip
**クイックスタート:** モデルを設定し、ServiceNow インスタンスのタブを開いてから、チャットにリクエストを入力して <kbd>Enter</kbd> を押します。
:::

## モデルを設定する {#guide-setup}

1. [設定](app:openSettingsPageView)を開き、**API プロバイダー**に移動します
2. API キーを使ってプロバイダー (Anthropic、OpenRouter、またはカスタムの OpenAI 互換 API) を追加します。Anthropic プロバイダーで **OAuth** を有効にすると、Claude アカウントでサインインすることもできます
3. **エージェントモデル**で使用するモデルを選びます

API キーはブラウザー内にのみ保存されます。AI の呼び出しはブラウザーからプロバイダーへ直接送信されます。

## インスタンスを接続する {#guide-instances}

AppAgent は、同じ Chrome プロファイルで開いている **ServiceNow インスタンスをすべて自動検出** します。接続文字列を入力する必要はありません。通常のタブでインスタンスにログインすれば、エージェントはあなたのユーザーのロールとアクセス権でそのインスタンスを操作できます。*「インスタンスを一覧表示して」* と頼むと、検出されたすべてのインスタンス、あなたのロール、接続状態を確認できます。

各インスタンスには **権限レベル** があり、インスタンスのドロップダウンから選択します:

- **手動** — 書き込み操作 (作成、更新、削除、フォーム入力) を 1 件ずつ承認します
- **自動** — 書き込み操作をエージェントが確認なしで判断します
- **開発** — 承認は一切不要です。このインスタンスでのツール呼び出しはすべて確認なしで実行されます。開発用インスタンスでのみ使用してください

読み取りは常に許可されています。より細かく制御するには [ツールの権限](#feature-permissions) を参照してください。

## チャットを始める {#guide-chat}

1. サイドバーの **新しいチャット** をクリックします [新しいチャットを開始 →](app:startNewChat)
2. リクエストを入力します。例: *「今日作成されたインシデントをすべて表示して」*
3. <kbd>Enter</kbd> を押して送信します
4. エージェントの作業を見守ります。各ツール呼び出しがチャットに表示され、承認が必要なステップでは確認画面が表示されます

エージェントの作業中も入力を続けられます。新しいメッセージを送信すると現在のステップが中断され、**一時停止** で実行を止められます。

## 画像やファイルを添付する {#guide-images}

1. 入力エリアの **ファイルを添付** ボタンをクリックして、画像、PDF、CSV、テキストファイルを追加します
2. クリップボードから画像を貼り付けたり、チャットにドラッグ＆ドロップしたりすることもできます
3. 添付ファイルについて質問を入力します

:::tip
エラーのスクリーンショット、UI のモックアップ、エクスポートしたデータを添付すると、エージェントはあなたが見ているものをそのまま確認できます。
:::

# 主な機能 {#features}

## チャット {#page-chat}

メインの会話画面です。[新しいチャットを開始 →](app:startNewChat)

- **メッセージエリア** — ツール呼び出しとその結果を含む会話
- **入力ボックス** — メッセージの入力やファイルの添付を行います。エージェントの作業中に送信すると作業を中断できます
- **一時停止 / 続行 / 再試行** — エージェントを止める、再開する、または最後のステップをやり直します
- **コンテキストインジケーター** — 会話がどれだけ埋まっているかを示します。クリックすると要約して新しいチャットに移れます
- **回答カード** — 回答の下に **要点** の要約と **リンク** カード (レコード、PR、ドキュメント) が表示されることがあります
- **チャットヘッダー** — チャットの名前変更やピン留めを行うほか、**ページ全体に展開** で AppAgent をブラウザーのタブ全体に開けます

## ブラウザー操作 {#feature-browser}

エージェントはインスタンス上のブラウザータブを開いて操作し、ページを確認・テストできます:

- **移動、クリック、入力、選択** — 実際の操作に近いイベントを使うため、フォームやオートコンプリート項目は手入力したときと同じように動作します
- **待機** — 遅延を推測する代わりに、要素、テキスト、URL が現れるのを待ちます
- **スクリーンショット** — ページ、ウィジェット、または個々の要素をキャプチャーして見た目を確認します
- **調査** — 要素のプロパティ、スタイル、コンソールエラー、ネットワークリクエストを読み取ります
- **代理ログイン** — 別のユーザーとしてテストし、その後元に戻ります

## レコードの編集とバージョン履歴 {#feature-history}

エージェントがインスタンスに加えた変更はすべて、チャットのサイドバーで追跡されます:

- **元に戻す** — 個々の変更を取り消します
- **やり直す** — 取り消した変更を復元します
- **XML をダウンロード** — すべての変更をエクスポートします。別のインスタンスへの移行などに使えます

## サブエージェント {#feature-subagents}

重い作業や並列作業では、エージェントは **サブエージェント** を起動できます。サブエージェントは独自のチャットとコンテキストで動くバックグラウンドのワーカーで、短い結果をメインのチャットに報告します。

- **モデル階層** — 各サブエージェントは **small**、**medium**、**large** のいずれかの階層で動作します。**same** を選ぶと親と同じモデルを使います。階層とモデルの対応は [設定](app:openSettingsPageView) → **サブエージェントのモデル階層** で設定します
- **ワーカーバー** — 実行中のサブエージェントはチャット入力欄の上にライブのチップとして表示されます。開くと進行状況を確認したり、やり取りの記録を読んだりできます
- **プール** — 同時に実行できるサブエージェントの数には上限があり、それを超えたものはキューで待機します

## ダッシュボードとウィジェット {#page-dashboard}

エージェントが生成したインタラクティブなウィジェットを並べるダッシュボードです。[ダッシュボードを開く →](app:openDashboardView)

1. **ウィジェットを追加** をクリックします
2. 作りたいものを説明します。例: *「未解決のインシデントを優先度別に示すグラフ」*
3. エージェントがウィジェットを作成します。いつでも変更を依頼したり、**再生成** をクリックしたりできます

ウィジェットはインスタンスからライブデータを取得できるため、常に最新の状態に保たれます。ドラッグ、サイズ変更、インポート、エクスポートが可能です ([高度な機能](#advanced) を参照)。エージェントがチャット内に表示したウィジェットは **ダッシュボードにピン留め** で保存できます。

## スマートドキュメント {#page-documents}

**スマートドキュメント** は、エージェントが作成・更新する、永続的でバージョン管理された Markdown ドキュメントです (計画、レポート、仕様、調査結果など)。チャット内にそのまま表示され、すべてのバージョンが保持され、あなたが直接編集することもできます。サイドバーの **ドキュメント** から開けます。[ドキュメントを開く →](app:openDocumentsView)

## スキル {#page-skills}

スキルは、エージェントに追加の知識とツールを与えます。[スキルを開く →](app:openSkillsView)

- **有効化 / 無効化** — スキルをオンまたはオフにします。不要なスキルを無効にすると、回答の焦点が絞られます
- **新しいスキル** — Markdown で独自のスキルを書くか、**エージェントで編集** を使います
- **インポート / エクスポート** — スキルをフォルダーとして共有します
- **スキルアクション** — ホームページに、定型のワークフローを開始するワンクリックボタンを追加するスキルもあります

スキルは **知識** (手順、ベストプラクティス) と **カスタムツール** (分離されたサンドボックスで実行される JavaScript 関数) を提供できます。

## ワークスペースと GitHub {#feature-workspace}

各チャットには **ワークスペース** があります。エージェントがファイルの読み取り、書き込み、編集、差分表示を行えるファイル領域です。

- **GitHub** — [設定](app:openSettingsPageView) で GitHub アカウントを接続すると、リポジトリをワークスペースにクローンできます。エージェントはチャットからブランチを作成し、コミットをプッシュし、プルリクエストを作成できます
- **プルリクエスト** — チャットから作成した PR はチャットのサイドバーに **マージ** ボタン付きで一覧表示されます
- **チャット間の保護** — 各ファイルはどのチャットが変更したかを記録するため、並行して作業する 2 つのチャットが互いの作業を気づかないうちに上書きすることはありません
- **自動同期** — クローンしたワークスペースは、ページを移動したとき、チャットを切り替えたとき、またはタブに戻ったときに GitHub と同期されます

## チャットサイドバー {#feature-sidebar}

右側のサイドバーには、現在のチャットで生成されたものがすべてまとめられます:

- **プルリクエスト** — タイトル、対象ブランチ、**マージ** ボタン
- **ワークスペースのファイル** — ファイルを開いて表示したり、差分を確認したり、以前のバージョンを参照したりできます
- **バージョン履歴** — インスタンスへの変更と **元に戻す**、**やり直す**、**XML をダウンロード**
- **ワーカー** — 実行中および完了したサブエージェント。ツール呼び出し数、編集したファイル数、作成した PR 数のカウンター付き

## アクションとライブ進捗 {#feature-actions}

時間のかかるタスクでも、黙り込まずに進捗をライブで表示します:

- **進捗カード** — 色分けされた状態 (実行中、停滞、完了、エラー) とステップの一覧を持つ 1 枚のカード
- **アクションボタン** — 後続のワークフローを開始するワンクリックボタン
- **実行中インジケーター** — エージェントが作業中のチャットがチャット一覧で示されます
- **「エージェントが完了しました」通知** — 実行中に別のタブやウィンドウに切り替えても、エージェントの作業が終わるとデスクトップ通知でお知らせします

## アクティブなチャットとジョブ {#feature-jobs}

ヘッダーのジョブピルを開くと、チャットとバックグラウンド作業をライブで確認できます:

- **実行中のチャット** — 実行中のチャットと未読の結果があるチャット (**太字** で表示)。それぞれにコンテキスト使用量のリングが付きます
- **サブエージェント** — 親チャットの下に一覧表示されます。開くとやり取りの記録を読めます
- **展開** — 一覧をより大きなパネルとして、列またはセクションのレイアウトで開きます

## ツールの権限 {#feature-permissions}

インスタンスごとの権限レベル (**手動**、**自動**、**開発**) に加えて、各ツールには [設定](app:openSettingsPageView) → **ツールの権限** で個別の設定があります:

- **許可** — ツールは常に確認なしで実行されます
- **自動** — ツールは確認なしで実行されます。ただし、エージェントが確認が必要と判断した呼び出しは除きます
- **確認** — 呼び出しのたびに承認を求められます
- **オフ** — エージェントはそのツールを使用できません

一部のツールにはさらに細かい設定があります。ServiceNow API は HTTP メソッド (GET、POST、PUT、PATCH、DELETE) ごと、ブラウザー操作はアクション (移動、クリック、入力、代理ログインなど) ごと、スキル管理はアクションごとに設定できます。確認ダイアログはリスクに応じて色分けされます: **青** (通常)、**オレンジ** (注意)、**赤** (破壊的)。

:::tip
DELETE などの破壊的な操作は **確認** のままにし、**開発** は開発用インスタンスでのみ使用してください。
:::

## エージェントのツール {#feature-tools}

エージェントが使用する主なツール:

| ツール | 機能 |
|------|--------------|
| **ServiceNow API** (`servicenow_api`) | レコードの読み取り、作成、更新、削除 |
| **バックグラウンドスクリプト** (`servicenow_run_script`) | インスタンスでサーバー側スクリプトを実行 (admin ロールが必要) |
| **スクリプト編集** (`servicenow_diff_edit`) | 正確な検索と置換でスクリプトを変更 |
| **ブラウザー操作** (`iframe_tool`) | ブラウザータブでの移動、クリック、入力、調査、代理ログイン |
| **ブラウザーコード** (`js_eval`) | 他のツールを呼び出せる分離サンドボックスで JavaScript を実行 |
| **スクリーンショット** (`take_screenshot`) | ページ、ウィジェット、要素をキャプチャー |
| **ウィジェットとカード** (`html_widget`, `display`) | インタラクティブなウィジェット、表、カード、タイムラインをチャットに表示 |
| **スマートドキュメント** (`document`) | 永続的な Markdown ドキュメントを作成・更新 |
| **ユーザーへの質問** (`prompt_user`) | インラインフォームで入力を求める |
| **サブエージェント** (`spawn_sub_agent`) | バックグラウンドのワーカーに作業を委任 |
| **ワークスペース** (`workspace`) | ファイルと GitHub リポジトリを操作 |
| **Web 取得** (`web_fetch`) | 公開 Web のページを読み取る |
| **スキル** (`get_skill`, `manage_skill`) | スキルの読み取りと管理 |

[設定](app:openSettingsPageView) → **ツールの権限** を開くと、すべてのツールとその提供元、権限を確認できます。

## 大きなコンテンツのキャッシュ {#feature-caching}

ツールの結果が会話に対して大きすぎる場合 (既定では 4K トークン超)、AppAgent はそれをキャッシュします。エージェントは概要を受け取り、必要な部分だけを読み取り、検索、参照します。これによりチャットが高速で焦点の定まった状態に保たれます。しきい値 (1K～100K トークン) は [設定](app:openSettingsPageView) → **大きなコンテンツのキャッシュ** で変更できます。

## コンテキストインジケーター {#feature-saturation}

チャット入力欄の横にある **コンテキストインジケーター** は、会話がどれだけ埋まっているかを示します。50% を超えるとエージェントは作業をまとめ、残りの重い作業をサブエージェントに任せるよう求められます。100% に達すると停止して報告します。インジケーターをクリックすると、いつでも会話を要約して新しいチャットに移れます。

## 使用量とレート制限 {#feature-usage}

- **使用量ピル** — ヘッダーに API の使用量と残りの上限が表示されます。クリックすると詳細を確認できます
- **自動再試行** — プロバイダーがレート制限中または過負荷 (HTTP 429 / 529) の場合、AppAgent は待機して自動的に再試行し、チャットにカウントダウンを表示します
- **クレジット切れ** — 429 が実際にはクレジットの枯渇を意味する場合、チャットにその旨がはっきり表示されます

## 言語 {#feature-languages}

インターフェースは英語に加えて 24 言語で利用できます: アラビア語、中国語 (簡体字、繁体字)、チェコ語、デンマーク語、オランダ語、フィンランド語、フランス語 (フランス、カナダ)、ドイツ語、ヘブライ語、ハンガリー語、イタリア語、日本語、韓国語、ノルウェー語、ポーランド語、ポルトガル語 (ブラジル、ポルトガル)、ロシア語、スペイン語、スウェーデン語、タイ語、トルコ語。

[設定](app:openSettingsPageView) → **言語**、またはヘッダーのクイック設定メニューから選択します。**自動** はブラウザーの言語に従い、対応していない場合は英語になります。変更は再読み込みなしですぐに反映されます。

- **右から左** — アラビア語とヘブライ語は右から左のレイアウトになります
- **地域の形式** — 日付、時刻、数値は選択した言語の形式に従います
- **エージェントの返答** — 別の言語で書かない限り、エージェントは選択した言語で返答します。コード、表名、フィールド名はそのまま残ります
- **このヘルプページ** — 選択した言語で表示されます。変更履歴は英語のままです

# ページと設定 {#pages}

## 設定 {#page-settings}

[設定を開く →](app:openSettingsPageView)

- **エージェントモデル** — エージェントが使用するモデル
- **API プロバイダー** — Anthropic、OpenRouter、またはカスタムのプロバイダー (API キーまたは OAuth)
- **LLM エンドポイント** — OpenAI 互換 API 用に名前を付けた `URL + API key` の組み合わせ
- **サブエージェントのモデル階層** — small、medium、large の各階層をモデル、または **同じ** に割り当てます
- **推論の労力、最大トークン数、思考予算** — 回答の深さと長さを調整します
- **コンテキストウィンドウ** — コンテキストインジケーターが使用するコンテキストのサイズ
- **表示** — API 統計、コンパクト表示、画面をスリープさせない設定
- **言語** — インターフェースの言語、または **自動**
- **フック** — チャットタイトルの自動生成、「エージェントが完了しました」通知などの自動化
- **大きなコンテンツのキャッシュ** — 大きな結果をキャッシュする条件
- **ツールの権限** — 自動実行、事前確認、無効化するものを設定します
- **GitHub** — GitHub アカウントを接続し、クローンしたリポジトリを管理します
- **システムプロンプト** — エージェントへの指示をカスタマイズします
- **データ管理** — データのエクスポート、インポート、削除

## 履歴 {#page-history}

すべての会話です。[履歴を開く →](app:openHistoryView)

- **検索** — タイトル、内容、使用したツール、ウィジェットでチャットを検索します
- **ピン留め** — 重要なチャットを先頭に固定します
- **エクスポート** — 1 つのチャットまたは履歴全体をダウンロードします
- **統計** — チャット数、ピン留めしたチャット数、合計コスト

## ヘルプ {#page-docs}

このページです。[ヘルプを開く →](app:openDocsView)

- **検索** — ツールバーの検索ボックスでヘルプのトピックを絞り込みます
- **目次** — 目次からセクションに移動します
- **ダウンロード** — ドキュメントを Markdown ファイルとして保存します

# ヒントとキーボードショートカット {#tips}

| 操作 | 方法 |
|--------|-----|
| メッセージを送信 | <kbd>Enter</kbd> |
| 改行 | <kbd>Shift</kbd> + <kbd>Enter</kbd> |
| チャットを検索 | <kbd>Ctrl</kbd> + <kbd>K</kbd> (Mac では <kbd>⌘</kbd> + <kbd>K</kbd>) |
| ダイアログやメニューを閉じる | <kbd>Esc</kbd> |
| 戻る | <kbd>Alt</kbd> + <kbd>←</kbd> |
| 画像を添付 | 貼り付けるか、チャットにドラッグ＆ドロップします |
| 要約して新しく始める | コンテキストインジケーターをクリックします |
| エージェントを中断 | 新しいメッセージを送信するか、**一時停止** をクリックします |

:::tip
**具体的に伝えましょう。** *「これを直して」* ではなく、*「MyUtils スクリプトインクルードの 42 行目の null 参照エラーを修正して」* のように伝えます。可能であれば、テーブル、レコード、ページの名前を挙げてください。
:::

- **1 つのチャットに 1 つの目的** — 関係のないタスクには新しいチャットを始めると、エージェントはより速く正確に動作します
- **テストを任せる** — ページを開いてスクリーンショットで自分の変更を確認するよう、エージェントに依頼しましょう
- **スキルを活用する** — 始める前に、タスクに合ったスキル (テストや監査など) を有効にしておきます

# トラブルシューティングとよくある質問 {#faq}

### エージェントにインスタンスが表示されない

同じ Chrome プロファイルのタブでインスタンスを開いてログインしていることを確認し、*「インスタンスを一覧表示して」* と頼んでください。それでも表示されない場合は、インスタンスのタブを再読み込みしてください。

### API エラーまたは認証エラーが発生する

[設定](app:openSettingsPageView) → **API プロバイダー** でプロバイダーを確認してください: API キー、選択したエンドポイント、モデル名。OAuth の場合は、同じ Chrome プロファイルで claude.ai に再度サインインしてください。

### エージェントがレート制限中と表示される

AppAgent は自動的に再試行し、カウントダウンを表示します。何度も発生する場合は、使用量ピルで残りのクレジットを確認するか、サブエージェントに小さいモデル階層を使ってください。

### 承認の確認が多すぎる、または少なすぎる

インスタンスのドロップダウンからインスタンスの権限レベル (**手動**、**自動**、**開発**) を変更し、[設定](app:openSettingsPageView) → **ツールの権限** で個々のツールを調整してください。

### 長いチャットで回答が遅くなったり不正確になったりする

会話のコンテキストが埋まりつつあります。コンテキストインジケーターをクリックして、要約付きの新しいチャットで続けてください。

### 変更を元に戻すには？

チャットのサイドバーを開き、バージョン履歴で対象の変更の **元に戻す** をクリックします。**XML をダウンロード** ですべての変更をエクスポートできます。

### データはどこに保存されますか？

ブラウザー内 (IndexedDB) にローカル保存されます。チャットが AppAgent のサーバーに送られることはなく、送信先は AI プロバイダーと ServiceNow インスタンスだけです。[データの保存](#adv-data-storage) を参照してください。

### インターフェースやこのページの言語が違う

[設定](app:openSettingsPageView) → **言語** で言語を選択してください。**自動** はブラウザーの言語に従います。

## ウィジェットのサイズ変更と移動 {#adv-resize-move}

**ウィジェットのサイズ変更:**

- 各ウィジェットの右下隅に **サイズ変更ハンドル** があります
- ハンドルをクリックしてドラッグすると、ウィジェットのサイズを変更できます
- 幅は 12 列のグリッドに合わせて調整されます (最小 3 列)
- 高さは 50px 単位で指定されます (最小 2 単位 = 100px)

**ウィジェットの移動:**

- **ヘッダー** の切り替えをオンにしてウィジェットヘッダーを表示します
- **ウィジェットのアイコン** (ドラッグハンドル) をクリックしてドラッグし、並べ替えます
- 別のウィジェットの上にドロップすると、位置が入れ替わります
- ウィジェットの順序は自動的に保存されます

## インポート/エクスポートの形式 {#adv-import-export}

**ダッシュボードのエクスポート** (`dashboard-YYYY-MM-DD.json`):

```
{
  "type": "appagent-dashboard",
  "version": 1,
  "widgets": [
    {
      "id": "widget_123",
      "title": "Widget Title",
      "html": "<html>...</html>",
      "width": 6,
      "height": 8,
      "order": 0,
      "conversation": [...]
    }
  ]
}
```

**単一ウィジェットのエクスポート:**

```
{
  "type": "appagent-dashboard-widget",
  "version": 1,
  "widget": { ... }
}
```

**単一チャットのエクスポート** (`chat-title-YYYY-MM-DD.json`):

```
{
  "exportType": "single_chat",
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chat": {
    "id": "chat_123",
    "title": "Chat Title",
    "messages": [
      {
        "role": "user",
        "content": "User message text"
      },
      {
        "role": "assistant",
        "content": "Agent response text"
      }
    ],
    "createdAt": 1705312200000
  }
}
```

チャットのエクスポートには、ユーザーのメッセージとエージェントの返答をすべて含む会話履歴全体が保存されます。個々のチャットをエクスポートするには、チャットのドロップダウンメニュー (···) から **ダウンロード** を選択します。

**スキルのエクスポート** (フォルダー構成):

```
skill-name/
├── SKILL.md      # Main skill definition
├── sample.xml    # Optional XML assets
├── helper.js     # Optional JS assets
└── notes.md      # Optional MD assets
```

:::tip
**注:** スキルのインポート/エクスポートは File System Access API を使用するため、**Chrome または Edge ブラウザーでのみ動作します**。
:::

**全データのエクスポート** (`appagent-backup-YYYY-MM-DD.json`):

```
{
  "version": 3,
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chats": [...],
  "settings": [...],
  "dashboardWidgets": [...],
  "apiProviders": [...]
}
```

完全バックアップには、すべてのチャット履歴、設定、ツールの権限、ダッシュボードのウィジェット、API プロバイダーの構成が含まれます。

## API 統計 {#adv-api-stats}

設定で有効にすると、エージェントの各返答の後に API 統計が表示されます:

| 指標 | 説明 |
|--------|-------------|
| **In** | 入力トークン — エージェントに送信したプロンプトのサイズ |
| **Out** | 出力トークン — エージェントの返答のサイズ |
| **Total** | 入力と出力のトークンの合計 |
| **Cache Read/Write** | プロンプトキャッシュから読み取った、または書き込んだトークン (コストを削減) |
| **Reasoning** | 内部の推論に使われたトークン (一部のモデル) |
| **Cost** | API 呼び出しの推定コスト (USD) |
| **Duration** | API 呼び出しにかかった時間 |

複数ターンの会話では、集計統計にすべての呼び出しの合計が表示されます。

:::tip
API 統計の表示は [設定](app:openSettingsPageView) → 表示 → API 統計を表示 で切り替えられます。
:::

**スキルを手動で作成する:**

2. スキルの名前と説明を入力します
3. スキルの内容を Markdown 形式で書きます
4. **保存** をクリックしてスキルを作成します

**SKILL.md の形式:**

```

Description of what this skill does.

Detailed instructions for the Agent...

```

**エージェントで編集する:**

1. 任意のスキルで **エージェントで編集** をクリックします
2. どのような変更をしたいかを説明します
3. エージェントがスキルの内容を変更します
4. 変更を確認して保存します

**スキルのアセット:** スキルには、エージェントに追加のコンテキストやコードを提供するファイル (XML、JS、MD) を含めることができます。

## システムプロンプト {#adv-system-prompt}

システムプロンプトは、エージェントの動作と機能を定義します。[設定](app:openSettingsPageView) でカスタマイズできます。

**システムプロンプトを編集する:**

1. 設定 → システムプロンプトのセクションに移動します
2. **編集** をクリックして編集モードに切り替えます
3. 必要に応じてテンプレートを変更します
4. **保存** をクリックして変更を適用します

**使用可能なプレースホルダー:**

| プレースホルダー | 説明 |
|-------------|-------------|
| `{{CURRENT_DATE}}` | 今日の日付 (曜日、月、日、年) |
| `{{ORCHESTRATOR_POLICY}}` | サブエージェントへの委任ポリシー — メインのチャットでは含まれ、サブエージェントのチャットでは空になります |
| `{{DISABLED_TOOLS}}` | 無効化されたツールの一覧 |

| `{{SKILLS_SUMMARY}}` | 有効なスキルの内容 |

プレースホルダーは、AI に送信するときに実際の値へ自動的に置き換えられます。トークン数の表示には、テンプレートのサイズと展開後のサイズの両方が示されます。

## エージェントの API 呼び出し {#adv-agent-api}

AppAgent は **Chrome 拡張機能** として動作します:

- AI API の呼び出しは **ブラウザーから AI プロバイダー (Anthropic、OpenRouter など) へ直接** 送信されます
- インスタンスや AppAgent のサーバーを経由することは **ありません**
- API キー (または OAuth トークン) はブラウザー内にローカル保存されます
- 会話データは処理のために AI プロバイダーへ送信されます

**仕組み:**

1. チャットにメッセージを入力します
2. AppAgent がシステム指示、ツール、会話履歴を含むプロンプトを組み立てます
3. プロンプトが AI プロバイダーの API に送信されます
4. エージェントの返答がブラウザーにストリーミングで返されます
5. ツール呼び出しはブラウザー内で実行され、API 呼び出しにはインスタンスのセッションが使われます

:::tip
**プライバシー:** API キーと会話データはクライアント側で処理されます。インスタンスとやり取りするツール呼び出しには、既存のセッションの認証情報が使われます。
:::

## LLM エンドポイント {#adv-endpoints}

モデルは **名前付きの LLM エンドポイント** (再利用できる `URL + API key` の組み合わせ) を通じて接続します。これにより、AppAgent を **任意の OpenAI 互換の chat-completions API** に向けることができます: OpenRouter、ローカルゲートウェイ、プロキシ、または自分でホストしているモデルなど。

1. [設定 → LLM エンドポイント](app:openSettingsPageView) で **エンドポイントを追加** をクリックします
2. 名前、API の URL、API キーを入力します
3. 各モデル (API プロバイダー) はエンドポイントを 1 つ選びます。キーを 1 回更新するだけで、そのエンドポイントを使うすべてのモデルが更新されます

:::tip
Claude の **OAuth** プロバイダーはエンドポイントを使いません。`api.anthropic.com` と直接通信します。
:::

## Claude でサインイン (OAuth) {#adv-oauth}

API キーを貼り付ける代わりに、既存の claude.ai のセッションを使って Anthropic プロバイダーにサインインできます:

1. [設定 → API プロバイダー](app:openSettingsPageView) で Anthropic プロバイダーを追加または編集し、**OAuth** を有効にします
2. 拡張機能は同じ Chrome プロファイルの claude.ai のサインインを使って、Anthropic に直接接続します
3. 追加のサインインウィンドウは不要で、間に AppAgent のサーバーも入りません

**要件:**

- 同じ Chrome プロファイルで `claude.ai` にサインインしている必要があります
- シングルサインオン (SSO) アカウントでも利用できます

:::tip
OAuth トークンは自動的に更新されます。サインインに失敗した場合は、同じプロファイルで `claude.ai` を開いて再度サインインしてください。
:::

## セキュリティに関する考慮事項 {#adv-security}

**API キーの保存:**

- **API キーはブラウザーの IndexedDB にローカル保存** されます
- キーがインスタンスや AI プロバイダー以外のサーバーに送信されることはありません
- ブラウザーのデータを消去すると、保存された API キーも削除されます

**セッションと権限:**

- エージェントは **現在のユーザーセッション** で動作し、あなたのアクセス権とロールを引き継ぎます
- インスタンスへの API 呼び出しにはすべて、あなたのセッションの認証情報が使われます
- エージェントがアクセスできるのは、あなたのユーザーアカウントがアクセスできる範囲だけです

**ツールの実行環境:**

- **ブラウザーコード (js_eval)** は、`executeTool()` にのみアクセスできる **分離されたサンドボックス** で JavaScript を実行します
- **ウィジェットのスクリプト** は **分離された iframe** で実行され、API 呼び出しには `executeTool()` のみを使えます
- **スキルのツール** は、`executeTool()` にのみアクセスできる **分離されたサンドボックス** で実行されます
- API へのアクセスはすべて `executeTool("servicenow_api", {...})` を介して **権限システム** を通ります
- エージェントは ServiceNow インスタンスの **ブラウザータブ** でページを操作します

**レコードを変更できる機能:**

- **ServiceNow API** ツールは、レコードを変更できる POST、PATCH、PUT、DELETE メソッドに対応しています
- 入力ツールとクリックツールの権限が与えられていれば、エージェントは **統合ブラウザー** を通じてレコードを作成・編集できます
- 承認が必要な操作は [ツールの権限](app:openSettingsPageView) で設定します

**自己改善:**

- エージェントは **自分のスキルを管理** できます (スキルの作成、編集、有効化)
- これにより、エージェントは時間とともに学習し、自己改善できます
- スキルの変更を定期的に確認し、期待どおりであることを確かめてください

## データの保存 {#adv-data-storage}

AppAgent は **IndexedDB** を使ってブラウザー内にデータをローカル保存します:

| データの種類 | 保存先 | 説明 |
|-----------|---------|-------------|
| **チャット** | IndexedDB | すべての会話履歴、メッセージ、ツールの結果 |
| **設定** | IndexedDB | ツールの権限、API キー、モデルの設定 |
| **ダッシュボードのウィジェット** | IndexedDB | ウィジェットの HTML、タイトル、サイズ、会話履歴 |
| **スキル** | IndexedDB | スキルの定義、内容、アセット |
| **API プロバイダー** | IndexedDB | カスタム API プロバイダーの構成とエンドポイント |
| **UI の状態** | localStorage | サイドバーの状態、現在の画面、スクロール位置 |

**データをダウンロードする:**

1. [設定](app:openSettingsPageView) → データ管理 に移動します
2. **データをエクスポート** をクリックします
3. JSON のバックアップファイルがダウンロードされます

**データを削除する:**

1. [設定](app:openSettingsPageView) → データ管理 に移動します
2. **すべてのデータを削除** をクリックします
3. 2 回確認すると、すべてが完全に削除されます

:::tip
**重要:** データは拡張機能内にローカル保存されます。ブラウザーのデータを消去したり、拡張機能をアンインストールしたり、別のブラウザープロファイルを使用したりすると、データは別々に保存されます。
:::
