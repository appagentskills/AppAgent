# AppAgent

**에이전트로 ServiceNow 앱을 만들고 유지 관리하세요. Chrome 확장 프로그램으로.**

AppAgent는 ServiceNow 개발 파트너입니다. 앱을 만들고 유지 관리하며 테스트까지 실행합니다. 테스트는 양식을 입력하고 스크린샷을 찍는 방식으로 진행합니다. 기술 지식이 없어도 됩니다.

API 키만 직접 준비하면(BYOK) 끝입니다! OpenAI, OpenRouter, Claude API는 물론 Claude Code 요금제와도 호환됩니다(별도로 문의해 주세요).

모든 채팅을 브라우저에 저장하는 Chrome 확장 프로그램이며, 데이터가 브라우저 밖으로 나가지 않습니다. ServiceNow 인스턴스 및 모델 API 공급자와만 통신합니다.

![AppAgent 예시](AppAgentExample.png)

API 캐시, 도구 캐싱, 도구 체이닝을 적극 활용하므로(기본 제공) Claude Code보다 토큰을 적게 사용합니다.

스킬을 추가할 수 있고, 탭을 통해 브라우저를 제어하며, 인스턴스에 적용한 모든 변경 사항에 대해 기계적인 실행 취소 버튼을 제공합니다.

> **참고:** 현재 AppAgent는 개발 인스턴스에서만 사용하도록 설계되었습니다.

## 기능

| 기능 | 설명 |
|---------|--------------|
| **원하는 모델 사용** | Claude, GPT, Gemini, Grok 등에서 선택 |
| **Claude로 로그인** | OAuth 흐름 — 기존 Claude Code Personal 또는 Enterprise 요금제를 사용하며 API 키가 필요 없습니다 |
| **이미지 및 PDF** | 스크린샷, 다이어그램 또는 문서를 첨부해 에이전트가 분석하도록 합니다 |
| **코드 편집** | 전체 버전 추적과 함께 스크립트를 읽고 수정합니다 |
| **브라우저 제어** | 자신의 작업을 직접 테스트합니다: 탭 이동, 클릭, 양식 입력, 스크린샷 촬영 |
| **실시간 대시보드** | 인스턴스에서 실시간 데이터를 가져오는 위젯을 만듭니다 |
| **에이전트 스킬** | 나만의 스킬을 만들어 에이전트의 기능을 확장합니다 |
| **스킬 작업** | 스킬이 홈 페이지에 미리 정의된 워크플로를 실행하는 원클릭 버튼을 표시할 수 있습니다 |
| **실시간 진행 상황** | 에이전트가 무엇을 하는지 실시간으로 확인 — 실행 중/막힘/완료/오류 상태로 바뀌는 진행 필 |
| **워크스페이스** | 채팅별 파일 작업 공간 — GitHub 리포지토리 복제, 읽기, 쓰기, 편집, 차이 비교, 브랜치 전환. 채팅당 여러 리포지토리를 지원하며 채팅 간 소유권 보호 기능이 있습니다 |
| **통합 Git 및 GitHub 푸시** | 에이전트가 채팅에서 바로 GitHub에서 풀하거나 GitHub로 푸시하고, 브랜치를 만들고, 풀 리퀘스트를 엽니다 — 터미널도 IDE도 필요 없습니다 |
| **스마트 문서** | 에이전트가 여러 채팅에서 편집하고 참조할 수 있는 영구적인 버전 관리 Markdown |
| **멀티 인스턴스** | 브라우저에 열린 모든 ServiceNow 인스턴스를 자동으로 감지하며, 에이전트가 하나의 채팅에서 모든 인스턴스를 확인하고 작업할 수 있습니다 |
| **하위 에이전트** | 무거운 작업이나 병렬 작업을 백그라운드 작업자 에이전트에 위임하고, 결과를 기본 채팅에 보고받습니다 |
| **25개 언어** | 오른쪽에서 왼쪽으로 쓰는 아랍어와 히브리어를 포함해 영어와 24개 언어로 인터페이스와 도움말 제공 |
| **일시 중지 및 중단** | 스트리밍 도중 일시 중지하거나 새 메시지를 보내면 진행 중인 호출이 즉시 중단됩니다 |
| **웹 검색** | Google과 DuckDuckGo를 통한 무료, 키 없는 웹 검색 |
| **기계적인 실행 취소** | 모든 변경 사항을 추적하며 클릭 한 번으로 롤백 |
| **XML로 내보내기** | 다른 인스턴스에 배포할 수 있도록 모든 변경 사항 내보내기 |
| **도구 권한** | 내장된 보안 기능으로 에이전트가 인스턴스에서 할 수 있는 작업을 제어합니다 |
| **개방형 표준** | [OpenRouter](https://openrouter.ai) 및 [AgentSkills.io](https://agentskills.io)와 호환 |
| **모델 캐싱** | 프롬프트 캐싱으로 비용을 최대 10배 절감 |
| **스마트 컨텍스트** | 대용량 파일에서 필요한 부분만 불러와 모델에 과부하를 주지 않습니다 |
| **의존성 없음** | 라이브러리도 프레임워크도 없는 순수 바닐라 JS |

## 작동 방식

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent는 에이전트 루프가 내장된 Chrome 확장 프로그램입니다. 원하는 작업을 설명하면 → 에이전트가 모델에 묻고 → 브라우저에서 도구를 실행하고 → 현재 사용자 권한으로 ServiceNow에 접근합니다. 에이전트는 온프레미스든 온라인이든 모델 API 공급자와 직접 통신합니다.

## 설정

1. **설치** — Chrome 웹 스토어에서 AppAgent 확장 프로그램을 설치합니다(개발용으로는 압축 해제된 확장 프로그램 로드)
2. **API 키 받기** — [OpenRouter](https://openrouter.ai)에 가입하거나, Anthropic/OpenAI를 직접 사용하거나, Claude Code 구독(Enterprise 또는 Personal)을 연결합니다
3. **구성** — 확장 프로그램을 열고 설정 → API 공급자에서 API 키를 추가하거나 Claude로 로그인합니다
4. **만들기 시작** — 탭에서 ServiceNow 인스턴스를 열고(자동으로 감지됨) 채팅을 시작합니다

## 예시

### "팀 작업을 추적하는 간단한 앱을 만들어 줘"
AppAgent가 테이블을 만들고, 필드를 추가하고, 양식과 목록 레이아웃을 구성하고, 탐색기에 모듈을 설정합니다. 프롬프트 하나로 완성된 앱이 나옵니다.

### "이 인스턴스를 전체 감사해 줘"
AppAgent가 보안 취약점, 비활성 관리자 계정, 오래된 레코드, 구성 모범 사례를 점검한 뒤 권장 사항이 담긴 보고서를 제공합니다.

### "이 페이지를 테스트하고 발견한 문제를 보고해 줘"
AppAgent가 브라우저 탭에서 페이지를 열고, 양식을 입력하고, 버튼을 클릭하고, 스크린샷을 찍은 뒤 발견한 모든 내용을 보고서로 정리합니다.

### "이 양식에 버그가 있는데 고쳐 줄 수 있어?"
AppAgent가 양식을 열고, 그 뒤의 스크립트를 검사하고, 버그를 찾아 코드를 수정한 뒤 무엇이 바뀌었는지 정확히 보여 줍니다. 필요하면 클릭 한 번으로 되돌릴 수 있습니다.

### "내 미해결 티켓용 대시보드 위젯을 만들어 줘"
AppAgent가 인스턴스에서 실시간 데이터를 가져오는 라이브 위젯을 만들어 대시보드에 표시합니다.

### "이 Excel 파일을 사용자 테이블로 가져와 줘"
AppAgent가 파일을 읽고, 열을 필드에 매핑한 뒤 데이터를 인스턴스로 가져옵니다.

### "업그레이드 기록을 확인하고 사용자 지정 문제를 고쳐 줘"
AppAgent가 업그레이드로 바뀐 내용을 검토하고, 손상된 사용자 지정 항목을 찾아 수정합니다.

### "P1 인시던트가 생성되면 팀에 알려 줘"
AppAgent가 P1 인시던트에서 트리거되어 팀에 알림을 보내는 알림 규칙을 만듭니다.
