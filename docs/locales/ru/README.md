# AppAgent

**Создавайте и сопровождайте приложения ServiceNow с помощью агента. В виде расширения Chrome.**

AppAgent — ваш партнёр по разработке для ServiceNow. Он умеет создавать и сопровождать приложения, а также запускать для них тесты. Тестирует он сам: заполняет формы и делает снимки экрана. Технические знания не требуются.

Вы используете собственный API-ключ (BYOK) — и всё! Поддерживаются OpenAI, OpenRouter, Claude API и даже планы Claude Code (свяжитесь с нами в частном порядке).

Это расширение Chrome, которое хранит всю переписку в вашем браузере (она даже не покидает браузер). Оно взаимодействует только с вашим экземпляром ServiceNow и API-провайдером вашей модели.

![Пример AppAgent](AppAgentExample.png)

Он расходует меньше токенов, чем Claude Code, так как активно использует кэш API, кэширование инструментов и цепочки вызовов инструментов (из коробки).

К нему можно добавлять навыки, он управляет браузером через вкладки, а для всех изменений, которые он вносит в ваш экземпляр, есть механические кнопки отмены.

> **Примечание:** пока AppAgent предназначен для использования только на экземплярах для разработки.

## Возможности

| Возможность | Что делает |
|---------|--------------|
| **Своя модель** | Выбор из Claude, GPT, Gemini, Grok и других |
| **Вход через Claude** | Вход по OAuth — используйте имеющийся план Claude Code Personal или Enterprise, API-ключ не нужен |
| **Изображения и PDF** | Прикрепляйте снимки экрана, схемы или документы, чтобы агент их проанализировал |
| **Редактирование кода** | Читает и изменяет скрипты с полным отслеживанием версий |
| **Управление браузером** | Сам тестирует свою работу: переходит по вкладкам, нажимает кнопки, заполняет формы, делает снимки экрана |
| **Живые панели мониторинга** | Создаёт виджеты, получающие данные из вашего экземпляра в реальном времени |
| **Навыки агента** | Создавайте собственные навыки, чтобы расширить возможности агента |
| **Действия навыков** | Навыки могут добавлять на главную страницу кнопки, которые одним нажатием запускают готовые сценарии |
| **Ход выполнения в реальном времени** | Видно, что агент делает прямо сейчас, — живые метки прогресса с состояниями «выполняется», «застряло», «готово» и «ошибка» |
| **Рабочие области** | Файловое пространство для каждого чата — клонирование репозиториев GitHub, чтение, запись, редактирование, сравнение и переключение веток. Несколько репозиториев в одном чате и защита от конфликтов между чатами |
| **Встроенные Git и отправка в GitHub** | Агент может получать изменения из GitHub и отправлять их туда, создавать ветки и открывать pull requests прямо из чата — без терминала и IDE |
| **Умные документы** | Постоянные документы Markdown с историей версий, которые агент может редактировать и использовать в разных чатах |
| **Несколько экземпляров** | Автоматически обнаруживает все экземпляры ServiceNow, открытые в браузере; агент видит их все и может работать с ними из одного чата |
| **Субагенты** | Передаёт объёмную или параллельную работу фоновым агентам-исполнителям, которые отчитываются в основной чат |
| **25 языков** | Интерфейс и справка на английском и ещё 24 языках, включая арабский и иврит с письмом справа налево |
| **Пауза и прерывание** | Поставьте на паузу или отправьте новое сообщение во время ответа — текущий вызов сразу прерывается |
| **Веб-поиск** | Бесплатный поиск в интернете без ключей через Google и DuckDuckGo |
| **Механическая отмена** | Каждое изменение отслеживается и откатывается одним нажатием |
| **Экспорт в XML** | Экспорт всех изменений для развёртывания на других экземплярах |
| **Разрешения инструментов** | Встроенная безопасность: вы определяете, что агенту можно делать на экземпляре |
| **Открытые стандарты** | Совместимость с [OpenRouter](https://openrouter.ai) и [AgentSkills.io](https://agentskills.io) |
| **Кэширование модели** | Снижает стоимость до 10 раз благодаря кэшированию промптов |
| **Умный контекст** | Загружает только нужные части больших файлов и не перегружает модель |
| **Никаких зависимостей** | Без библиотек и фреймворков, только чистый JS |

## Как это работает

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent — это расширение Chrome со встроенным агентным циклом. Вы описываете, что вам нужно → агент обращается к модели → выполняет инструменты в браузере → работает с ServiceNow с правами вашего текущего пользователя. Агент напрямую взаимодействует с API-провайдерами моделей — локальными или облачными.

## Установка

1. **Установка** — установите расширение AppAgent из Chrome Web Store (или загрузите распакованное расширение для разработки)
2. **Получение API-ключа** — зарегистрируйтесь на [OpenRouter](https://openrouter.ai), используйте Anthropic/OpenAI напрямую или подключите подписку Claude Code (Enterprise или Personal)
3. **Настройка** — откройте расширение и добавьте API-ключ (или войдите через Claude) в разделе «Настройки» → «API-провайдеры»
4. **Начало работы** — откройте свой экземпляр ServiceNow во вкладке (он будет обнаружен автоматически) и начните общение

## Примеры

### «Создай простое приложение для учёта задач команды»
AppAgent создаст таблицу, добавит поля, настроит макеты формы и списка и добавит модуль в навигатор. Один промпт — готовое приложение.

### «Проведи полный аудит этого экземпляра»
AppAgent проверит экземпляр на пробелы в безопасности, неактивные учётные записи администраторов, устаревшие записи и соответствие конфигурации рекомендациям, а затем подготовит отчёт с рекомендациями.

### «Протестируй эту страницу и сообщи обо всех найденных проблемах»
AppAgent откроет страницу во вкладке браузера, заполнит формы, понажимает кнопки, сделает снимки экрана и составит отчёт обо всём, что обнаружил.

### «В этой форме ошибка, можешь исправить?»
AppAgent откроет форму, изучит связанные с ней скрипты, найдёт ошибку, исправит код и покажет, что именно изменилось. При необходимости всё отменяется одним нажатием.

### «Создай виджет панели мониторинга для моих открытых тикетов»
AppAgent создаст живой виджет, который получает данные из вашего экземпляра в реальном времени и показывает их на панели мониторинга.

### «Импортируй этот файл Excel в таблицу пользователей»
AppAgent прочитает файл, сопоставит столбцы с полями и импортирует данные в ваш экземпляр.

### «Проверь историю обновлений и исправь проблемы с настройками»
AppAgent изучит, что изменилось при обновлении, найдёт сломанные доработки и исправит их.

### «Уведомляй команду при создании инцидента P1»
AppAgent создаст правило уведомлений, которое срабатывает на инциденты P1 и отправляет оповещение вашей команде.
