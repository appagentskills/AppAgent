# AppAgent

**借助智能体构建和维护 ServiceNow 应用。以 Chrome 扩展的形式。**

AppAgent 是您在 ServiceNow 上的开发伙伴。它可以创建和维护应用，并为应用运行测试。它通过填写表单和截图来完成测试。无需任何技术知识。

您只需自带 API 密钥（BYOK），仅此而已！它兼容 OpenAI、OpenRouter、Claude API，甚至 Claude Code 套餐（请私下联系我们）。

它是一个 Chrome 扩展，所有聊天内容都存储在您的浏览器中（甚至不会离开您的浏览器）。它只与您的 ServiceNow 实例和您的模型 API 提供商交互。

![AppAgent 示例](AppAgentExample.png)

它比 Claude Code 消耗更少的 token，因为它大量利用了 API 缓存、工具缓存和工具链式调用（开箱即用）。

您可以为它添加技能，它可以通过标签页控制浏览器，并且它对您的实例所做的所有更改都有机械式撤销按钮。

> **注意：** 目前，AppAgent 仅适用于开发实例。

## 功能

| **使用 Claude 登录** | OAuth 流程——使用您现有的 Claude Code 个人版或企业版套餐，无需 API 密钥 |
| **图片和 PDF** | 附加截图、图表或文档，供智能体分析 |
| **代码编辑** | 读取和修改脚本，并完整跟踪版本 |
| **浏览器控制** | 测试自己的工作：切换标签页、点击、填写表单、截图 |
| **实时仪表板** | 创建从您的实例拉取实时数据的小组件 |
| **智能体技能** | 构建您自己的技能来扩展智能体的能力 |
| **技能操作** | 技能可以在主页上提供一键按钮，触发预设工作流 |
| **实时进度** | 实时查看智能体正在做什么——进度胶囊会随运行中/卡住/完成/出错等状态变化 |
| **工作区** | 每个聊天独立的文件草稿区——克隆 GitHub 仓库，读取、写入、编辑、比较差异并切换分支。每个聊天支持多个仓库，并提供跨聊天的归属保护 |
| **集成 Git 与 GitHub 推送** | 智能体可以直接在聊天中从 GitHub 拉取/推送到 GitHub、创建分支并打开拉取请求——无需终端，无需 IDE |
| **智能文档** | 持久化、带版本的 Markdown 文档，智能体可以跨聊天编辑和引用 |
| **多实例** | 自动检测浏览器中打开的每个 ServiceNow 实例；智能体可以在一个聊天中查看并操作所有实例 |
| **子代理** | 将繁重或并行的工作委派给后台工作代理，完成后向主聊天汇报 |
| **25 种语言** | 界面和帮助支持英语及另外 24 种语言，包括从右到左书写的阿拉伯语和希伯来语 |
| **暂停与中断** | 在流式输出过程中暂停或发送新消息——正在进行的调用会立即中止 |
| **网页搜索** | 通过 Google 和 DuckDuckGo 进行免费、无需密钥的网页查询 |
| **机械式撤销** | 跟踪每一项更改，一键回滚 |
| **导出为 XML** | 导出所有更改，以部署到其他实例 |
| **工具权限** | 内置安全机制，控制智能体在实例上可以执行的操作 |
| **开放标准** | 兼容 [OpenRouter](https://openrouter.ai) 和 [AgentSkills.io](https://agentskills.io) |
| **模型缓存** | 通过提示词缓存将成本降低多达 10 倍 |
| **智能上下文** | 只加载大文件中需要的部分，不会让模型过载 |
| **零依赖** | 不使用任何库或框架，纯原生 JS |

## 工作原理

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent 是一个内置智能体循环的 Chrome 扩展。您描述想要的结果 → 智能体询问模型 → 在浏览器中执行工具 → 以您当前的用户权限访问 ServiceNow。智能体直接与模型 API 提供商通信，无论是本地部署还是在线服务。

## 设置

1. **安装** — 从 Chrome 网上应用店安装 AppAgent 扩展（或在开发时以“加载已解压的扩展程序”方式加载）
2. **获取 API 密钥** — 在 [OpenRouter](https://openrouter.ai) 注册，直接使用 Anthropic/OpenAI，或连接您的 Claude Code 订阅（企业版或个人版）
3. **配置** — 打开扩展，在“设置 → API 提供商”中添加您的 API 密钥（或使用 Claude 登录）
4. **开始构建** — 在标签页中打开您的 ServiceNow 实例（会被自动检测），然后开始聊天

## 示例

### “帮我构建一个跟踪团队任务的简单应用”
AppAgent 会创建表、添加字段、构建表单和列表布局，并在导航栏中设置模块。一个提示词，一个完整的应用。

### “对这个实例进行全面审计”
AppAgent 会扫描安全漏洞、不活跃的管理员账户、过期记录以及配置最佳实践，然后为您提供一份附带建议的报告。

### “测试这个页面并报告发现的任何问题”
AppAgent 会在浏览器标签页中打开该页面，填写表单、点击按钮、截图，并汇总一份包含所有发现的报告。

### “这个表单有个 bug，你能修复吗？”
AppAgent 会打开该表单，检查其背后的脚本，找出 bug，修复代码，并准确展示更改了什么。如有需要，一键即可撤销。

### “为我的未结工单创建一个仪表板小组件”
AppAgent 会创建一个实时小组件，从您的实例拉取实时数据并显示在您的仪表板上。

### “把这个 Excel 文件导入用户表”
AppAgent 会读取文件，将列映射到字段，并把数据导入您的实例。

### “检查升级历史并修复自定义问题”
AppAgent 会审查升级中的变更，找出失效的自定义内容并修复它们。

### “创建 P1 事件时通知团队”
AppAgent 会创建一条通知规则，在出现 P1 事件时触发，并向您的团队发送提醒。
