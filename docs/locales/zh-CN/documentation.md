# 入门 {#getting-started}

AppAgent 是一款以 Chrome 扩展形式运行的 ServiceNow AI 智能体。用平实的语言描述您的需求，智能体就会查询数据、编辑记录、构建应用和小组件、在浏览器中测试页面，并向您汇报结果。

:::tip
**快速开始：** 设置好模型，在您的 ServiceNow 实例上打开一个标签页，然后在聊天中输入请求并按 <kbd>Enter</kbd>。
:::

## 设置模型 {#guide-setup}

1. 打开[设置](app:openSettingsPageView)，进入 **API 提供商**
2. 使用您的 API 密钥添加一个提供商（Anthropic、OpenRouter 或自定义的 OpenAI 兼容 API）——或在 Anthropic 提供商上启用 **OAuth**，用您的 Claude 账户登录
3. 在 **智能体模型** 下选择要使用的模型

您的 API 密钥仅存储在您的浏览器中。AI 调用直接从您的浏览器发送到提供商。

## 连接您的实例 {#guide-instances}

AppAgent 会**自动检测您在同一 Chrome 配置文件中打开的每个 ServiceNow 实例**——无需输入任何连接字符串。在普通标签页中登录实例后，智能体即可以您用户的角色和访问权限在该实例上工作。输入 *“list instances”*（列出实例）即可查看所有已检测到的实例、您的角色和连接状态。

每个实例都有一个**权限级别**，可在实例下拉菜单中选择：

- **手动** — 每项写操作（创建、更新、删除、填写表单）都需要您批准
- **自动** — 由智能体自行决定写操作，无需询问
- **开发** — 完全无需批准：此实例上的每次工具调用都直接运行，不会询问。仅在开发实例上使用

读取操作始终允许。如需更精细的控制，请参阅[工具权限](#feature-permissions)。

## 开始聊天 {#guide-chat}

1. 点击侧边栏中的 **新建对话** [开始新对话 →](app:startNewChat)
2. 输入您的请求，例如 *“显示今天创建的所有事件”*
3. 按 <kbd>Enter</kbd> 发送
4. 跟随智能体的工作进度：每次工具调用都会显示在聊天中，当某个步骤需要您同意时会出现批准提示

智能体工作时您可以继续输入：发送新消息会中断当前步骤，**暂停** 则会停止运行。

## 附加图片和文件 {#guide-images}

1. 点击输入区域中的 **附加文件** 按钮，添加图片、PDF、CSV 或文本文件
2. 或者从剪贴板粘贴图片，或将其拖放到聊天中
3. 输入您关于该附件的问题

:::tip
附加错误截图、UI 原型或导出的数据，让智能体准确看到您所看到的内容。
:::

# 主要功能 {#features}

## 聊天 {#page-chat}

主对话视图。[开始新对话 →](app:startNewChat)

- **消息区域** — 对话内容，包括工具调用及其结果
- **输入框** — 输入消息；附加文件；在智能体工作时发送消息即可中断它
- **暂停 / 继续 / 重试** — 停止智能体、恢复运行，或重试上一步
- **上下文指示器** — 显示对话的占用程度；点击它可将对话总结到新聊天中
- **回答卡片** — 回答下方可能会出现 **要点** 摘要卡片和 **链接** 卡片（记录、PR、文档）
- **聊天标题栏** — 重命名或固定聊天，或通过 **展开为整页** 在完整的浏览器标签页中打开 AppAgent

## 浏览器控制 {#feature-browser}

智能体可以在您的实例上打开并控制浏览器标签页，以查看和测试页面：

- **导航、点击、填写和选择** — 触发真实事件，使表单和自动补全字段的行为与您亲手输入时一致
- **等待** — 等待某个元素、文本或 URL 出现，而不是猜测延迟时间
- **截图** — 截取整个页面、某个小组件或单个元素，用于视觉检查
- **检查** — 读取元素属性、样式、控制台错误和网络请求
- **模拟用户** — 以其他用户身份进行测试，然后切换回来

## 编辑记录与版本历史 {#feature-history}

智能体对您实例所做的每项更改都会在聊天侧边栏中被跟踪：

- **撤销** — 还原单项更改
- **重做** — 恢复已还原的更改
- **下载 XML** — 导出所有更改，例如用于迁移到其他实例

## 子代理 {#feature-subagents}

对于繁重或并行的工作，智能体可以启动**子代理**：它们是在各自的聊天和上下文中运行的后台工作代理，完成后会向主聊天汇报简短的结果。

- **模型层级** — 每个子代理运行在 **small**、**medium** 或 **large** 层级上，或使用 **same** 以沿用父代理的模型。可在[设置](app:openSettingsPageView) → **子代理模型层级** 中将层级映射到模型
- **工作代理栏** — 正在运行的子代理会以实时标签的形式显示在聊天输入框上方；打开其中一个即可查看其进度或阅读其对话记录
- **工作池** — 并发子代理的数量有上限；多出的子代理会在队列中等待

## 仪表板与小组件 {#page-dashboard}

由智能体生成的交互式小组件组成的仪表板。[打开仪表板 →](app:openDashboardView)

1. 点击 **添加小组件**
2. 描述您想要的内容，例如 *“一个按优先级显示未结事件的图表”*
3. 智能体会构建该小组件；您可以随时提出修改要求，或点击 **重新生成**

小组件可以从您的实例获取实时数据，因此始终保持最新。您可以拖动、调整大小、导入和导出小组件（请参阅[高级](#advanced)）。智能体在聊天中内联显示的小组件可以通过 **固定到仪表板** 保存。

## 智能文档 {#page-documents}

**智能文档** 是由智能体编写和更新的持久化、带版本的 Markdown 文档——计划、报告、规格说明、调查结果等。它们在聊天中内联呈现，保留每个版本，您也可以直接编辑。可从侧边栏的 **文档** 中打开它们。[打开文档 →](app:openDocumentsView)

## 技能 {#page-skills}

技能为智能体提供额外的知识和工具。[打开技能 →](app:openSkillsView)

- **激活 / 停用** — 开启或关闭技能；停用不需要的技能，让回答更加聚焦
- **新建技能** — 用 Markdown 编写您自己的技能，或使用 **使用智能体编辑**
- **导入 / 导出** — 以文件夹形式共享技能
- **技能操作** — 某些技能会在主页上添加一键按钮，用于启动预设工作流

技能可以提供**知识**（说明、最佳实践）和**自定义工具**（在隔离沙箱中运行的 JavaScript 函数）。

## 工作区与 GitHub {#feature-workspace}

每个聊天都有一个**工作区**——一个供智能体读取、写入、编辑和比较文件差异的文件区域。

- **GitHub** — 在[设置](app:openSettingsPageView)中连接 GitHub 账户，即可将仓库克隆到工作区。智能体可以在聊天中创建分支、推送提交并打开拉取请求
- **拉取请求** — 从聊天中打开的 PR 会列在聊天侧边栏中，并带有 **合并** 按钮
- **聊天之间的保护** — 每个文件都会记住是哪个聊天修改了它，因此两个并行工作的聊天不会在不知不觉中覆盖彼此的工作
- **自动同步** — 当您导航、切换聊天或返回标签页时，已克隆的工作区会与 GitHub 同步

## 聊天侧边栏 {#feature-sidebar}

右侧边栏汇集了当前聊天产生的所有内容：

- **拉取请求** — 标题、目标分支和 **合并** 按钮
- **工作区文件** — 打开文件即可查看其内容、差异或浏览早期版本
- **版本历史** — 实例更改，附带 **撤销**、**重做** 和 **下载 XML**
- **工作代理** — 正在运行和已完成的子代理，并显示工具调用、已编辑文件和已打开 PR 的计数

## 操作与实时进度 {#feature-actions}

长时间任务会显示实时进度，而不是毫无动静：

- **进度卡片** — 一张带有彩色状态（运行中、卡住、完成、出错）和步骤列表的卡片
- **操作按钮** — 用于启动后续工作流的一键按钮
- **运行指示器** — 聊天列表会标记智能体正在工作的聊天
- **“智能体已完成”通知** — 如果您在运行期间切换了标签页或窗口，桌面通知会在智能体完成时提醒您

## 活动聊天与任务 {#feature-jobs}

标题栏中的任务胶囊会打开一个实时视图，显示您的聊天和后台工作：

- **活动聊天** — 正在运行的聊天以及有未读结果的聊天（以**粗体**显示），每个聊天都带有上下文用量环
- **子代理** — 列在其父聊天下方；打开其中一个即可阅读其对话记录
- **展开** — 以更大的面板打开列表，可选择分栏或分区布局

## 工具权限 {#feature-permissions}

除了按实例设置的权限级别（**手动**、**自动**、**开发**）之外，每个工具在[设置](app:openSettingsPageView) → **工具权限** 中都有各自的设置：

- **允许** — 该工具始终直接运行，不会询问
- **自动** — 该工具直接运行，不会询问，除非智能体将某次调用标记为需要您确认
- **询问** — 每次调用前您都会收到批准提示
- **关闭** — 智能体无法使用该工具

某些工具有更精细的控制：ServiceNow API 可按 HTTP 方法（GET、POST、PUT、PATCH、DELETE）设置，浏览器控制可按操作（导航、点击、填写、模拟用户…）设置，技能管理也可按操作设置。确认对话框按风险用颜色区分：**蓝色**（常规）、**橙色**（注意）、**红色**（破坏性）。

:::tip
请将 DELETE 和其他破坏性操作保持为 **询问**，并且仅在开发实例上使用 **开发**。
:::

## 智能体工具 {#feature-tools}

智能体使用的主要工具：

| 工具 | 作用 |
|------|--------------|
| **ServiceNow API** (`servicenow_api`) | 读取、创建、更新和删除记录 |
| **后台脚本** (`servicenow_run_script`) | 在实例上运行服务器端脚本（需要 admin 角色） |
| **脚本编辑** (`servicenow_diff_edit`) | 通过精确的查找替换编辑来修改脚本 |
| **浏览器控制** (`iframe_tool`) | 在浏览器标签页中导航、点击、填写、检查和模拟用户 |
| **浏览器代码** (`js_eval`) | 在可调用其他工具的隔离沙箱中运行 JavaScript |
| **截图** (`take_screenshot`) | 截取页面、小组件或元素 |
| **小组件和卡片** (`html_widget`, `display`) | 在聊天中显示交互式小组件、表格、卡片和时间线 |
| **智能文档** (`document`) | 创建和更新持久化的 Markdown 文档 |
| **提示用户** (`prompt_user`) | 通过内联表单向您征求输入 |
| **子代理** (`spawn_sub_agent`) | 将工作委派给后台工作代理 |
| **工作区** (`workspace`) | 处理文件和 GitHub 仓库 |
| **网页获取** (`web_fetch`) | 读取公共网络上的页面 |
| **技能** (`get_skill`, `manage_skill`) | 读取和管理技能 |

打开[设置](app:openSettingsPageView) → **工具权限**，即可查看每个工具、其来源及其权限。

## 大内容缓存 {#feature-caching}

当工具结果对于对话来说过大时（默认超过 4K token），AppAgent 会将其缓存。智能体会收到一份大纲，然后只读取、搜索或浏览它需要的部分。这能让聊天保持快速和聚焦。可在[设置](app:openSettingsPageView) → **大内容缓存** 中更改阈值（1K 到 100K token）。

## 上下文指示器 {#feature-saturation}

聊天输入框旁的**上下文指示器**显示对话的占用程度。超过 50% 时，智能体会被要求收尾，并将剩余的繁重工作交给子代理；达到 100% 时，它会停止并汇报。您可以随时点击该指示器，将对话总结到一个新的聊天中。

## 用量与速率限制 {#feature-usage}

- **用量胶囊** — 标题栏显示您的 API 用量和剩余额度；点击可查看详情
- **自动重试** — 当提供商触发速率限制或过载时（HTTP 429 / 529），AppAgent 会自动等待并重试，并在聊天中显示倒计时
- **额度用尽** — 当 429 实际上表示您的额度已用完时，聊天中会明确说明

## 语言 {#feature-languages}

界面支持英语及另外 24 种语言：阿拉伯语、中文（简体、繁体）、捷克语、丹麦语、荷兰语、芬兰语、法语（法国、加拿大）、德语、希伯来语、匈牙利语、意大利语、日语、韩语、挪威语、波兰语、葡萄牙语（巴西、葡萄牙）、俄语、西班牙语、瑞典语、泰语和土耳其语。

可在[设置](app:openSettingsPageView) → **语言** 中选择，或通过标题栏中的快速设置菜单选择。**自动** 会跟随您浏览器的语言，并回退到英语。更改会立即生效，无需重新加载。

- **从右到左** — 阿拉伯语和希伯来语使用从右到左的布局
- **本地格式** — 日期、时间和数字遵循您所选语言的格式
- **智能体回复** — 除非您使用其他语言书写，否则智能体会用所选语言回复。代码、表名和字段名保持不变
- **本帮助页面** — 以您的语言显示；更新日志保持英文

# 故障排除与常见问题 {#faq}

### 智能体看不到我的实例

在同一 Chrome 配置文件的标签页中打开该实例并确保您已登录，然后输入 *“list instances”*（列出实例）。如果仍未出现，请重新加载该实例的标签页。

### 我遇到了 API 或身份验证错误

在[设置](app:openSettingsPageView) → **API 提供商** 中检查您的提供商：API 密钥、所选端点和模型名称。如果使用 OAuth，请在同一 Chrome 配置文件中重新登录 claude.ai。

### 智能体提示受到速率限制

AppAgent 会自动重试并显示倒计时。如果这种情况持续发生，请查看用量胶囊中的剩余额度，或为子代理使用更小的模型层级。

### 批准提示太多或太少

通过实例下拉菜单更改实例的权限级别（**手动**、**自动**、**开发**），并在[设置](app:openSettingsPageView) → **工具权限** 中调整各个工具。

### 在长聊天中，回答变慢或变得不够准确

对话的上下文正在被填满。点击上下文指示器，即可带着摘要在新的聊天中继续。

### 如何撤销更改？

打开聊天侧边栏，在版本历史中对该更改点击 **撤销**。**下载 XML** 可导出所有更改。

### 我的数据存储在哪里？

存储在您本地的浏览器中（IndexedDB）。聊天内容绝不会发送到 AppAgent 服务器——只会发送到您的 AI 提供商和您的 ServiceNow 实例。请参阅[数据存储](#adv-data-storage)。

### 界面或本页面的语言不对

在[设置](app:openSettingsPageView) → **语言** 中选择语言。**自动** 会跟随您浏览器的语言。

# 高级 {#advanced}

本节介绍高级功能、标题栏按钮、导入/导出格式，以及 AppAgent 工作原理的技术细节。

## 仪表板标题栏按钮 {#adv-dashboard-header}

仪表板标题栏包含多个操作按钮：

| 按钮 | 说明 |
|--------|-------------|

## 智能体 API 调用 {#adv-agent-api}

AppAgent 以 **Chrome 扩展** 的形式运行：

- AI API 调用**直接从您的浏览器发送到 AI 提供商**（例如 Anthropic、OpenRouter）
- 这些调用**不会**经过您的实例或任何 AppAgent 服务器
- 您的 API 密钥（或 OAuth 令牌）存储在您本地的浏览器中
- 对话数据会发送给 AI 提供商进行处理

**工作原理：**

1. 您在聊天中输入一条消息
2. AppAgent 使用系统指令、工具和对话历史构建提示词
3. 提示词被发送到 AI 提供商的 API
4. 智能体的回复以流式方式返回到您的浏览器
5. 工具调用在您的浏览器中执行，并使用您的实例会话进行 API 调用

:::tip
**隐私：** 您的 API 密钥和对话数据在客户端处理。与您的实例交互的工具调用会使用您现有的会话凭据。
:::

## LLM 端点 {#adv-endpoints}

模型通过**命名的 LLM 端点**进行连接——即可复用的 `URL + API key` 组合。这使您可以让 AppAgent 指向**任何 OpenAI 兼容的 chat-completions API**：OpenRouter、本地网关、代理，或您自己托管的模型。

1. 在[设置 → LLM 端点](app:openSettingsPageView)中，点击 **添加端点**
2. 为其设置名称、API URL 和 API 密钥
3. 每个模型（API 提供商）都会选择一个端点——只需更新一次密钥，所有使用该端点的模型都会随之更新

:::tip
Claude **OAuth** 提供商不使用端点——它们直接与 `api.anthropic.com` 通信。
:::

## 使用 Claude 登录（OAuth） {#adv-oauth}

您无需粘贴 API 密钥，而是可以使用现有的 claude.ai 会话登录 Anthropic 提供商：

1. 在[设置 → API 提供商](app:openSettingsPageView)中，添加或编辑一个 Anthropic 提供商并启用 **OAuth**
2. 扩展会使用您在同一 Chrome 配置文件中的 claude.ai 登录状态，直接连接到 Anthropic
3. 无需额外的登录窗口，中间也没有 AppAgent 服务器

**要求：**

- 您必须在同一 Chrome 配置文件中登录 `claude.ai`
- 支持单点登录（SSO）账户

:::tip
OAuth 令牌会自动刷新。如果登录失败，请在同一配置文件中打开 `claude.ai` 并重新登录。
:::

## 安全注意事项 {#adv-security}

**API 密钥存储：**

- 您的 **API 密钥存储在本地**浏览器的 IndexedDB 中
- 该密钥绝不会发送到您的实例或除 AI 提供商以外的任何服务器
- 清除浏览器数据会删除您已存储的 API 密钥

**会话与权限：**

- 智能体以您的**当前用户会话**运行，继承您的访问权限和角色
- 所有发往您实例的 API 调用都使用您的会话凭据
- 智能体只能访问您的用户账户有权访问的内容

**工具执行环境：**

- **浏览器代码（js_eval）** 在**隔离沙箱**中运行 JavaScript，只能访问 `executeTool()`
- **小组件脚本** 在**隔离的 iframe** 中运行，只能通过 `executeTool()` 进行 API 调用
- **技能工具** 在**隔离沙箱**中运行，只能访问 `executeTool()`
- 所有 API 访问都通过 `executeTool("servicenow_api", {...})` 经由**权限系统**
- 智能体在您 ServiceNow 实例的**浏览器标签页**中与页面交互

**记录修改能力：**

- **ServiceNow API** 工具支持可修改记录的 POST、PATCH、PUT 和 DELETE 方法
- 如果授予了填写和点击工具的权限，智能体可以通过**集成浏览器**创建和编辑记录
- 配置[工具权限](app:openSettingsPageView)，控制哪些操作需要批准

**自我改进：**

- 智能体可以**管理自己的技能**——创建、编辑和激活技能
- 这使智能体能够随着时间推移不断学习和自我改进
- 请定期检查技能的更改，确保它们符合您的预期

## 数据存储 {#adv-data-storage}

AppAgent 使用 **IndexedDB** 将数据存储在您本地的浏览器中：

| 数据类型 | 存储位置 | 说明 |
|-----------|---------|-------------|
| **聊天** | IndexedDB | 所有对话历史、消息和工具结果 |
| **设置** | IndexedDB | 工具权限、API 密钥、模型偏好 |
| **仪表板小组件** | IndexedDB | 小组件 HTML、标题、尺寸和对话历史 |
| **技能** | IndexedDB | 技能定义、内容和资源 |
| **API 提供商** | IndexedDB | 自定义 API 提供商配置和端点 |
| **界面状态** | localStorage | 侧边栏状态、当前视图、滚动位置 |

**下载您的数据：**

1. 前往[设置](app:openSettingsPageView) → 数据管理
2. 点击 **导出数据**
3. 系统将下载一个 JSON 备份文件

**删除您的数据：**

1. 前往[设置](app:openSettingsPageView) → 数据管理
2. 点击 **删除所有数据**
3. 确认两次即可永久删除所有内容

:::tip
**重要：** 数据存储在扩展本地。清除浏览器数据、卸载扩展或使用其他浏览器配置文件，都会导致数据存储彼此分离。
:::
