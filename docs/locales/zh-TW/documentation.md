# 開始使用 {#getting-started}

AppAgent 是一款以 Chrome 擴充功能形式執行的 ServiceNow AI 代理程式。只要用日常語言描述您的需求，代理程式就會查詢資料、編輯記錄、建置應用程式與小工具、在瀏覽器中測試頁面，並向您回報結果。

:::tip
**快速入門：** 先設定模型，在 ServiceNow 執行個體上開啟一個分頁，然後在對話中輸入需求並按下 <kbd>Enter</kbd>。
:::

## 設定模型 {#guide-setup}

1. 開啟[設定](app:openSettingsPageView)並前往 **API 提供者**
2. 使用您的 API 金鑰新增提供者（Anthropic、OpenRouter 或自訂的 OpenAI 相容 API），或在 Anthropic 提供者上啟用 **OAuth**，以您的 Claude 帳戶登入
3. 在 **代理程式模型** 中選擇要使用的模型

您的 API 金鑰只會儲存在瀏覽器中。AI 呼叫會直接從您的瀏覽器傳送到提供者。

## 連結您的執行個體 {#guide-instances}

AppAgent 會**自動偵測**您在同一個 Chrome 設定檔中開啟的**每一個 ServiceNow 執行個體**，不需要輸入任何連線字串。只要在一般分頁中登入執行個體，代理程式就能以您使用者的角色與存取權限在上面作業。輸入 *「列出執行個體」*，即可查看所有偵測到的執行個體、您的角色與連線狀態。

每個執行個體都有一個**權限等級**，可從執行個體下拉式選單中選擇：

- **手動** — 每一項寫入作業（建立、更新、刪除、填寫表單）都需要您核准
- **自動** — 由代理程式自行決定寫入作業，不會詢問您
- **開發** — 完全不需核准：此執行個體上的每個工具呼叫都會直接執行。請僅在開發用執行個體上使用

讀取作業一律允許。如需更細部的控制，請參閱[工具權限](#feature-permissions)。

## 開始對話 {#guide-chat}

1. 按一下側邊欄中的 **新對話** [開始新對話 →](app:startNewChat)
2. 輸入您的需求，例如 *「顯示今天建立的所有事件」*
3. 按下 <kbd>Enter</kbd> 傳送
4. 隨時掌握代理程式的作業進度：每個工具呼叫都會顯示在對話中，當某個步驟需要您同意時，會出現核准提示

代理程式作業期間您仍可繼續輸入：傳送新訊息會中斷目前的步驟，按下 **暫停** 則會停止執行。

## 附加圖片與檔案 {#guide-images}

1. 按一下輸入區域中的 **附加檔案** 按鈕，即可新增圖片、PDF、CSV 或文字檔
2. 也可以從剪貼簿貼上圖片，或將圖片拖放到對話中
3. 輸入與附件相關的問題

:::tip
附上錯誤畫面截圖、UI 模型圖或匯出的資料，讓代理程式看到與您完全相同的內容。
:::

# 主要功能 {#features}

## 對話 {#page-chat}

主要的對話畫面。[開始新對話 →](app:startNewChat)

- **訊息區域** — 顯示對話內容，包括工具呼叫及其結果
- **輸入方塊** — 輸入訊息、附加檔案；在代理程式作業時傳送訊息即可中斷它
- **暫停 / 繼續 / 重試** — 停止代理程式、繼續執行，或重試上一個步驟
- **內容指示器** — 顯示對話已使用多少內容空間；按一下即可將對話摘要到新對話中
- **回答卡片** — 回答下方可能會出現 **重點摘要** 卡片與 **連結** 卡片（記錄、PR、文件）
- **對話標題列** — 重新命名或釘選對話，或使用 **展開為完整頁面** 在完整的瀏覽器分頁中開啟 AppAgent

## 瀏覽器控制 {#feature-browser}

代理程式可以開啟並控制執行個體上的瀏覽器分頁，以檢視與測試頁面：

- **瀏覽、點擊、填寫與選取** — 模擬真實事件，讓表單與自動完成欄位的行為就像您親自輸入一樣
- **等待** — 等待某個元素、文字或 URL 出現，而不是猜測延遲時間
- **螢幕截圖** — 擷取整個頁面、某個小工具或單一元素，用於視覺檢查
- **檢查** — 讀取元素屬性、樣式、主控台錯誤與網路要求
- **模擬使用者** — 以其他使用者身分進行測試，再切換回來

## 編輯記錄與版本記錄 {#feature-history}

代理程式對執行個體所做的每一項變更，都會記錄在對話側邊欄中：

- **復原** — 還原個別變更
- **取消復原** — 重新套用已還原的變更
- **下載 XML** — 匯出所有變更，例如將其移轉到另一個執行個體

## 子代理程式 {#feature-subagents}

面對繁重或可平行處理的工作時，代理程式可以啟動**子代理程式**：這些背景工作者會在各自的對話與內容中執行，完成後將簡短結果回報給主要對話。

- **模型層級** — 每個子代理程式會以 **small**、**medium** 或 **large** 層級執行，或使用 **same** 沿用上層對話的模型。可在[設定](app:openSettingsPageView) → **子代理程式模型層級** 中將各層級對應到模型
- **工作者列** — 執行中的子代理程式會以即時標籤的形式顯示在對話輸入框上方；開啟任一個即可查看其進度或閱讀對話記錄
- **工作者集區** — 同時執行的子代理程式數量有上限；超出的會在佇列中等待

## 儀表板與小工具 {#page-dashboard}

由代理程式產生的互動式小工具儀表板。[開啟儀表板 →](app:openDashboardView)

1. 按一下 **新增小工具**
2. 描述您想要的內容，例如 *「依優先順序顯示未結事件的圖表」*
3. 代理程式會建置小工具；您可以隨時要求修改，或按一下 **重新產生**

小工具可以從執行個體擷取即時資料，因此內容會保持最新。您可以拖曳、調整大小、匯入及匯出小工具（請參閱[進階](#advanced)）。代理程式在對話中內嵌顯示的小工具，可以透過 **釘選至儀表板** 儲存。

## 智慧文件 {#page-documents}

**智慧文件** 是由代理程式撰寫與更新、可持久保存且具版本控制的 Markdown 文件，例如計畫、報告、規格與調查結果。這些文件會內嵌顯示在對話中、保留每一個版本，您也可以直接編輯。請從側邊欄的 **文件** 開啟。[開啟文件 →](app:openDocumentsView)

## 技能 {#page-skills}

技能可為代理程式提供額外的知識與工具。[開啟技能 →](app:openSkillsView)

- **啟用 / 停用** — 開啟或關閉技能；停用不需要的技能，可讓回答更聚焦
- **新技能** — 以 Markdown 撰寫您自己的技能，或使用 **使用代理程式編輯**
- **匯入 / 匯出** — 以資料夾形式分享技能
- **技能動作** — 部分技能會在首頁新增一鍵按鈕，用來啟動預設的工作流程

技能可以提供**知識**（指示、最佳做法）以及**自訂工具**（在隔離沙箱中執行的 JavaScript 函式）。

## 工作區與 GitHub {#feature-workspace}

每個對話都有一個**工作區**，也就是代理程式可以讀取、寫入、編輯及比對差異的檔案區域。

- **GitHub** — 在[設定](app:openSettingsPageView)中連結 GitHub 帳戶，即可將存放庫複製到工作區。代理程式可以直接在對話中建立分支、推送提交並開啟提取要求
- **提取要求** — 從對話開啟的 PR 會列在對話側邊欄中，並附有 **合併** 按鈕
- **對話之間的保護** — 每個檔案都會記住是哪個對話變更了它，因此兩個平行作業的對話不會在不知情的情況下覆寫彼此的成果
- **自動同步** — 當您瀏覽頁面、切換對話或返回分頁時，已複製的工作區會與 GitHub 同步

## 對話側邊欄 {#feature-sidebar}

右側的側邊欄會彙整目前對話所產生的一切：

- **提取要求** — 標題、目標分支與 **合併** 按鈕
- **工作區檔案** — 開啟檔案即可檢視內容、查看差異或瀏覽先前的版本
- **版本記錄** — 執行個體上的變更，附有 **復原**、**取消復原** 與 **下載 XML**
- **工作者** — 執行中與已完成的子代理程式，並顯示工具呼叫、已編輯檔案與已開啟 PR 的計數

## 動作與即時進度 {#feature-actions}

長時間的工作會顯示即時進度，而不會毫無動靜：

- **進度卡片** — 單一卡片，以顏色標示狀態（執行中、卡住、完成、錯誤）並列出步驟清單
- **動作按鈕** — 一鍵啟動後續工作流程的按鈕
- **執行中指示器** — 對話清單會標示代理程式正在作業的對話
- **「代理程式已完成」通知** — 若您在執行期間切換到其他分頁或視窗，桌面通知會在代理程式完成時提醒您

## 進行中的對話與工作 {#feature-jobs}

標題列中的工作標籤會開啟即時檢視，顯示您的對話與背景工作：

- **進行中的對話** — 執行中的對話與有未讀結果的對話（以**粗體**顯示），每個都附有內容使用量圓環
- **子代理程式** — 列在其上層對話下方；開啟任一個即可閱讀其對話記錄
- **展開** — 以較大的面板開啟清單，可選擇欄位或區段版面配置

## 工具權限 {#feature-permissions}

除了每個執行個體的權限等級（**手動**、**自動**、**開發**）之外，每個工具在[設定](app:openSettingsPageView) → **工具權限** 中也有各自的設定：

- **允許** — 工具一律直接執行，不會詢問
- **自動** — 工具會直接執行，除非代理程式將某個呼叫標示為需要您確認
- **詢問** — 每次呼叫前都會出現核准提示
- **關閉** — 代理程式無法使用此工具

部分工具提供更細部的控制：ServiceNow API 可依 HTTP 方法（GET、POST、PUT、PATCH、DELETE）設定，瀏覽器控制可依動作（瀏覽、點擊、填寫、模擬使用者…）設定，技能管理也可依動作設定。確認對話方塊會依風險以顏色區分：**藍色**（例行）、**橘色**（注意）、**紅色**（破壞性）。

:::tip
請將 DELETE 及其他破壞性作業保持在 **詢問**，並僅在開發用執行個體上使用 **開發**。
:::

## 代理程式工具 {#feature-tools}

代理程式使用的主要工具：

| 工具 | 功能 |
|------|--------------|
| **ServiceNow API** (`servicenow_api`) | 讀取、建立、更新及刪除記錄 |
| **背景指令碼** (`servicenow_run_script`) | 在執行個體上執行伺服器端指令碼（需要 admin 角色） |
| **指令碼編輯** (`servicenow_diff_edit`) | 以精確的搜尋與取代方式修改指令碼 |
| **瀏覽器控制** (`iframe_tool`) | 在瀏覽器分頁中瀏覽、點擊、填寫、檢查及模擬使用者 |
| **瀏覽器程式碼** (`js_eval`) | 在可呼叫其他工具的隔離沙箱中執行 JavaScript |
| **螢幕截圖** (`take_screenshot`) | 擷取頁面、小工具或元素 |
| **小工具與卡片** (`html_widget`, `display`) | 在對話中顯示互動式小工具、表格、卡片與時間軸 |
| **智慧文件** (`document`) | 建立及更新可持久保存的 Markdown 文件 |
| **詢問使用者** (`prompt_user`) | 透過內嵌表單向您索取輸入 |
| **子代理程式** (`spawn_sub_agent`) | 將工作委派給背景工作者 |
| **工作區** (`workspace`) | 處理檔案與 GitHub 存放庫 |
| **網頁擷取** (`web_fetch`) | 讀取公開網路上的頁面 |
| **技能** (`get_skill`, `manage_skill`) | 讀取及管理技能 |

開啟[設定](app:openSettingsPageView) → **工具權限**，即可查看每個工具、其來源與權限。

## 大型內容快取 {#feature-caching}

當工具結果太大而不適合放入對話時（預設超過 4K 個 token），AppAgent 會將其快取。代理程式會收到內容大綱，再只讀取、搜尋或瀏覽所需的部分。這能讓對話保持快速且聚焦。您可以在[設定](app:openSettingsPageView) → **大型內容快取** 中變更門檻值（1K 到 100K 個 token）。

## 內容指示器 {#feature-saturation}

對話輸入框旁的**內容指示器**會顯示對話已使用多少內容空間。超過 50% 時，系統會要求代理程式收尾，並將剩餘的繁重工作交給子代理程式；達到 100% 時，代理程式會停止並回報。您隨時可以按一下指示器，將對話摘要到新的對話中。

## 用量與速率限制 {#feature-usage}

- **用量標籤** — 標題列會顯示您的 API 用量與剩餘額度；按一下即可查看詳細資料
- **自動重試** — 當提供者遇到速率限制或過載（HTTP 429 / 529）時，AppAgent 會自動等待並重試，並在對話中顯示倒數計時
- **額度用盡** — 當 429 實際上代表您的額度已用完時，對話會清楚說明

## 語言 {#feature-languages}

介面提供英文及另外 24 種語言：阿拉伯文、中文（簡體、繁體）、捷克文、丹麥文、荷蘭文、芬蘭文、法文（法國、加拿大）、德文、希伯來文、匈牙利文、義大利文、日文、韓文、挪威文、波蘭文、葡萄牙文（巴西、葡萄牙）、俄文、西班牙文、瑞典文、泰文及土耳其文。

請在[設定](app:openSettingsPageView) → **語言** 中選擇，或從標題列的快速設定選單中選擇。**自動** 會依照您瀏覽器的語言，若不支援則改用英文。變更會立即生效，不需要重新載入。

- **由右至左** — 阿拉伯文與希伯來文採用由右至左的版面配置
- **在地格式** — 日期、時間與數字會依照您的語言顯示
- **代理程式回覆** — 除非您使用其他語言撰寫，否則代理程式會以所選語言回覆。程式碼、資料表與欄位名稱維持不變
- **本說明頁面** — 以您的語言顯示；變更記錄則維持英文

## 設定 {#page-settings}

- **工具權限** — 哪些會自動執行、需先詢問或已停用
- **GitHub** — 連結 GitHub 帳戶並管理已複製的存放庫
- **系統提示詞** — 自訂代理程式的指示

# 使用訣竅與鍵盤快速鍵 {#tips}

| 動作 | 方式 |
|--------|-----|
| 傳送訊息 | <kbd>Enter</kbd> |
| 換行 | <kbd>Shift</kbd> + <kbd>Enter</kbd> |
| 搜尋對話 | <kbd>Ctrl</kbd> + <kbd>K</kbd>（Mac 上為 <kbd>⌘</kbd> + <kbd>K</kbd>） |
| 關閉對話方塊或選單 | <kbd>Esc</kbd> |
| 返回 | <kbd>Alt</kbd> + <kbd>←</kbd> |
| 附加圖片 | 貼上圖片，或將其拖放到對話中 |
| 以摘要重新開始 | 按一下內容指示器 |
| 中斷代理程式 | 傳送新訊息，或按一下 **暫停** |

:::tip
**請具體說明。** 與其說 *「修正這個」*，不如說 *「修正 MyUtils script include 第 42 行的 null 參照錯誤」*。盡可能指明資料表、記錄或頁面。
:::

- **一個對話一個目標** — 處理不相關的工作時請開始新對話，代理程式會更快、更準確
- **讓它自行測試** — 請代理程式開啟頁面，並以螢幕截圖驗證它自己所做的變更
- **善用技能** — 開始之前，先啟用符合工作需求的技能（例如測試或稽核）

# 疑難排解與常見問題 {#faq}

### 代理程式看不到我的執行個體

請在同一個 Chrome 設定檔的分頁中開啟執行個體並確認已登入，然後輸入 *「列出執行個體」*。如果仍未出現，請重新載入執行個體的分頁。

### 我收到 API 或驗證錯誤

請在[設定](app:openSettingsPageView) → **API 提供者** 中檢查您的提供者：API 金鑰、所選端點與模型名稱。若使用 OAuth，請在同一個 Chrome 設定檔中重新登入 claude.ai。

### 代理程式表示遇到速率限制

AppAgent 會自動重試並顯示倒數計時。如果持續發生，請查看用量標籤中的剩餘額度，或為子代理程式改用較小的模型層級。

### 核准提示太多或太少

請從執行個體下拉式選單變更執行個體的權限等級（**手動**、**自動**、**開發**），並在[設定](app:openSettingsPageView) → **工具權限** 中調整個別工具。

### 在長時間的對話中，回答變慢或變得不準確

對話的內容空間即將用滿。按一下內容指示器，即可帶著摘要在新的對話中繼續。

### 如何復原變更？

開啟對話側邊欄，在版本記錄中找到該變更並按一下 **復原**。**下載 XML** 則可匯出所有變更。

### 我的資料儲存在哪裡？

儲存在您瀏覽器的本機中（IndexedDB）。對話絕不會傳送到 AppAgent 伺服器，只會傳送到您的 AI 提供者與 ServiceNow 執行個體。請參閱[資料儲存](#adv-data-storage)。

### 介面或本頁面顯示的語言不正確

請在[設定](app:openSettingsPageView) → **語言** 中選擇語言。**自動** 會依照您瀏覽器的語言。

## 調整小工具大小與移動小工具 {#adv-resize-move}

**調整小工具大小：**

- 每個小工具的右下角都有一個**大小調整控點**
- 按住並拖曳控點即可調整小工具大小
- 寬度會對齊 12 欄格線（最少 3 欄）
- 高度以 50px 為單位（最少 2 個單位 = 100px）

**移動小工具：**

- 開啟 **標題列** 切換以顯示小工具標題列
- 按住並拖曳**小工具圖示**（拖曳控點）即可重新排列
- 將小工具放到另一個小工具上即可交換位置
- 小工具的順序會自動儲存

## 匯入/匯出格式 {#adv-import-export}

**儀表板匯出**（`dashboard-YYYY-MM-DD.json`）：

```
{
  "type": "appagent-dashboard",
  "version": 1,
  "widgets": [
    {
      "id": "widget_123",
      "title": "Widget Title",
      "html": "<html>...</html>",
      "width": 6,
      "height": 8,
      "order": 0,
      "conversation": [...]
    }
  ]
}
```

**單一小工具匯出：**

```
{
  "type": "appagent-dashboard-widget",
  "version": 1,
  "widget": { ... }
}
```

**單一對話匯出**（`chat-title-YYYY-MM-DD.json`）：

```
{
  "exportType": "single_chat",
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chat": {
    "id": "chat_123",
    "title": "Chat Title",
    "messages": [
      {
        "role": "user",
        "content": "User message text"
      },
      {
        "role": "assistant",
        "content": "Agent response text"
      }
    ],
    "createdAt": 1705312200000
  }
}
```

對話匯出會保留完整的對話歷史記錄，包括所有使用者訊息與代理程式回應。若要匯出個別對話，請使用對話的下拉式選單（···）並選取 **下載**。

**技能匯出**（資料夾結構）：

```
skill-name/
├── SKILL.md      # Main skill definition
├── sample.xml    # Optional XML assets
├── helper.js     # Optional JS assets
└── notes.md      # Optional MD assets
```

:::tip
**注意：** 技能的匯入/匯出使用 File System Access API，**僅適用於 Chrome 或 Edge** 瀏覽器。
:::

**所有資料匯出**（`appagent-backup-YYYY-MM-DD.json`）：

```
{
  "version": 3,
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chats": [...],
  "settings": [...],
  "dashboardWidgets": [...],
  "apiProviders": [...]
}
```

完整備份包含所有對話歷史記錄、設定、工具權限、儀表板小工具與 API 提供者設定。

## API 統計資料 {#adv-api-stats}

在設定中啟用後，每次代理程式回應後都會顯示 API 統計資料：

| 指標 | 說明 |
|--------|-------------|
| **In** | 輸入 token — 傳送給代理程式的提示詞大小 |
| **Out** | 輸出 token — 代理程式回應的大小 |
| **Total** | 輸入 + 輸出 token 的總和 |
| **Cache Read/Write** | 從提示詞快取讀取或寫入的 token（可降低費用） |
| **Reasoning** | 用於內部推理的 token（部分模型） |
| **Cost** | API 呼叫的預估費用（美元） |
| **Duration** | API 呼叫所花費的時間 |

在多輪對話中，彙總統計資料會顯示所有呼叫的總計。

:::tip
可在[設定](app:openSettingsPageView) → 顯示 → 顯示 API 統計資料 中切換 API 統計資料的顯示。
:::

**使用代理程式編輯：**

2. 描述您想要的變更
3. 代理程式會修改技能內容
4. 檢閱並儲存變更

## 系統提示詞 {#adv-system-prompt}

系統提示詞定義了代理程式的行為與能力。您可以在[設定](app:openSettingsPageView)中自訂。

**編輯系統提示詞：**

1. 前往 設定 → 系統提示詞 區段
2. 按一下 **編輯** 切換到編輯模式
3. 視需要修改範本
4. 按一下 **儲存** 以套用變更

**可用的預留位置：**

| 預留位置 | 說明 |
|-------------|-------------|
| `{{CURRENT_DATE}}` | 今天的日期（星期、月、日、年） |
| `{{ORCHESTRATOR_POLICY}}` | 子代理程式委派原則 — 包含在主要對話中，在子代理程式對話中則留空 |
| `{{DISABLED_TOOLS}}` | 已停用工具的清單 |

| `{{SKILLS_SUMMARY}}` | 已啟用技能的內容 |

如有需要，按一下 **還原為預設值** 即可還原原始的系統提示詞。
:::

## 代理程式的 API 呼叫 {#adv-agent-api}

AppAgent 以 **Chrome 擴充功能** 的形式執行：

- AI API 呼叫會**直接從您的瀏覽器傳送到 AI 提供者**（例如 Anthropic、OpenRouter）
- 這些呼叫**不會**經過您的執行個體或任何 AppAgent 伺服器
- 您的 API 金鑰（或 OAuth 權杖）會儲存在瀏覽器本機中
- 對話資料會傳送給 AI 提供者進行處理

**運作方式：**

1. 您在對話中輸入訊息
2. AppAgent 會以系統指示、工具與對話歷史記錄組成提示詞
3. 提示詞會傳送到 AI 提供者的 API
4. 代理程式的回應會以串流方式傳回您的瀏覽器
5. 工具呼叫會在您的瀏覽器中執行，並使用您的執行個體工作階段進行 API 呼叫

:::tip
**隱私：** 您的 API 金鑰與對話資料都在用戶端處理。與執行個體互動的工具呼叫會使用您現有的工作階段認證。
:::

## LLM 端點 {#adv-endpoints}

模型透過**具名的 LLM 端點**連線，也就是可重複使用的 `URL + API key` 組合。這讓您可以將 AppAgent 指向**任何 OpenAI 相容的 chat-completions API**：OpenRouter、本機閘道、Proxy，或您自行託管的模型。

1. 在[設定 → LLM 端點](app:openSettingsPageView)中，按一下 **新增端點**
2. 為其命名，並填入 API URL 與 API 金鑰
3. 每個模型（API 提供者）都會選擇一個端點 — 只要更新一次金鑰，所有使用該端點的模型都會一併更新

:::tip
Claude **OAuth** 提供者不使用端點，而是直接與 `api.anthropic.com` 通訊。
:::

## 使用 Claude 登入（OAuth） {#adv-oauth}

您不必貼上 API 金鑰，而是可以使用現有的 claude.ai 工作階段登入 Anthropic 提供者：

1. 在[設定 → API 提供者](app:openSettingsPageView)中，新增或編輯 Anthropic 提供者並啟用 **OAuth**
2. 擴充功能會使用您在同一個 Chrome 設定檔中的 claude.ai 登入資訊，直接連線到 Anthropic
3. 不會出現額外的登入視窗，中間也沒有 AppAgent 伺服器

**需求：**

- 您必須在同一個 Chrome 設定檔中登入 `claude.ai`
- 支援單一登入（SSO）帳戶

:::tip
OAuth 權杖會自動重新整理。如果登入失敗，請在同一個設定檔中開啟 `claude.ai` 並重新登入。
:::

## 安全性考量 {#adv-security}

**API 金鑰儲存：**

- 您的 **API 金鑰儲存在本機**瀏覽器的 IndexedDB 中
- 金鑰絕不會傳送到您的執行個體，也不會傳送到 AI 提供者以外的任何伺服器
- 清除瀏覽器資料會移除您儲存的 API 金鑰

**工作階段與權限：**

- 代理程式會以您的**目前使用者工作階段**執行，並沿用您的存取權限與角色
- 所有對執行個體的 API 呼叫都會使用您的工作階段認證
- 代理程式只能存取您的使用者帳戶可存取的內容

**工具執行環境：**

- **瀏覽器程式碼（js_eval）** 會在**隔離沙箱**中執行 JavaScript，且只能存取 `executeTool()`
- **小工具指令碼** 會在**隔離的 iframe** 中執行，且只能透過 `executeTool()` 進行 API 呼叫
- **技能工具** 會在**隔離沙箱**中執行，且只能存取 `executeTool()`
- 所有 API 存取都會透過 `executeTool("servicenow_api", {...})` 經由**權限系統**處理
- 代理程式會在您 ServiceNow 執行個體上的**瀏覽器分頁**中與頁面互動

**修改記錄的能力：**

- **ServiceNow API** 工具支援可變更記錄的 POST、PATCH、PUT 與 DELETE 方法
- 若獲得填寫與點擊工具的權限，代理程式可以透過**整合式瀏覽器**建立及編輯記錄
- 設定[工具權限](app:openSettingsPageView)，即可控制哪些作業需要核准

**自我改進：**

- 代理程式可以**管理自己的技能**，包括建立、編輯及啟用技能
- 這讓代理程式能夠隨著時間學習並自我改進
- 請定期檢閱技能的變更，確保符合您的期望

## 資料儲存 {#adv-data-storage}

AppAgent 使用 **IndexedDB** 將資料儲存在您瀏覽器的本機中：

| 資料類型 | 儲存位置 | 說明 |
|-----------|---------|-------------|
| **對話** | IndexedDB | 所有對話歷史記錄、訊息與工具結果 |
| **設定** | IndexedDB | 工具權限、API 金鑰、模型偏好設定 |
| **儀表板小工具** | IndexedDB | 小工具的 HTML、標題、大小與對話歷史記錄 |
| **技能** | IndexedDB | 技能定義、內容與資產 |
| **API 提供者** | IndexedDB | 自訂 API 提供者的設定與端點 |
| **UI 狀態** | localStorage | 側邊欄狀態、目前檢視、捲動位置 |

**下載您的資料：**

1. 前往[設定](app:openSettingsPageView) → 資料管理
2. 按一下 **匯出資料**
3. 系統會下載一個 JSON 備份檔案

**刪除您的資料：**

1. 前往[設定](app:openSettingsPageView) → 資料管理
2. 按一下 **刪除所有資料**
3. 確認兩次即可永久刪除所有內容

:::tip
**重要：** 資料儲存在擴充功能的本機中。清除瀏覽器資料、解除安裝擴充功能，或使用不同的瀏覽器設定檔，都會產生各自獨立的資料儲存區。
:::
