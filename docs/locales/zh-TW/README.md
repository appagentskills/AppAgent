# AppAgent

**用代理程式建置與維護 ServiceNow 應用程式。以 Chrome 擴充功能的形式提供。**

AppAgent 是您在 ServiceNow 上的開發夥伴。它可以建立與維護應用程式，並為應用程式執行測試。它會透過填寫表單與擷取螢幕截圖來進行測試。完全不需要技術背景。

只要自備 API 金鑰（BYOK）就能開始使用！支援 OpenAI、OpenRouter、Claude API，甚至是 Claude Code 方案（請私下與我們聯絡）。

這是一款 Chrome 擴充功能，所有對話都儲存在您的瀏覽器中（甚至不會離開瀏覽器）。它只會與您的 ServiceNow 執行個體及模型 API 提供者互動。

![AppAgent 範例](AppAgentExample.png)

由於大量運用 API 快取、工具快取與工具串接（開箱即用），它使用的 token 比 Claude Code 更少。

您可以為它新增技能，它能透過分頁控制瀏覽器，而且針對它對執行個體所做的每一項變更，都提供機械式的復原按鈕。

> **注意：** 目前 AppAgent 僅供開發用執行個體使用。

| **代理程式技能** | 建置您自己的技能，擴充代理程式的能力 |
| **技能動作** | 技能可以在首頁提供一鍵按鈕，觸發預設的工作流程 |

| **匯出為 XML** | 匯出所有變更，以部署到其他執行個體 |
| **工具權限** | 內建安全機制，控制代理程式可以在執行個體上做什麼 |

## 運作方式

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent 是內建代理程式迴圈的 Chrome 擴充功能。您描述想要的結果 → 代理程式詢問模型 → 在瀏覽器中執行工具 → 以您目前的使用者權限存取 ServiceNow。代理程式會直接與模型 API 提供者通訊，無論是內部部署還是線上服務。

## 設定

1. **安裝** — 從 Chrome 線上應用程式商店安裝 AppAgent 擴充功能（或在開發時以「載入未封裝項目」方式載入）
2. **取得 API 金鑰** — 在 [OpenRouter](https://openrouter.ai) 註冊、直接使用 Anthropic/OpenAI，或連結您的 Claude Code 訂閱（企業版或個人版）
3. **進行設定** — 開啟擴充功能，並在 設定 → API 提供者 中新增 API 金鑰（或使用 Claude 登入）
4. **開始建置** — 在分頁中開啟您的 ServiceNow 執行個體（系統會自動偵測），然後開始對話

## 範例

### 「幫我建立一個追蹤團隊工作的簡單應用程式」
AppAgent 會建立資料表、新增欄位、建置表單與清單版面配置，並在導覽器中設定模組。一個提示詞，就能完成整個應用程式。

### 「對這個執行個體進行完整稽核」
AppAgent 會掃描安全漏洞、非使用中的管理員帳戶、過時的記錄以及設定上的最佳做法，然後提供附有建議的報告。

### 「測試這個頁面並回報你發現的任何問題」
AppAgent 會在瀏覽器分頁中開啟頁面、填寫表單、點擊按鈕、擷取螢幕截圖，並將所有發現彙整成報告。

### 「這個表單有錯誤，你可以修正嗎？」
AppAgent 會開啟表單、檢查其背後的指令碼、找出錯誤、修正程式碼，並清楚呈現變更了哪些內容。如有需要，一鍵即可復原。

### 「為我的未結工單建立儀表板小工具」
AppAgent 會建立一個即時小工具，從您的執行個體擷取即時資料並顯示在儀表板上。

### 「將這個 Excel 檔案匯入使用者資料表」
AppAgent 會讀取檔案、將欄對應到欄位，並將資料匯入您的執行個體。

### 「檢查升級記錄並修正自訂內容的問題」
AppAgent 會檢閱升級中變更的內容、找出損壞的自訂內容並加以修正。

### 「在建立 P1 事件時通知團隊」
AppAgent 會建立一個在 P1 事件發生時觸發的通知規則，並向您的團隊傳送警示。
