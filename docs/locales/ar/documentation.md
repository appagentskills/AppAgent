# البدء {#getting-started}

AppAgent هو وكيل ذكاء اصطناعي لـ ServiceNow يعمل كإضافة لمتصفح Chrome. صِف ما تحتاجه بلغة بسيطة، وسيتولى الوكيل الاستعلام عن البيانات وتحرير السجلات وبناء التطبيقات وعناصر الواجهة واختبار الصفحات في متصفحك، ثم يوافيك بالنتائج.

:::tip
**بدء سريع:** اضبط نموذجًا، وافتح علامة تبويب على مثيل ServiceNow الخاص بك، ثم اكتب طلبًا في المحادثة واضغط <kbd>Enter</kbd>.
:::

## إعداد نموذج {#guide-setup}

1. افتح [الإعدادات](app:openSettingsPageView) وانتقل إلى **موفرو API**
2. أضف موفرًا (Anthropic أو OpenRouter أو API مخصص متوافق مع OpenAI) باستخدام مفتاح API الخاص بك — أو فعّل **OAuth** على موفر Anthropic لتسجيل الدخول بحساب Claude الخاص بك
3. اختر النموذج الذي تريد استخدامه ضمن **نموذج الوكيل**

يُخزَّن مفتاح API الخاص بك في متصفحك فقط. تنتقل استدعاءات الذكاء الاصطناعي مباشرةً من متصفحك إلى الموفر.

## ربط مثيلاتك {#guide-instances}

**يكتشف AppAgent تلقائيًا كل مثيل ServiceNow** مفتوح لديك في ملف تعريف Chrome نفسه — لا توجد سلسلة اتصال لإدخالها. سجّل الدخول إلى مثيل في علامة تبويب عادية، وسيتمكن الوكيل من العمل عليه بأدوار المستخدم الخاص بك وصلاحيات الوصول الخاصة به. اطلب *"list instances"* (سرد المثيلات) لرؤية كل المثيلات المكتشفة وأدوارك وحالة الاتصال.

لكل مثيل **مستوى أذونات** يُختار من القائمة المنسدلة للمثيل:

- **يدوي** — توافق بنفسك على كل عملية كتابة (إنشاء، تحديث، حذف، تعبئة نماذج)
- **تلقائي** — يقرر الوكيل بشأن عمليات الكتابة دون أن يسألك
- **تطوير** — بلا موافقات إطلاقًا: يُنفَّذ كل استدعاء أداة على هذا المثيل دون سؤال. استخدمه على مثيلات التطوير فقط

عمليات القراءة مسموح بها دائمًا. راجع [أذونات الأدوات](#feature-permissions) لتحكم أدق.

## بدء محادثة {#guide-chat}

1. انقر على **محادثة جديدة** في الشريط الجانبي [بدء محادثة جديدة ←](app:startNewChat)
2. اكتب طلبك، على سبيل المثال *"اعرض لي كل الحوادث التي أُنشئت اليوم"*
3. اضغط <kbd>Enter</kbd> للإرسال
4. تابع عمل الوكيل: يظهر كل استدعاء أداة في المحادثة، وتظهر مطالبات الموافقة عندما تحتاج خطوة ما إلى موافقتك

يمكنك مواصلة الكتابة أثناء عمل الوكيل: إرسال رسالة جديدة يقاطع الخطوة الحالية، و**إيقاف مؤقت** يوقف التشغيل.

## إرفاق الصور والملفات {#guide-images}

1. انقر على زر **إرفاق ملف** في منطقة الإدخال لإضافة صورة أو ملف PDF أو CSV أو ملف نصي
2. أو الصق صورة من الحافظة، أو اسحبها وأفلتها في المحادثة
3. اكتب سؤالك حول المرفق

:::tip
أرفق لقطات شاشة للأخطاء أو نماذج أولية للواجهة أو بيانات مُصدَّرة حتى يرى الوكيل تمامًا ما تراه.
:::

# الميزات الرئيسية {#features}

## المحادثة {#page-chat}

عرض المحادثة الرئيسي. [بدء محادثة جديدة ←](app:startNewChat)

- **منطقة الرسائل** — المحادثة، بما فيها استدعاءات الأدوات ونتائجها
- **مربع الإدخال** — اكتب الرسائل؛ وأرفق الملفات؛ وأرسل أثناء عمل الوكيل لمقاطعته
- **إيقاف مؤقت / متابعة / إعادة المحاولة** — أوقف الوكيل، أو استأنف عمله، أو أعد محاولة الخطوة الأخيرة
- **مؤشر السياق** — يوضح مدى امتلاء المحادثة؛ انقر عليه لتلخيصها في محادثة جديدة
- **بطاقات الإجابة** — قد تظهر أسفل الإجابة بطاقة **الخلاصة** وبطاقة **الروابط** (سجلات، طلبات سحب، مستندات)
- **رأس المحادثة** — أعد تسمية المحادثة أو ثبّتها، أو افتح AppAgent في علامة تبويب كاملة في المتصفح باستخدام **توسيع إلى صفحة كاملة**

## التحكم في المتصفح {#feature-browser}

يمكن للوكيل فتح علامات تبويب المتصفح على مثيلك والتحكم فيها لرؤية الصفحات واختبارها:

- **التنقل والنقر والتعبئة والاختيار** — أحداث واقعية، بحيث تتصرف النماذج وحقول الإكمال التلقائي كما لو كنت تكتب بنفسك
- **الانتظار** — انتظار عنصر أو نص أو عنوان URL بدلًا من تخمين مدة التأخير
- **لقطات الشاشة** — التقاط الصفحة أو عنصر واجهة أو عنصر واحد للتحقق البصري
- **الفحص** — قراءة خصائص العناصر وأنماطها وأخطاء وحدة التحكم وطلبات الشبكة
- **انتحال الهوية** — الاختبار بصفة مستخدم آخر، ثم العودة

## تحرير السجلات وسجل الإصدارات {#feature-history}

يُتتبَّع كل تغيير يُجريه الوكيل على مثيلك في الشريط الجانبي للمحادثة:

- **تراجع** — التراجع عن تغيير منفرد
- **إعادة** — استعادة تغيير تم التراجع عنه
- **تنزيل XML** — تصدير كل التغييرات، على سبيل المثال لنقلها إلى مثيل آخر

## الوكلاء الفرعيون {#feature-subagents}

للأعمال الثقيلة أو المتوازية، يمكن للوكيل تشغيل **وكلاء فرعيين**: عاملين في الخلفية يعمل كل منهم في محادثته وسياقه الخاصين، ثم يُبلغون المحادثة الرئيسية بنتيجة موجزة.

- **مستويات النماذج** — يعمل كل وكيل فرعي على مستوى **small** (صغير) أو **medium** (متوسط) أو **large** (كبير)، أو **same** (نفسه) لاستخدام نموذج الوكيل الأصل. اربط المستويات بالنماذج في [الإعدادات](app:openSettingsPageView) ← **مستويات نماذج الوكلاء الفرعيين**
- **شريط العاملين** — يظهر الوكلاء الفرعيون قيد التشغيل كشارات مباشرة فوق حقل إدخال المحادثة؛ افتح أيًّا منها لمتابعة تقدمه أو قراءة نصه الكامل
- **المجمّع** — عدد الوكلاء الفرعيين المتزامنين محدود؛ وينتظر الإضافيون منهم في قائمة انتظار

## لوحة المعلومات وعناصر الواجهة {#page-dashboard}

لوحة معلومات من عناصر واجهة تفاعلية يُنشئها الوكيل. [فتح لوحة المعلومات ←](app:openDashboardView)

1. انقر على **إضافة عنصر واجهة**
2. صِف ما تريده، على سبيل المثال *"مخطط يعرض الحوادث المفتوحة حسب الأولوية"*
3. يبني الوكيل عنصر الواجهة؛ اطلب تغييرات أو انقر على **إعادة الإنشاء** في أي وقت

يمكن لعناصر الواجهة جلب بيانات مباشرة من مثيلك، فتبقى محدّثة دائمًا. اسحبها وغيّر حجمها واستوردها وصدّرها (راجع [متقدم](#advanced)). يمكن حفظ عناصر الواجهة التي يعرضها الوكيل داخل المحادثة باستخدام **تثبيت في لوحة المعلومات**.

## المستندات الذكية {#page-documents}

**المستندات الذكية** هي مستندات Markdown دائمة وذات إصدارات يكتبها الوكيل ويحدّثها — خطط وتقارير ومواصفات ونتائج. تُعرض داخل المحادثة، وتحتفظ بكل إصدار، ويمكنك تحريرها مباشرةً. افتحها من **المستندات** في الشريط الجانبي. [فتح المستندات ←](app:openDocumentsView)

## المهارات {#page-skills}

تمنح المهارات الوكيلَ معرفة وأدوات إضافية. [فتح المهارات ←](app:openSkillsView)

- **تنشيط / إلغاء التنشيط** — شغّل المهارات أو أوقفها؛ ألغِ تنشيط ما لا تحتاج إليه لتبقى الإجابات مركّزة
- **مهارة جديدة** — اكتب مهارتك الخاصة بصيغة Markdown، أو استخدم **التحرير بواسطة الوكيل**
- **استيراد / تصدير** — شارك المهارات كمجلدات
- **إجراءات المهارات** — تضيف بعض المهارات أزرارًا بنقرة واحدة في الصفحة الرئيسية تبدأ سير عمل مُعدًّا مسبقًا

يمكن أن توفر المهارة **معرفة** (تعليمات، أفضل الممارسات) و**أدوات مخصصة** (دوال JavaScript تعمل في بيئة معزولة).

## مساحة العمل وGitHub {#feature-workspace}

لكل محادثة **مساحة عمل** — منطقة ملفات يستطيع فيها الوكيل قراءة الملفات وكتابتها وتحريرها ومقارنة الفروق بينها.

- **GitHub** — اربط حساب GitHub في [الإعدادات](app:openSettingsPageView) لاستنساخ المستودعات إلى مساحة عمل. يستطيع الوكيل إنشاء فروع ودفع التزامات وفتح طلبات سحب من المحادثة
- **طلبات السحب** — تُدرَج طلبات السحب المفتوحة من محادثة في الشريط الجانبي للمحادثة، مع زر **دمج**
- **الحماية بين المحادثات** — يتذكر كل ملف المحادثة التي غيّرته، فلا تكتب محادثتان تعملان بالتوازي فوق عمل بعضهما بصمت
- **المزامنة التلقائية** — تتزامن مساحات العمل المستنسخة مع GitHub عند التنقل أو التبديل بين المحادثات أو العودة إلى علامة التبويب

## الشريط الجانبي للمحادثة {#feature-sidebar}

يجمع الشريط الجانبي الأيمن كل ما أنتجته المحادثة الحالية:

- **طلبات السحب** — العنوان والفرع الهدف وزر **دمج**
- **ملفات مساحة العمل** — افتح ملفًا لعرضه، أو رؤية الفروق فيه، أو تصفح إصداراته السابقة
- **سجل الإصدارات** — تغييرات المثيل مع **تراجع** و**إعادة** و**تنزيل XML**
- **العاملون** — الوكلاء الفرعيون قيد التشغيل والمنتهون، مع عدادات لاستدعاءات الأدوات والملفات المحرّرة وطلبات السحب المفتوحة

## الإجراءات والتقدم المباشر {#feature-actions}

تعرض المهام الطويلة تقدمها مباشرةً بدلًا من الصمت:

- **بطاقة التقدم** — بطاقة واحدة بحالة ملوّنة (قيد التشغيل، عالق، مكتمل، خطأ) وقائمة بالخطوات
- **أزرار الإجراءات** — أزرار بنقرة واحدة تبدأ مسارات عمل للمتابعة
- **مؤشر التشغيل** — تُميّز قائمة المحادثات المحادثاتِ التي يعمل فيها الوكيل
- **إشعار "أنهى الوكيل عمله"** — إذا بدّلت علامات التبويب أو النوافذ أثناء التشغيل، يُعلمك إشعار على سطح المكتب عندما ينتهي الوكيل

## المحادثات والمهام النشطة {#feature-jobs}

تفتح شارة المهام في الرأس عرضًا مباشرًا لمحادثاتك وأعمالك في الخلفية:

- **المحادثات النشطة** — المحادثات قيد التشغيل والمحادثات التي تحتوي على نتائج غير مقروءة (تظهر **بخط عريض**)، ولكل منها حلقة توضح استخدام السياق
- **الوكلاء الفرعيون** — مُدرَجون تحت محادثتهم الأصل؛ افتح أيًّا منهم لقراءة نصه الكامل
- **توسيع** — افتح القائمة كلوحة أكبر بتخطيط أعمدة أو أقسام

## أذونات الأدوات {#feature-permissions}

إلى جانب مستوى الأذونات الخاص بكل مثيل (**يدوي**، **تلقائي**، **تطوير**)، لكل أداة إعدادها الخاص في [الإعدادات](app:openSettingsPageView) ← **أذونات الأدوات**:

- **السماح** — تعمل الأداة دائمًا دون سؤال
- **تلقائي** — تعمل الأداة دون سؤال، ما لم يُشِر الوكيل إلى أن استدعاءً ما يحتاج إلى تأكيدك
- **السؤال** — تظهر لك مطالبة موافقة قبل كل استدعاء
- **إيقاف** — لا يستطيع الوكيل استخدام الأداة

لبعض الأدوات عناصر تحكم أدق: ServiceNow API لكل أسلوب HTTP (GET وPOST وPUT وPATCH وDELETE)، والتحكم في المتصفح لكل إجراء (التنقل، النقر، التعبئة، انتحال الهوية…)، وإدارة المهارات لكل إجراء. مربعات حوار التأكيد مرمّزة بالألوان حسب درجة الخطورة: **الأزرق** (روتيني)، **البرتقالي** (تنبيه)، **الأحمر** (مُتلِف).

:::tip
أبقِ DELETE وغيرها من العمليات المُتلِفة على **السؤال**، واستخدم **تطوير** على مثيلات التطوير فقط.
:::

## أدوات الوكيل {#feature-tools}

الأدوات الرئيسية التي يستخدمها الوكيل:

| الأداة | وظيفتها |
|------|--------------|
| **ServiceNow API** (`servicenow_api`) | قراءة السجلات وإنشاؤها وتحديثها وحذفها |
| **البرنامج النصي في الخلفية** (`servicenow_run_script`) | تشغيل برنامج نصي من جانب الخادم على المثيل (يتطلب دور admin) |
| **تحرير البرامج النصية** (`servicenow_diff_edit`) | تغيير البرامج النصية بعمليات بحث واستبدال دقيقة |
| **التحكم في المتصفح** (`iframe_tool`) | التنقل والنقر والتعبئة والفحص وانتحال الهوية في علامات تبويب المتصفح |
| **تعليمات المتصفح البرمجية** (`js_eval`) | تشغيل JavaScript في بيئة معزولة يمكنها استدعاء أدوات أخرى |
| **لقطات الشاشة** (`take_screenshot`) | التقاط الصفحة أو عنصر واجهة أو عنصر |
| **عناصر الواجهة والبطاقات** (`html_widget`, `display`) | عرض عناصر واجهة تفاعلية وجداول وبطاقات وخطوط زمنية في المحادثة |
| **المستندات الذكية** (`document`) | إنشاء مستندات Markdown دائمة وتحديثها |
| **مطالبة المستخدم** (`prompt_user`) | طلب مدخلات منك عبر نموذج داخل المحادثة |
| **الوكلاء الفرعيون** (`spawn_sub_agent`) | تفويض العمل إلى عاملين في الخلفية |
| **مساحة العمل** (`workspace`) | العمل على الملفات ومستودعات GitHub |
| **جلب الويب** (`web_fetch`) | قراءة الصفحات من الويب العام |
| **المهارات** (`get_skill`, `manage_skill`) | قراءة المهارات وإدارتها |

افتح [الإعدادات](app:openSettingsPageView) ← **أذونات الأدوات** لرؤية كل أداة ومصدرها وإذنها.

## التخزين المؤقت للمحتوى الكبير {#feature-caching}

عندما تكون نتيجة أداة أكبر من أن تتسع لها المحادثة (أكثر من 4 آلاف رمز افتراضيًا)، يخزّنها AppAgent مؤقتًا. يتلقى الوكيل مخططًا عامًا ثم يقرأ أو يبحث أو يتصفح الأجزاء التي يحتاج إليها فقط. هذا يُبقي المحادثات سريعة ومركّزة. غيّر الحد (من ألف إلى 100 ألف رمز) في [الإعدادات](app:openSettingsPageView) ← **التخزين المؤقت للمحتوى الكبير**.

## مؤشر السياق {#feature-saturation}

يوضح **مؤشر السياق** المجاور لحقل إدخال المحادثة مدى امتلاء المحادثة. بعد تجاوز 50% يُطلب من الوكيل الإنهاء وتسليم العمل الثقيل المتبقي إلى وكلاء فرعيين؛ وعند 100% يتوقف ويقدّم تقريره. انقر على المؤشر في أي وقت لتلخيص المحادثة في محادثة جديدة.

## الاستخدام وحدود المعدل {#feature-usage}

- **شارة الاستخدام** — يعرض الرأس استخدامك لـ API والحدود المتبقية؛ انقر عليها للتفاصيل
- **إعادة المحاولة التلقائية** — عندما يكون الموفر مقيّدًا بحد المعدل أو محمّلًا فوق طاقته (HTTP 429 / 529)، ينتظر AppAgent ويعيد المحاولة تلقائيًا ويعرض عدًّا تنازليًا في المحادثة
- **نفاد الرصيد** — عندما يعني الخطأ 429 فعلًا أن رصيدك قد نفد، تذكر المحادثة ذلك بوضوح

## اللغات {#feature-languages}

الواجهة متاحة بالإنجليزية إضافةً إلى 24 لغة: العربية، والصينية (المبسطة، التقليدية)، والتشيكية، والدنماركية، والهولندية، والفنلندية، والفرنسية (فرنسا، كندا)، والألمانية، والعبرية، والمجرية، والإيطالية، واليابانية، والكورية، والنرويجية، والبولندية، والبرتغالية (البرازيل، البرتغال)، والروسية، والإسبانية، والسويدية، والتايلاندية، والتركية.

اختر إحداها في [الإعدادات](app:openSettingsPageView) ← **اللغة**، أو من قائمة الإعدادات السريعة في الرأس. يتبع خيار **تلقائي** لغة متصفحك ويعود إلى الإنجليزية عند الحاجة. يُطبَّق التغيير فورًا، دون إعادة تحميل.

- **من اليمين إلى اليسار** — تستخدم العربية والعبرية تخطيطًا من اليمين إلى اليسار
- **التنسيقات المحلية** — تتبع التواريخ والأوقات والأرقام لغتك
- **ردود الوكيل** — يرد الوكيل باللغة المختارة ما لم تكتب بلغة أخرى. تبقى التعليمات البرمجية وأسماء الجداول والحقول دون تغيير

# استكشاف الأخطاء وإصلاحها والأسئلة الشائعة {#faq}

### الوكيل لا يرى مثيلي

افتح المثيل في علامة تبويب ضمن ملف تعريف Chrome نفسه وتأكد من أنك مسجّل الدخول، ثم اطلب *"list instances"* (سرد المثيلات). إذا لم يظهر بعد ذلك، فأعد تحميل علامة تبويب المثيل.

### يظهر لي خطأ في API أو في المصادقة

تحقق من الموفر في [الإعدادات](app:openSettingsPageView) ← **موفرو API**: مفتاح API، ونقطة النهاية المحددة، واسم النموذج. في حالة OAuth، سجّل الدخول إلى claude.ai مجددًا في ملف تعريف Chrome نفسه.

### يقول الوكيل إنه مقيّد بحد المعدل

يعيد AppAgent المحاولة تلقائيًا ويعرض عدًّا تنازليًا. إذا تكرر ذلك، فتحقق من شارة الاستخدام لمعرفة الرصيد المتبقي، أو استخدم مستوى نموذج أصغر للوكلاء الفرعيين.

### مطالبات الموافقة كثيرة جدًا، أو غير كافية

غيّر مستوى أذونات المثيل (**يدوي**، **تلقائي**، **تطوير**) من القائمة المنسدلة للمثيل، واضبط الأدوات كلًّا على حدة في [الإعدادات](app:openSettingsPageView) ← **أذونات الأدوات**.

### تصبح الإجابات أبطأ أو أقل دقة في محادثة طويلة

المحادثة تملأ سياقها. انقر على مؤشر السياق للمتابعة في محادثة جديدة مع ملخص.

### كيف أتراجع عن تغيير؟

افتح الشريط الجانبي للمحادثة وانقر على **تراجع** على التغيير في سجل الإصدارات. يُصدّر **تنزيل XML** كل التغييرات.

### أين تُخزَّن بياناتي؟

محليًا في متصفحك (IndexedDB). لا تُرسَل المحادثات أبدًا إلى خادم AppAgent — بل إلى موفر الذكاء الاصطناعي ومثيل ServiceNow الخاص بك فقط. راجع [تخزين البيانات](#adv-data-storage).

### الواجهة أو هذه الصفحة بلغة خاطئة

اختر اللغة في [الإعدادات](app:openSettingsPageView) ← **اللغة**. يتبع خيار **تلقائي** لغة متصفحك.

## أزرار رأس لوحة المعلومات {#adv-dashboard-header}

يحتوي رأس لوحة المعلومات على عدة أزرار إجراءات:

| الزر | الوصف |
|--------|-------------|
| **تبديل الشريط الجانبي** | إظهار شريط التنقل الجانبي الأيسر أو إخفاؤه |
| **فتح بشكل مستقل** | فتح لوحة المعلومات في علامة تبويب جديدة في المتصفح لعرضها بشكل مستقل |
| **الرؤوس** | تبديل إظهار رؤوس عناصر الواجهة على لوحة المعلومات. عند إخفائها، تُعرض عناصر الواجهة بشكل أكثر نظافة |
| **إعادة إنشاء الكل** | إعادة إنشاء كل عناصر الواجهة على لوحة المعلومات باستخدام الوكيل. مفيد لتحديث البيانات |
| **استيراد** | استيراد لوحة معلومات أو عنصر واجهة من ملف JSON |
| **تصدير** | تصدير لوحة المعلومات بالكامل إلى ملف JSON للنسخ الاحتياطي أو المشاركة |
| **إضافة عنصر واجهة** | يفتح محرر عناصر الواجهة لإنشاء عنصر واجهة جديد بمساعدة الوكيل |

## أزرار رأس عنصر الواجهة {#adv-widget-headers}

**رؤوس عناصر الواجهة في لوحة المعلومات** (تظهر عند تشغيل مفتاح الرؤوس):

| الزر | الوصف |
|--------|-------------|
| **مقبض السحب** | تعمل أيقونة عنصر الواجهة كمقبض سحب لإعادة ترتيب عناصر الواجهة |
| **إعادة الإنشاء** | اطلب من الوكيل إعادة إنشاء محتوى عنصر الواجهة هذا |
| **السجل** | عرض الإصدارات السابقة من عنصر الواجهة هذا (إن وُجدت) |
| **ملء الشاشة** | توسيع عنصر الواجهة إلى عرض ملء الشاشة |
| **تحرير** | فتح محرر عناصر الواجهة للتعديل عبر المحادثة مع الوكيل |
| **حذف** | إزالة عنصر الواجهة من لوحة المعلومات (مع تأكيد) |

**رؤوس عناصر الواجهة في المحادثة** (عناصر الواجهة المضمّنة في المحادثة):

| الزر | الوصف |
|--------|-------------|
| **تثبيت في لوحة المعلومات** | حفظ عنصر الواجهة هذا في لوحة المعلومات الخاصة بك |
| **تحرير التعليمات البرمجية** | عرض تعليمات HTML/CSS/JS البرمجية لعنصر الواجهة وتحريرها مباشرةً |
| **توسيع/طي** | تبديل إظهار محتوى عنصر الواجهة |

## تغيير حجم عناصر الواجهة ونقلها {#adv-resize-move}

**تغيير حجم عناصر الواجهة:**

- لكل عنصر واجهة **مقبض تغيير الحجم** في الزاوية السفلية اليمنى
- انقر على المقبض واسحبه لتغيير حجم عنصر الواجهة
- يلتزم العرض بشبكة من 12 عمودًا (3 أعمدة كحد أدنى)
- يُقاس الارتفاع بوحدات من 50px (وحدتان كحد أدنى = 100px)

**نقل عناصر الواجهة:**

- فعّل مفتاح **الرؤوس** لإظهار رؤوس عناصر الواجهة
- انقر على **أيقونة عنصر الواجهة** (مقبض السحب) واسحبها لإعادة الترتيب
- أفلت عنصر الواجهة على عنصر واجهة آخر لتبديل موضعيهما
- يُحفظ ترتيب عناصر الواجهة تلقائيًا

## تنسيقات الاستيراد/التصدير {#adv-import-export}

**تصدير لوحة المعلومات** (`dashboard-YYYY-MM-DD.json`):

```
{
  "type": "appagent-dashboard",
  "version": 1,
  "widgets": [
    {
      "id": "widget_123",
      "title": "Widget Title",
      "html": "<html>...</html>",
      "width": 6,
      "height": 8,
      "order": 0,
      "conversation": [...]
    }
  ]
}
```

**تصدير عنصر واجهة واحد:**

```
{
  "type": "appagent-dashboard-widget",
  "version": 1,
  "widget": { ... }
}
```

**تصدير محادثة واحدة** (`chat-title-YYYY-MM-DD.json`):

```
{
  "exportType": "single_chat",
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chat": {
    "id": "chat_123",
    "title": "Chat Title",
    "messages": [
      {
        "role": "user",
        "content": "User message text"
      },
      {
        "role": "assistant",
        "content": "Agent response text"
      }
    ],
    "createdAt": 1705312200000
  }
}
```

تحتفظ صادرات المحادثات بسجل المحادثة كاملًا، بما في ذلك كل رسائل المستخدم وردود الوكيل. استخدم القائمة المنسدلة للمحادثة (···) واختر **تنزيل** لتصدير محادثات فردية.

**تصدير المهارات** (بنية المجلد):

```
skill-name/
├── SKILL.md      # Main skill definition
├── sample.xml    # Optional XML assets
├── helper.js     # Optional JS assets
└── notes.md      # Optional MD assets
```

:::tip
**ملاحظة:** يستخدم استيراد المهارات وتصديرها File System Access API، و**لا يعمل إلا في متصفحَي Chrome أو Edge**.
:::

**تصدير كل البيانات** (`appagent-backup-YYYY-MM-DD.json`):

```
{
  "version": 3,
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chats": [...],
  "settings": [...],
  "dashboardWidgets": [...],
  "apiProviders": [...]
}
```

تتضمن النسخة الاحتياطية الكاملة كل سجل المحادثات والإعدادات وأذونات الأدوات وعناصر واجهة لوحة المعلومات وتكوينات موفري API.

عند تفعيلها في الإعدادات، تُعرض إحصاءات API بعد كل رد من الوكيل:

| المقياس | الوصف |

## تحرير المهارات يدويًا {#adv-skills-manual}

يمكن إنشاء المهارات وتحريرها يدويًا أو بمساعدة الوكيل:

**إنشاء مهارة يدويًا:**

1. انتقل إلى [المهارات](app:openSkillsView) وانقر على **مهارة جديدة**
2. أدخل اسم المهارة ووصفها
3. اكتب محتوى المهارة بتنسيق Markdown
4. انقر على **حفظ** لإنشاء المهارة

**تنسيق SKILL.md:**

```

Description of what this skill does.

## Instructions

Detailed instructions for the Agent...

## Examples

- Example usage 1
- Example usage 2
```

**التحرير بواسطة الوكيل:**

1. انقر على **التحرير بواسطة الوكيل** على أي مهارة
2. صِف التغييرات التي تريدها
3. سيعدّل الوكيل محتوى المهارة
4. راجع التغييرات واحفظها

**أصول المهارات:** يمكن أن تتضمن المهارات ملفات إضافية (XML وJS وMD) توفر سياقًا أو تعليمات برمجية إضافية للوكيل.

## موجّه النظام {#adv-system-prompt}

يحدد موجّه النظام سلوك الوكيل وقدراته. يمكنك تخصيصه في [الإعدادات](app:openSettingsPageView).

**تحرير موجّه النظام:**

1. انتقل إلى الإعدادات ← قسم موجّه النظام
2. انقر على **تحرير** للتبديل إلى وضع التحرير
3. عدّل القالب حسب الحاجة
4. انقر على **حفظ** لتطبيق التغييرات

**العناصر النائبة المتاحة:**

| العنصر النائب | الوصف |
|-------------|-------------|
| `{{CURRENT_DATE}}` | تاريخ اليوم (اليوم من الأسبوع، الشهر، اليوم، السنة) |
| `{{ORCHESTRATOR_POLICY}}` | سياسة التفويض إلى الوكلاء الفرعيين — مُضمَّنة في المحادثات الرئيسية، وتُترك فارغة في محادثات الوكلاء الفرعيين |
| `{{DISABLED_TOOLS}}` | قائمة الأدوات المعطّلة |
| `{{TOOL_CATALOG}}` | فهرس الأدوات المؤجلة (فارغ عند إيقاف التحميل المؤجل للأدوات) |
| `{{SKILLS_SUMMARY}}` | محتوى المهارات النشطة |

تُستبدل العناصر النائبة تلقائيًا بالقيم الفعلية عند الإرسال إلى الذكاء الاصطناعي. يعرض مؤشر عدد الرموز حجم القالب والحجم بعد التوسيع معًا.

:::tip
انقر على **العودة إلى الافتراضي** لاستعادة موجّه النظام الأصلي عند الحاجة.
:::

## استدعاءات API الخاصة بالوكيل {#adv-agent-api}

يعمل AppAgent كـ **إضافة لمتصفح Chrome**:

- تنتقل استدعاءات API للذكاء الاصطناعي **مباشرةً من متصفحك إلى موفر الذكاء الاصطناعي** (مثل Anthropic وOpenRouter)
- **لا** تمر عبر مثيلك أو أي خادم لـ AppAgent
- يُخزَّن مفتاح API الخاص بك (أو رمز OAuth المميز) محليًا في متصفحك
- تُرسَل بيانات المحادثة إلى موفر الذكاء الاصطناعي لمعالجتها

**آلية العمل:**

1. تكتب رسالة في المحادثة
2. يبني AppAgent موجّهًا يتضمن تعليمات النظام والأدوات وسجل المحادثة
3. يُرسَل الموجّه إلى API موفر الذكاء الاصطناعي
4. يُبث رد الوكيل عائدًا إلى متصفحك
5. تُنفَّذ استدعاءات الأدوات في متصفحك، باستخدام جلسة مثيلك لاستدعاءات API

:::tip
**الخصوصية:** تُعالَج مفتاح API وبيانات المحادثة من جانب العميل. تستخدم استدعاءات الأدوات التي تتفاعل مع مثيلك بيانات اعتماد جلستك الحالية.
:::

## نقاط نهاية LLM {#adv-endpoints}

تتصل النماذج عبر **نقاط نهاية LLM مسمّاة** — أزواج `URL + API key` قابلة لإعادة الاستخدام. يتيح لك ذلك توجيه AppAgent إلى **أي API لإكمال المحادثات متوافق مع OpenAI**: OpenRouter، أو بوابة محلية، أو وكيل (proxy)، أو نموذجك المستضاف الخاص.

1. في [الإعدادات ← نقاط نهاية LLM](app:openSettingsPageView)، انقر على **إضافة نقطة نهاية**
2. أعطها اسمًا وعنوان URL لـ API ومفتاح API
3. يختار كل نموذج (موفر API) نقطة نهاية — حدّث المفتاح مرة واحدة فيتحدّث في كل نموذج يستخدمها

:::tip
لا يستخدم موفرو Claude عبر **OAuth** نقاط النهاية — بل يتصلون بـ `api.anthropic.com` مباشرةً.
:::

## تسجيل الدخول باستخدام Claude (OAuth) {#adv-oauth}

بدلًا من لصق مفتاح API، يمكنك تسجيل الدخول إلى موفري Anthropic باستخدام جلسة claude.ai الحالية لديك:

1. في [الإعدادات ← موفرو API](app:openSettingsPageView)، أضف موفر Anthropic أو حرّره وفعّل **OAuth**
2. تستخدم الإضافة تسجيل دخولك إلى claude.ai من ملف تعريف Chrome نفسه للاتصال بـ Anthropic مباشرةً
3. لا توجد نافذة تسجيل دخول إضافية، ولا يوجد خادم لـ AppAgent في المنتصف

**المتطلبات:**

- يجب أن تكون مسجّل الدخول إلى `claude.ai` في ملف تعريف Chrome نفسه
- يعمل مع حسابات تسجيل الدخول الموحّد (SSO)

:::tip
تُحدَّث رموز OAuth المميزة تلقائيًا. إذا فشل تسجيل الدخول، فافتح `claude.ai` في ملف التعريف نفسه وسجّل الدخول مجددًا.
:::

## اعتبارات الأمان {#adv-security}

**تخزين مفتاح API:**

- **يُخزَّن مفتاح API الخاص بك محليًا** في IndexedDB بمتصفحك
- لا يُرسَل المفتاح أبدًا إلى مثيلك أو إلى أي خادم غير موفر الذكاء الاصطناعي
- يؤدي مسح بيانات المتصفح إلى إزالة مفتاح API المخزّن

**الجلسة والأذونات:**

- يعمل الوكيل **بجلسة المستخدم الحالية الخاصة بك**، فيرث صلاحيات الوصول والأدوار الخاصة بك
- تستخدم كل استدعاءات API إلى مثيلك بيانات اعتماد جلستك
- لا يستطيع الوكيل الوصول إلا إلى ما يستطيع حساب المستخدم الخاص بك الوصول إليه

**بيئة تنفيذ الأدوات:**

- **تعليمات المتصفح البرمجية (js_eval)** تشغّل JavaScript في **بيئة معزولة** مع إمكانية الوصول إلى `executeTool()` فقط
- **البرامج النصية لعناصر الواجهة** تعمل في **إطارات iframe معزولة** مع إمكانية الوصول إلى `executeTool()` فقط لاستدعاءات API
- **أدوات المهارات** تعمل في **بيئات معزولة** مع إمكانية الوصول إلى `executeTool()` فقط
- يمر كل وصول إلى API عبر **نظام الأذونات** من خلال `executeTool("servicenow_api", {...})`
- يتفاعل الوكيل مع الصفحات في **علامات تبويب المتصفح** على مثيل ServiceNow الخاص بك

**قدرات تعديل السجلات:**

- تدعم أداة **ServiceNow API** أساليب POST وPATCH وPUT وDELETE التي يمكنها تغيير السجلات
- يستطيع الوكيل إنشاء السجلات وتحريرها عبر **المتصفح المدمج** إذا مُنح أذونات لأدوات التعبئة والنقر
- اضبط [أذونات الأدوات](app:openSettingsPageView) للتحكم في العمليات التي تتطلب موافقة

**التحسين الذاتي:**

- يستطيع الوكيل **إدارة مهاراته الخاصة** — إنشاء المهارات وتحريرها وتنشيطها
- يتيح ذلك للوكيل التعلّم وتحسين نفسه بمرور الوقت
- راجع تغييرات المهارات دوريًا للتأكد من توافقها مع توقعاتك

## تخزين البيانات {#adv-data-storage}

يخزّن AppAgent البيانات محليًا في متصفحك باستخدام **IndexedDB**:

| نوع البيانات | التخزين | الوصف |
|-----------|---------|-------------|
| **المحادثات** | IndexedDB | كل سجل المحادثات والرسائل ونتائج الأدوات |
| **الإعدادات** | IndexedDB | أذونات الأدوات ومفاتيح API وتفضيلات النماذج |
| **عناصر واجهة لوحة المعلومات** | IndexedDB | HTML عناصر الواجهة وعناوينها وأحجامها وسجل المحادثة |
| **المهارات** | IndexedDB | تعريفات المهارات ومحتواها وأصولها |
| **موفرو API** | IndexedDB | تكوينات موفري API المخصصين ونقاط النهاية |
| **حالة الواجهة** | localStorage | حالة الشريط الجانبي والعرض الحالي ومواضع التمرير |

**تنزيل بياناتك:**

1. انتقل إلى [الإعدادات](app:openSettingsPageView) ← إدارة البيانات
2. انقر على **تصدير البيانات**
3. سيُنزَّل ملف نسخة احتياطية بتنسيق JSON

**حذف بياناتك:**

1. انتقل إلى [الإعدادات](app:openSettingsPageView) ← إدارة البيانات
2. انقر على **حذف كل البيانات**
3. أكّد مرتين لحذف كل شيء نهائيًا

:::tip
**مهم:** تُخزَّن البيانات محليًا في الإضافة. يؤدي مسح بيانات المتصفح أو إلغاء تثبيت الإضافة أو استخدام ملف تعريف متصفح مختلف إلى مخازن بيانات منفصلة.
:::
