# AppAgent

**ابنِ تطبيقات ServiceNow وصُنها باستخدام وكيل. كإضافة لمتصفح Chrome.**

AppAgent هو شريكك في التطوير على ServiceNow. يستطيع إنشاء التطبيقات وصيانتها وتشغيل الاختبارات عليها. ويُجري الاختبارات بتعبئة النماذج والتقاط لقطات الشاشة. لا حاجة إلى أي معرفة تقنية.

أحضر مفتاح API الخاص بك (BYOK) وهذا كل شيء! إنه متوافق مع OpenAI وOpenRouter وClaude API، وحتى مع خطط Claude Code (تواصل معنا بشكل خاص).

إنه إضافة لمتصفح Chrome تخزّن المحادثة بالكامل في متصفحك (لا تغادر متصفحك أصلًا). ولا يتفاعل إلا مع مثيل ServiceNow الخاص بك وموفر API النموذج الخاص بك.

![مثال على AppAgent](AppAgentExample.png)

يستخدم رموزًا أقل من Claude Code، إذ يعتمد بشكل كبير على التخزين المؤقت لـ API والتخزين المؤقت للأدوات وتسلسل الأدوات (جاهزة للاستخدام مباشرةً).

يمكنك إضافة مهارات إليه، ويتحكم في المتصفح عبر علامات التبويب، ويوفر أزرار تراجع آلية لكل التغييرات التي يُجريها على مثيلك.

> **ملاحظة:** في الوقت الحالي، AppAgent مخصص للاستخدام على مثيلات التطوير فقط.

| **بلا تبعيات** | بلا مكتبات، وبلا أطر عمل، JavaScript خالص |

## آلية العمل

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent إضافة لمتصفح Chrome مع حلقة وكيل مدمجة. تصف ما تريده ← يسأل الوكيل النموذج ← يُنفّذ الأدوات في المتصفح ← يصل إلى ServiceNow بأذونات المستخدم الحالي الخاصة بك. يتواصل الوكيل مباشرةً مع موفري API للنماذج، سواء في مقرك أو عبر الإنترنت.

## الإعداد

1. **التثبيت** — ثبّت إضافة AppAgent من Chrome Web Store (أو حمّلها غير مضغوطة لأغراض التطوير)
2. **احصل على مفتاح API** — أنشئ حسابًا على [OpenRouter](https://openrouter.ai)، أو استخدم Anthropic/OpenAI مباشرةً، أو اربط اشتراكك في Claude Code (المؤسسي أو الشخصي)
3. **التكوين** — افتح الإضافة وأضف مفتاح API الخاص بك (أو سجّل الدخول باستخدام Claude) في الإعدادات ← موفرو API
4. **ابدأ البناء** — افتح مثيل ServiceNow الخاص بك في علامة تبويب (يُكتشف تلقائيًا) وابدأ المحادثة

## أمثلة

### "ابنِ لي تطبيقًا بسيطًا لتتبع مهام الفريق"
سينشئ AppAgent الجدول، ويضيف الحقول، ويبني تخطيط النموذج والقائمة، ويُعدّ وحدة في المتصفح التنقلي (navigator). موجّه واحد، تطبيق كامل.

### "أجرِ تدقيقًا كاملًا على هذا المثيل"
سيفحص AppAgent الثغرات الأمنية وحسابات المسؤولين غير النشطة والسجلات القديمة وأفضل ممارسات التكوين، ثم يقدّم لك تقريرًا بالتوصيات.

### "اختبر هذه الصفحة وأبلغ عن أي مشكلات تجدها"
سيفتح AppAgent الصفحة في علامة تبويب في المتصفح، ويعبّئ النماذج، وينقر على الأزرار، ويلتقط لقطات الشاشة، ويُعدّ تقريرًا بكل ما يجده.

### "يوجد خطأ في هذا النموذج، هل يمكنك إصلاحه؟"
سيفتح AppAgent النموذج، ويفحص البرامج النصية التي تقف خلفه، ويحدد الخطأ، ويصلح التعليمات البرمجية، ويُريك بالضبط ما الذي تغيّر. نقرة واحدة للتراجع عند الحاجة.

### "أنشئ عنصر واجهة في لوحة المعلومات لتذاكري المفتوحة"
سينشئ AppAgent عنصر واجهة مباشرًا يجلب بيانات في الوقت الفعلي من مثيلك ويعرضها على لوحة المعلومات الخاصة بك.

### "استورد ملف Excel هذا إلى جدول المستخدمين"
سيقرأ AppAgent الملف، ويربط الأعمدة بالحقول، ويستورد البيانات إلى مثيلك.

### "تحقق من سجل الترقية وأصلح مشكلات التخصيص"
سيراجع AppAgent ما تغيّر في الترقية، ويعثر على التخصيصات المعطّلة، ويصلحها.

### "أبلغ الفريق عند إنشاء حادثة P1"
سينشئ AppAgent قاعدة إشعار تُطلَق عند حوادث P1 وترسل تنبيهًا إلى فريقك.
