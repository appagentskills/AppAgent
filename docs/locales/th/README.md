# AppAgent

**สร้างและดูแลแอป ServiceNow ด้วยเอเจนต์ ในรูปแบบส่วนขยายของ Chrome**

AppAgent คือคู่หูในการพัฒนาสำหรับ ServiceNow ของคุณ สามารถสร้างและดูแลแอป รวมถึงรันการทดสอบให้แอปเหล่านั้น โดยทดสอบด้วยการกรอกฟอร์มและจับภาพหน้าจอ ไม่ต้องมีความรู้ทางเทคนิค

เพียงนำคีย์ API ของคุณเองมาใช้ (BYOK) ก็พร้อมใช้งานแล้ว! เข้ากันได้กับ OpenAI, OpenRouter, Claude API และแม้แต่แพ็กเกจ Claude Code (ติดต่อเราเป็นการส่วนตัว)

เป็นส่วนขยายของ Chrome ที่เก็บแชททั้งหมดไว้ในเบราว์เซอร์ของคุณ (ข้อมูลไม่ออกจากเบราว์เซอร์เลย) และโต้ตอบเฉพาะกับอินสแตนซ์ ServiceNow และผู้ให้บริการ API ของโมเดลของคุณเท่านั้น

![ตัวอย่าง AppAgent](AppAgentExample.png)

ใช้โทเค็นน้อยกว่า Claude Code เพราะอาศัยแคช API การแคชเครื่องมือ และการเชื่อมต่อเครื่องมือเป็นลำดับอย่างเต็มที่ (พร้อมใช้งานทันที)

คุณเพิ่มทักษะได้ มีการควบคุมเบราว์เซอร์ผ่านแท็บ และมีปุ่มเลิกทำเชิงกลไกสำหรับทุกการเปลี่ยนแปลงที่ทำกับอินสแตนซ์ของคุณ

> **หมายเหตุ:** ในตอนนี้ AppAgent มีไว้สำหรับใช้กับอินสแตนซ์สำหรับการพัฒนาเท่านั้น

## วิธีการทำงาน

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│              │      │              │      │              │
│   Chrome     │◀────▶│    Model     │      │  ServiceNow  │
│  Extension   │      │   (Claude,   │      │   Instance   │
│              │      │   GPT, etc)  │      │              │
│  [AppAgent]  │      └──────────────┘      │              │
│              │◀──────────────────────────▶│              │
└──────────────┘                            └──────────────┘
```

AppAgent เป็นส่วนขยายของ Chrome ที่มีลูปเอเจนต์ในตัว คุณอธิบายสิ่งที่ต้องการ → เอเจนต์ถามโมเดล → รันเครื่องมือในเบราว์เซอร์ → เข้าถึง ServiceNow ด้วยสิทธิ์ผู้ใช้ปัจจุบันของคุณ เอเจนต์สื่อสารกับผู้ให้บริการ API ของโมเดลโดยตรง ทั้งแบบติดตั้งภายในองค์กรหรือออนไลน์

## การตั้งค่า

1. **ติดตั้ง** — ติดตั้งส่วนขยาย AppAgent จาก Chrome Web Store (หรือโหลดแบบ unpacked สำหรับการพัฒนา)
2. **รับคีย์ API** — สมัครที่ [OpenRouter](https://openrouter.ai) ใช้ Anthropic/OpenAI โดยตรง หรือเชื่อมต่อการสมัครใช้งาน Claude Code ของคุณ (Enterprise หรือ Personal)
3. **กำหนดค่า** — เปิดส่วนขยายแล้วเพิ่มคีย์ API ของคุณ (หรือลงชื่อเข้าใช้ด้วย Claude) ใน การตั้งค่า → ผู้ให้บริการ API
4. **เริ่มสร้าง** — เปิดอินสแตนซ์ ServiceNow ของคุณในแท็บ (ระบบจะตรวจพบโดยอัตโนมัติ) แล้วเริ่มแชทได้เลย

## ตัวอย่าง

### "สร้างแอปง่ายๆ สำหรับติดตามงานของทีมให้หน่อย"
AppAgent จะสร้างตาราง เพิ่มฟิลด์ สร้างเลย์เอาต์ฟอร์มและรายการ และตั้งค่าโมดูลในตัวนำทาง พรอมต์เดียวได้แอปครบ

### "ตรวจสอบอินสแตนซ์นี้แบบเต็มรูปแบบ"
AppAgent จะสแกนหาช่องโหว่ด้านความปลอดภัย บัญชีผู้ดูแลที่ไม่ได้ใช้งาน เรกคอร์ดที่ค้างเก่า และแนวทางปฏิบัติที่ดีในการกำหนดค่า แล้วส่งรายงานพร้อมคำแนะนำให้คุณ

### "ทดสอบหน้านี้และรายงานปัญหาที่พบ"
AppAgent จะเปิดหน้าในแท็บเบราว์เซอร์ กรอกฟอร์ม คลิกปุ่ม จับภาพหน้าจอ และรวบรวมรายงานทุกสิ่งที่พบ

### "ฟอร์มนี้มีบั๊ก ช่วยแก้ให้หน่อยได้ไหม"
AppAgent จะเปิดฟอร์ม ตรวจสอบสคริปต์เบื้องหลัง ระบุบั๊ก แก้โค้ด และแสดงให้คุณเห็นว่ามีอะไรเปลี่ยนไปบ้าง เลิกทำได้ในคลิกเดียวหากจำเป็น

### "สร้างวิดเจ็ตแดชบอร์ดสำหรับทิกเก็ตที่เปิดอยู่ของฉัน"
AppAgent จะสร้างวิดเจ็ตแบบสดที่ดึงข้อมูลแบบเรียลไทม์จากอินสแตนซ์ของคุณและแสดงบนแดชบอร์ด

### "นำเข้าไฟล์ Excel นี้ไปยังตารางผู้ใช้"
AppAgent จะอ่านไฟล์ จับคู่คอลัมน์กับฟิลด์ และนำเข้าข้อมูลไปยังอินสแตนซ์ของคุณ

### "ตรวจสอบประวัติการอัปเกรดและแก้ปัญหาการปรับแต่ง"
AppAgent จะตรวจทานสิ่งที่เปลี่ยนไปในการอัปเกรด ค้นหาการปรับแต่งที่เสียหาย และแก้ไขให้

### "แจ้งทีมเมื่อมีการสร้างอินซิเดนต์ P1"
AppAgent จะสร้างกฎการแจ้งเตือนที่ทำงานเมื่อมีอินซิเดนต์ P1 และส่งการแจ้งเตือนไปยังทีมของคุณ
