# เริ่มต้นใช้งาน {#getting-started}

AppAgent คือเอเจนต์ AI สำหรับ ServiceNow ที่ทำงานเป็นส่วนขยายของ Chrome เพียงอธิบายสิ่งที่คุณต้องการด้วยภาษาธรรมดา เอเจนต์จะค้นหาข้อมูล แก้ไขเรกคอร์ด สร้างแอปและวิดเจ็ต ทดสอบหน้าเว็บในเบราว์เซอร์ของคุณ แล้วรายงานผลกลับมา

:::tip
**เริ่มต้นอย่างรวดเร็ว:** ตั้งค่าโมเดล เปิดแท็บของอินสแตนซ์ ServiceNow จากนั้นพิมพ์คำขอในแชทแล้วกด <kbd>Enter</kbd>
:::

## ตั้งค่าโมเดล {#guide-setup}

1. เปิด [การตั้งค่า](app:openSettingsPageView) แล้วไปที่ **ผู้ให้บริการ API**
2. เพิ่มผู้ให้บริการ (Anthropic, OpenRouter หรือ API แบบกำหนดเองที่เข้ากันได้กับ OpenAI) พร้อมคีย์ API ของคุณ หรือเปิดใช้ **OAuth** กับผู้ให้บริการ Anthropic เพื่อลงชื่อเข้าใช้ด้วยบัญชี Claude ของคุณ
3. เลือกโมเดลที่จะใช้ใน **โมเดลของเอเจนต์**

คีย์ API ของคุณจะถูกเก็บไว้ในเบราว์เซอร์ของคุณเท่านั้น การเรียก AI จะส่งตรงจากเบราว์เซอร์ของคุณไปยังผู้ให้บริการ

## เชื่อมต่ออินสแตนซ์ของคุณ {#guide-instances}

AppAgent **ตรวจพบทุกอินสแตนซ์ ServiceNow โดยอัตโนมัติ** ที่คุณเปิดไว้ในโปรไฟล์ Chrome เดียวกัน ไม่ต้องป้อนสตริงการเชื่อมต่อใดๆ เพียงลงชื่อเข้าใช้อินสแตนซ์ในแท็บปกติ เอเจนต์ก็จะทำงานกับอินสแตนซ์นั้นได้ด้วยบทบาทและสิทธิ์การเข้าถึงของผู้ใช้คุณ ลองพิมพ์ *"แสดงรายการอินสแตนซ์"* เพื่อดูทุกอินสแตนซ์ที่ตรวจพบ บทบาทของคุณ และสถานะการเชื่อมต่อ

แต่ละอินสแตนซ์มี **ระดับสิทธิ์** ซึ่งเลือกได้จากเมนูดรอปดาวน์ของอินสแตนซ์:

- **ด้วยตนเอง** — คุณอนุมัติการเขียนแต่ละครั้งเอง (สร้าง อัปเดต ลบ กรอกฟอร์ม)
- **อัตโนมัติ** — เอเจนต์ตัดสินใจเรื่องการเขียนเองโดยไม่ต้องถาม
- **นักพัฒนา** — ไม่ต้องอนุมัติใดๆ เลย: การเรียกเครื่องมือทุกครั้งบนอินสแตนซ์นี้จะทำงานโดยไม่ถาม ใช้เฉพาะกับอินสแตนซ์สำหรับการพัฒนาเท่านั้น

การอ่านได้รับอนุญาตเสมอ ดู [สิทธิ์ของเครื่องมือ](#feature-permissions) สำหรับการควบคุมที่ละเอียดขึ้น

## เริ่มแชท {#guide-chat}

1. คลิก **แชทใหม่** ในแถบด้านข้าง [เริ่มแชทใหม่ →](app:startNewChat)
2. พิมพ์คำขอของคุณ เช่น *"แสดงอินซิเดนต์ทั้งหมดที่สร้างวันนี้"*
3. กด <kbd>Enter</kbd> เพื่อส่ง
4. ติดตามการทำงานของเอเจนต์: การเรียกเครื่องมือแต่ละครั้งจะแสดงในแชท และจะมีข้อความขออนุมัติเมื่อขั้นตอนใดต้องการความยินยอมจากคุณ

คุณพิมพ์ต่อได้ขณะที่เอเจนต์กำลังทำงาน: การส่งข้อความใหม่จะขัดจังหวะขั้นตอนปัจจุบัน และ **หยุดชั่วคราว** จะหยุดการทำงาน

## แนบรูปภาพและไฟล์ {#guide-images}

1. คลิกปุ่ม **แนบไฟล์** ในช่องป้อนข้อความเพื่อเพิ่มรูปภาพ PDF, CSV หรือไฟล์ข้อความ
2. หรือวางรูปภาพจากคลิปบอร์ด หรือลากแล้ววางลงในแชท
3. พิมพ์คำถามเกี่ยวกับไฟล์แนบ

:::tip
แนบภาพหน้าจอข้อผิดพลาด ภาพจำลอง UI หรือข้อมูลที่ส่งออก เพื่อให้เอเจนต์เห็นสิ่งที่คุณเห็นได้อย่างแม่นยำ
:::

# ฟีเจอร์หลัก {#features}

## แชท {#page-chat}

มุมมองการสนทนาหลัก [เริ่มแชทใหม่ →](app:startNewChat)

- **พื้นที่ข้อความ** — การสนทนา รวมถึงการเรียกเครื่องมือและผลลัพธ์
- **ช่องป้อนข้อความ** — พิมพ์ข้อความ แนบไฟล์ หรือส่งข้อความขณะเอเจนต์ทำงานเพื่อขัดจังหวะ
- **หยุดชั่วคราว / ดำเนินการต่อ / ลองอีกครั้ง** — หยุดเอเจนต์ ให้ทำงานต่อ หรือลองขั้นตอนล่าสุดอีกครั้ง
- **ตัวบ่งชี้บริบท** — แสดงว่าการสนทนาเต็มแค่ไหน คลิกเพื่อสรุปไปยังแชทใหม่
- **การ์ดคำตอบ** — การ์ดสรุป **สรุปสั้นๆ** และการ์ด **ลิงก์** (เรกคอร์ด PR เอกสาร) อาจแสดงใต้คำตอบ
- **ส่วนหัวของแชท** — เปลี่ยนชื่อหรือปักหมุดแชท หรือเปิด AppAgent ในแท็บเบราว์เซอร์เต็มด้วย **ขยายเต็มหน้า**

## การควบคุมเบราว์เซอร์ {#feature-browser}

เอเจนต์สามารถเปิดและควบคุมแท็บเบราว์เซอร์บนอินสแตนซ์ของคุณเพื่อดูและทดสอบหน้าต่างๆ:

- **นำทาง คลิก กรอก และเลือก** — ใช้เหตุการณ์ที่สมจริง ฟอร์มและช่องเติมข้อความอัตโนมัติจึงทำงานเหมือนคุณพิมพ์เอง
- **รอ** — รอองค์ประกอบ ข้อความ หรือ URL แทนการเดาเวลาหน่วง
- **ภาพหน้าจอ** — จับภาพทั้งหน้า วิดเจ็ต หรือองค์ประกอบเดียวเพื่อตรวจสอบด้วยสายตา
- **ตรวจสอบ** — อ่านคุณสมบัติขององค์ประกอบ สไตล์ ข้อผิดพลาดในคอนโซล และคำขอเครือข่าย
- **สวมบทบาท** — ทดสอบในฐานะผู้ใช้อื่น แล้วสลับกลับ

## แก้ไขเรกคอร์ดและประวัติเวอร์ชัน {#feature-history}

ทุกการเปลี่ยนแปลงที่เอเจนต์ทำกับอินสแตนซ์ของคุณจะถูกติดตามไว้ในแถบด้านข้างของแชท:

- **เลิกทำ** — ย้อนกลับการเปลี่ยนแปลงทีละรายการ
- **ทำซ้ำ** — คืนค่าการเปลี่ยนแปลงที่ย้อนกลับไปแล้ว
- **ดาวน์โหลด XML** — ส่งออกการเปลี่ยนแปลงทั้งหมด เช่น เพื่อย้ายไปยังอินสแตนซ์อื่น

## เอเจนต์ย่อย {#feature-subagents}

สำหรับงานหนักหรืองานคู่ขนาน เอเจนต์สามารถเริ่ม **เอเจนต์ย่อย** ได้: เวิร์กเกอร์เบื้องหลังที่ทำงานในแชทและบริบทของตัวเอง แล้วรายงานผลสั้นๆ กลับมายังแชทหลัก

- **ระดับโมเดล** — เอเจนต์ย่อยแต่ละตัวทำงานบนระดับ **เล็ก** **กลาง** หรือ **ใหญ่** หรือ **เหมือนเดิม** เพื่อใช้โมเดลเดียวกับแชทหลัก กำหนดว่าแต่ละระดับใช้โมเดลใดได้ใน [การตั้งค่า](app:openSettingsPageView) → **ระดับโมเดลของเอเจนต์ย่อย**
- **แถบเวิร์กเกอร์** — เอเจนต์ย่อยที่กำลังทำงานจะแสดงเป็นชิปแบบสดเหนือช่องป้อนข้อความ เปิดชิปเพื่อดูความคืบหน้าหรืออ่านบันทึกการสนทนา
- **พูล** — จำนวนเอเจนต์ย่อยที่ทำงานพร้อมกันมีขีดจำกัด ตัวที่เกินจะรอในคิว

## แดชบอร์ดและวิดเจ็ต {#page-dashboard}

แดชบอร์ดของวิดเจ็ตแบบโต้ตอบที่เอเจนต์สร้างขึ้น [เปิดแดชบอร์ด →](app:openDashboardView)

1. คลิก **เพิ่มวิดเจ็ต**
2. อธิบายสิ่งที่คุณต้องการ เช่น *"แผนภูมิแสดงอินซิเดนต์ที่เปิดอยู่ตามลำดับความสำคัญ"*
3. เอเจนต์จะสร้างวิดเจ็ตให้ คุณขอให้แก้ไขหรือคลิก **สร้างใหม่** ได้ทุกเมื่อ

วิดเจ็ตดึงข้อมูลสดจากอินสแตนซ์ของคุณได้ จึงอัปเดตอยู่เสมอ คุณลาก ปรับขนาด นำเข้า และส่งออกวิดเจ็ตได้ (ดู [ขั้นสูง](#advanced)) วิดเจ็ตที่เอเจนต์แสดงในแชทสามารถบันทึกได้ด้วย **ปักหมุดที่แดชบอร์ด**

## เอกสารอัจฉริยะ {#page-documents}

**เอกสารอัจฉริยะ** คือเอกสาร Markdown แบบถาวรที่มีการจัดเวอร์ชัน ซึ่งเอเจนต์เขียนและอัปเดต เช่น แผนงาน รายงาน ข้อกำหนด หรือผลการตรวจสอบ เอกสารเหล่านี้แสดงในแชทโดยตรง เก็บทุกเวอร์ชันไว้ และคุณแก้ไขเองได้ เปิดได้จาก **เอกสาร** ในแถบด้านข้าง [เปิดเอกสาร →](app:openDocumentsView)

## ทักษะ {#page-skills}

ทักษะช่วยเพิ่มความรู้และเครื่องมือให้เอเจนต์ [เปิดทักษะ →](app:openSkillsView)

- **เปิดใช้งาน / ปิดใช้งาน** — เปิดหรือปิดทักษะ ปิดทักษะที่ไม่จำเป็นเพื่อให้คำตอบตรงประเด็น
- **ทักษะใหม่** — เขียนทักษะของคุณเองด้วย Markdown หรือใช้ **แก้ไขด้วยเอเจนต์**
- **นำเข้า / ส่งออก** — แชร์ทักษะเป็นโฟลเดอร์
- **การดำเนินการของทักษะ** — ทักษะบางอย่างเพิ่มปุ่มคลิกเดียวบนหน้าแรกเพื่อเริ่มเวิร์กโฟลว์ที่ตั้งไว้ล่วงหน้า

ทักษะสามารถให้ **ความรู้** (คำแนะนำ แนวทางปฏิบัติที่ดี) และ **เครื่องมือแบบกำหนดเอง** (ฟังก์ชัน JavaScript ที่ทำงานในแซนด์บ็อกซ์แยก)

## เวิร์กสเปซและ GitHub {#feature-workspace}

แต่ละแชทมี **เวิร์กสเปซ** ซึ่งเป็นพื้นที่ไฟล์ที่เอเจนต์อ่าน เขียน แก้ไข และเปรียบเทียบความแตกต่างของไฟล์ได้

- **GitHub** — เชื่อมต่อบัญชี GitHub ใน [การตั้งค่า](app:openSettingsPageView) เพื่อโคลนรีโพสิทอรีลงในเวิร์กสเปซ เอเจนต์สามารถสร้างแบรนช์ พุชคอมมิต และเปิด Pull Request ได้จากแชท
- **Pull Request** — PR ที่เปิดจากแชทจะแสดงในแถบด้านข้างของแชท พร้อมปุ่ม **ผสาน**
- **การป้องกันระหว่างแชท** — แต่ละไฟล์จะจำว่าแชทใดเป็นผู้เปลี่ยนแปลง แชทสองแชทที่ทำงานคู่ขนานกันจึงไม่เขียนทับงานของกันและกันโดยไม่รู้ตัว
- **ซิงค์อัตโนมัติ** — เวิร์กสเปซที่โคลนไว้จะซิงค์กับ GitHub เมื่อคุณนำทาง สลับแชท หรือกลับมาที่แท็บ

## แถบด้านข้างของแชท {#feature-sidebar}

แถบด้านข้างทางขวารวบรวมทุกอย่างที่แชทปัจจุบันสร้างขึ้น:

- **Pull Request** — ชื่อ แบรนช์ปลายทาง และปุ่ม **ผสาน**
- **ไฟล์ในเวิร์กสเปซ** — เปิดไฟล์เพื่อดู ดูความแตกต่าง หรือเรียกดูเวอร์ชันก่อนหน้า
- **ประวัติเวอร์ชัน** — การเปลี่ยนแปลงบนอินสแตนซ์ พร้อม **เลิกทำ** **ทำซ้ำ** และ **ดาวน์โหลด XML**
- **เวิร์กเกอร์** — เอเจนต์ย่อยที่กำลังทำงานและที่เสร็จแล้ว พร้อมตัวนับการเรียกเครื่องมือ ไฟล์ที่แก้ไข และ PR ที่เปิด

## การดำเนินการและความคืบหน้าแบบสด {#feature-actions}

งานที่ใช้เวลานานจะแสดงความคืบหน้าแบบสดแทนการเงียบหายไป:

- **การ์ดความคืบหน้า** — การ์ดเดียวที่แสดงสถานะด้วยสี (กำลังทำงาน ติดขัด เสร็จสิ้น ข้อผิดพลาด) และรายการขั้นตอน
- **ปุ่มการดำเนินการ** — ปุ่มคลิกเดียวที่เริ่มเวิร์กโฟลว์ต่อเนื่อง
- **ตัวบ่งชี้การทำงาน** — รายการแชทจะทำเครื่องหมายแชทที่เอเจนต์กำลังทำงานอยู่
- **การแจ้งเตือน "เอเจนต์ทำงานเสร็จแล้ว"** — หากคุณสลับแท็บหรือหน้าต่างระหว่างการทำงาน การแจ้งเตือนบนเดสก์ท็อปจะบอกคุณเมื่อเอเจนต์ทำงานเสร็จ

## แชทและงานที่ทำงานอยู่ {#feature-jobs}

ปุ่มงานในส่วนหัวจะเปิดมุมมองแบบสดของแชทและงานเบื้องหลังของคุณ:

- **แชทที่ใช้งานอยู่** — แชทที่กำลังทำงานและแชทที่มีผลลัพธ์ยังไม่ได้อ่าน (แสดงเป็น **ตัวหนา**) แต่ละแชทมีวงแหวนแสดงการใช้บริบท
- **เอเจนต์ย่อย** — แสดงอยู่ใต้แชทหลักของตัวเอง เปิดเพื่ออ่านบันทึกการสนทนา
- **ขยาย** — เปิดรายการเป็นแผงที่ใหญ่ขึ้นในรูปแบบคอลัมน์หรือส่วน

## สิทธิ์ของเครื่องมือ {#feature-permissions}

นอกจากระดับสิทธิ์ของแต่ละอินสแตนซ์ (**ด้วยตนเอง** **อัตโนมัติ** **นักพัฒนา**) แล้ว เครื่องมือแต่ละตัวยังมีการตั้งค่าของตัวเองใน [การตั้งค่า](app:openSettingsPageView) → **สิทธิ์ของเครื่องมือ**:

- **อนุญาต** — เครื่องมือทำงานเสมอโดยไม่ถาม
- **อัตโนมัติ** — เครื่องมือทำงานโดยไม่ถาม เว้นแต่เอเจนต์จะระบุว่าการเรียกนั้นต้องได้รับการยืนยันจากคุณ
- **ถาม** — คุณจะได้รับข้อความขออนุมัติก่อนการเรียกทุกครั้ง
- **ปิด** — เอเจนต์ใช้เครื่องมือนี้ไม่ได้

เครื่องมือบางตัวมีการควบคุมที่ละเอียดขึ้น: ServiceNow API แยกตามเมธอด HTTP (GET, POST, PUT, PATCH, DELETE) การควบคุมเบราว์เซอร์แยกตามการกระทำ (นำทาง คลิก กรอก สวมบทบาท…) และการจัดการทักษะแยกตามการกระทำ กล่องโต้ตอบยืนยันจะใช้สีตามระดับความเสี่ยง: **น้ำเงิน** (งานปกติ) **ส้ม** (ควรระวัง) **แดง** (ทำลายข้อมูล)

:::tip
ตั้ง DELETE และการดำเนินการที่ทำลายข้อมูลอื่นๆ ไว้ที่ **ถาม** และใช้ **นักพัฒนา** เฉพาะกับอินสแตนซ์สำหรับการพัฒนาเท่านั้น
:::

## เครื่องมือของเอเจนต์ {#feature-tools}

เครื่องมือหลักที่เอเจนต์ใช้:

| เครื่องมือ | หน้าที่ |
|------|--------------|
| **ServiceNow API** (`servicenow_api`) | อ่าน สร้าง อัปเดต และลบเรกคอร์ด |
| **สคริปต์เบื้องหลัง** (`servicenow_run_script`) | รันสคริปต์ฝั่งเซิร์ฟเวอร์บนอินสแตนซ์ (ต้องมีบทบาท admin) |
| **การแก้ไขสคริปต์** (`servicenow_diff_edit`) | เปลี่ยนสคริปต์ด้วยการค้นหาและแทนที่อย่างแม่นยำ |
| **การควบคุมเบราว์เซอร์** (`iframe_tool`) | นำทาง คลิก กรอก ตรวจสอบ และสวมบทบาทในแท็บเบราว์เซอร์ |
| **โค้ดเบราว์เซอร์** (`js_eval`) | รัน JavaScript ในแซนด์บ็อกซ์แยกที่เรียกเครื่องมืออื่นได้ |
| **ภาพหน้าจอ** (`take_screenshot`) | จับภาพหน้า วิดเจ็ต หรือองค์ประกอบ |
| **วิดเจ็ตและการ์ด** (`html_widget`, `display`) | แสดงวิดเจ็ตแบบโต้ตอบ ตาราง การ์ด และไทม์ไลน์ในแชท |
| **เอกสารอัจฉริยะ** (`document`) | สร้างและอัปเดตเอกสาร Markdown แบบถาวร |
| **ถามผู้ใช้** (`prompt_user`) | ขอข้อมูลจากคุณผ่านฟอร์มในแชท |
| **เอเจนต์ย่อย** (`spawn_sub_agent`) | มอบหมายงานให้เวิร์กเกอร์เบื้องหลัง |
| **เวิร์กสเปซ** (`workspace`) | ทำงานกับไฟล์และรีโพสิทอรี GitHub |
| **ดึงข้อมูลเว็บ** (`web_fetch`) | อ่านหน้าเว็บสาธารณะ |
| **ทักษะ** (`get_skill`, `manage_skill`) | อ่านและจัดการทักษะ |

เปิด [การตั้งค่า](app:openSettingsPageView) → **สิทธิ์ของเครื่องมือ** เพื่อดูเครื่องมือทั้งหมด แหล่งที่มา และสิทธิ์ของแต่ละตัว

## แคชเนื้อหาขนาดใหญ่ {#feature-caching}

เมื่อผลลัพธ์ของเครื่องมือมีขนาดใหญ่เกินไปสำหรับการสนทนา (เกิน 4K โทเค็นโดยค่าเริ่มต้น) AppAgent จะเก็บไว้ในแคช เอเจนต์จะได้รับโครงร่าง แล้วอ่าน ค้นหา หรือเรียกดูเฉพาะส่วนที่ต้องการ ช่วยให้แชทรวดเร็วและตรงประเด็น เปลี่ยนเกณฑ์ (1K ถึง 100K โทเค็น) ได้ใน [การตั้งค่า](app:openSettingsPageView) → **แคชเนื้อหาขนาดใหญ่**

## ตัวบ่งชี้บริบท {#feature-saturation}

**ตัวบ่งชี้บริบท** ข้างช่องป้อนข้อความแสดงว่าการสนทนาเต็มแค่ไหน เมื่อเกิน 50% เอเจนต์จะถูกขอให้สรุปงานและส่งงานหนักที่เหลือให้เอเจนต์ย่อย เมื่อถึง 100% เอเจนต์จะหยุดและรายงานผล คลิกตัวบ่งชี้ได้ทุกเมื่อเพื่อสรุปการสนทนาไปยังแชทใหม่

## การใช้งานและขีดจำกัดอัตรา {#feature-usage}

- **ปุ่มการใช้งาน** — ส่วนหัวแสดงการใช้ API และขีดจำกัดที่เหลืออยู่ คลิกเพื่อดูรายละเอียด
- **ลองใหม่อัตโนมัติ** — เมื่อผู้ให้บริการจำกัดอัตราหรือทำงานหนักเกินไป (HTTP 429 / 529) AppAgent จะรอและลองใหม่โดยอัตโนมัติ พร้อมแสดงการนับถอยหลังในแชท
- **เครดิตหมด** — เมื่อข้อผิดพลาด 429 หมายถึงเครดิตของคุณหมดจริงๆ แชทจะแจ้งอย่างชัดเจน

## ภาษา {#feature-languages}

อินเทอร์เฟซพร้อมใช้งานในภาษาอังกฤษและอีก 24 ภาษา ได้แก่ อาหรับ จีน (ตัวย่อ ตัวเต็ม) เช็ก เดนมาร์ก ดัตช์ ฟินแลนด์ ฝรั่งเศส (ฝรั่งเศส แคนาดา) เยอรมัน ฮีบรู ฮังการี อิตาลี ญี่ปุ่น เกาหลี นอร์เวย์ โปแลนด์ โปรตุเกส (บราซิล โปรตุเกส) รัสเซีย สเปน สวีเดน ไทย และตุรกี

เลือกภาษาได้ใน [การตั้งค่า](app:openSettingsPageView) → **ภาษา** หรือจากเมนูการตั้งค่าด่วนในส่วนหัว **อัตโนมัติ** จะใช้ภาษาของเบราว์เซอร์และใช้ภาษาอังกฤษเป็นค่าสำรอง การเปลี่ยนแปลงมีผลทันทีโดยไม่ต้องโหลดใหม่

- **ขวาไปซ้าย** — ภาษาอาหรับและฮีบรูใช้เลย์เอาต์จากขวาไปซ้าย
- **รูปแบบท้องถิ่น** — วันที่ เวลา และตัวเลขจะแสดงตามภาษาของคุณ
- **คำตอบของเอเจนต์** — เอเจนต์ตอบเป็นภาษาที่เลือก เว้นแต่คุณจะเขียนเป็นภาษาอื่น โค้ด ชื่อตาราง และชื่อฟิลด์จะไม่เปลี่ยนแปลง
- **หน้าวิธีใช้นี้** — แสดงเป็นภาษาของคุณ ส่วนบันทึกการเปลี่ยนแปลงยังคงเป็นภาษาอังกฤษ

- **ระดับโมเดลของเอเจนต์ย่อย** — กำหนดโมเดลให้ระดับเล็ก กลาง และใหญ่ หรือ **เหมือนเดิม**

- **Hooks** — ตั้งชื่อแชทอัตโนมัติ การแจ้งเตือน "เอเจนต์ทำงานเสร็จแล้ว" และระบบอัตโนมัติอื่นๆ

# การแก้ไขปัญหาและคำถามที่พบบ่อย {#faq}

### เอเจนต์มองไม่เห็นอินสแตนซ์ของฉัน

เปิดอินสแตนซ์ในแท็บของโปรไฟล์ Chrome เดียวกันและตรวจสอบว่าคุณลงชื่อเข้าใช้แล้ว จากนั้นพิมพ์ *"แสดงรายการอินสแตนซ์"* หากยังไม่ปรากฏ ให้โหลดแท็บอินสแตนซ์ใหม่

### ฉันได้รับข้อผิดพลาดเกี่ยวกับ API หรือการยืนยันตัวตน

ตรวจสอบผู้ให้บริการของคุณใน [การตั้งค่า](app:openSettingsPageView) → **ผู้ให้บริการ API**: คีย์ API เอนด์พอยต์ที่เลือก และชื่อโมเดล สำหรับ OAuth ให้ลงชื่อเข้าใช้ claude.ai อีกครั้งในโปรไฟล์ Chrome เดียวกัน

### เอเจนต์แจ้งว่าถูกจำกัดอัตรา

AppAgent จะลองใหม่โดยอัตโนมัติและแสดงการนับถอยหลัง หากยังเกิดขึ้นอยู่เรื่อยๆ ให้ตรวจสอบเครดิตที่เหลือจากปุ่มการใช้งาน หรือใช้ระดับโมเดลที่เล็กลงสำหรับเอเจนต์ย่อย

### มีข้อความขออนุมัติมากเกินไป หรือน้อยเกินไป

เปลี่ยนระดับสิทธิ์ของอินสแตนซ์ (**ด้วยตนเอง** **อัตโนมัติ** **นักพัฒนา**) จากเมนูดรอปดาวน์ของอินสแตนซ์ และปรับเครื่องมือแต่ละตัวใน [การตั้งค่า](app:openSettingsPageView) → **สิทธิ์ของเครื่องมือ**

### คำตอบช้าลงหรือแม่นยำน้อยลงในแชทที่ยาว

การสนทนากำลังใช้บริบทจนใกล้เต็ม คลิกตัวบ่งชี้บริบทเพื่อทำงานต่อในแชทใหม่พร้อมสรุป

### ฉันจะเลิกทำการเปลี่ยนแปลงได้อย่างไร

เปิดแถบด้านข้างของแชทแล้วคลิก **เลิกทำ** ที่การเปลี่ยนแปลงในประวัติเวอร์ชัน **ดาวน์โหลด XML** จะส่งออกการเปลี่ยนแปลงทั้งหมด

### ข้อมูลของฉันถูกเก็บไว้ที่ไหน

เก็บไว้ในเบราว์เซอร์ของคุณ (IndexedDB) แชทจะไม่ถูกส่งไปยังเซิร์ฟเวอร์ของ AppAgent เลย ส่งไปเฉพาะผู้ให้บริการ AI และอินสแตนซ์ ServiceNow ของคุณเท่านั้น ดู [การจัดเก็บข้อมูล](#adv-data-storage)

### อินเทอร์เฟซหรือหน้านี้แสดงผิดภาษา

เลือกภาษาใน [การตั้งค่า](app:openSettingsPageView) → **ภาษา** **อัตโนมัติ** จะใช้ภาษาของเบราว์เซอร์

# ขั้นสูง {#advanced}

ส่วนนี้ครอบคลุมฟีเจอร์ขั้นสูง ปุ่มในส่วนหัว รูปแบบการนำเข้า/ส่งออก และรายละเอียดทางเทคนิคเกี่ยวกับการทำงานของ AppAgent

## ปุ่มในส่วนหัวของแดชบอร์ด {#adv-dashboard-header}

ส่วนหัวของแดชบอร์ดมีปุ่มการดำเนินการหลายปุ่ม:

| ปุ่ม | คำอธิบาย |
|--------|-------------|
| **สลับแถบด้านข้าง** | แสดงหรือซ่อนแถบนำทางด้านซ้าย |
| **เปิดแบบแยกหน้าต่าง** | เปิดแดชบอร์ดในแท็บเบราว์เซอร์ใหม่เพื่อดูแบบแยก |
| **ส่วนหัว** | สลับการแสดงส่วนหัวของวิดเจ็ตบนแดชบอร์ด เมื่อซ่อนไว้ วิดเจ็ตจะแสดงในมุมมองที่สะอาดตาขึ้น |
| **สร้างใหม่ทั้งหมด** | ให้เอเจนต์สร้างวิดเจ็ตทั้งหมดบนแดชบอร์ดใหม่ มีประโยชน์สำหรับการรีเฟรชข้อมูล |
| **นำเข้า** | นำเข้าแดชบอร์ดหรือวิดเจ็ตจากไฟล์ JSON |
| **ส่งออก** | ส่งออกแดชบอร์ดทั้งหมดเป็นไฟล์ JSON เพื่อสำรองหรือแชร์ |
| **เพิ่มวิดเจ็ต** | เปิดตัวแก้ไขวิดเจ็ตเพื่อสร้างวิดเจ็ตใหม่โดยมีเอเจนต์ช่วย |

## ปุ่มในส่วนหัวของวิดเจ็ต {#adv-widget-headers}

**ส่วนหัวของวิดเจ็ตบนแดชบอร์ด** (มองเห็นได้เมื่อเปิดสวิตช์ส่วนหัว):

| ปุ่ม | คำอธิบาย |
|--------|-------------|
| **จุดจับสำหรับลาก** | ไอคอนวิดเจ็ตทำหน้าที่เป็นจุดจับสำหรับลากเพื่อจัดลำดับวิดเจ็ตใหม่ |
| **สร้างใหม่** | ขอให้เอเจนต์สร้างเนื้อหาของวิดเจ็ตนี้ใหม่ |
| **ประวัติ** | ดูเวอร์ชันก่อนหน้าของวิดเจ็ตนี้ (ถ้ามี) |
| **เต็มหน้าจอ** | ขยายวิดเจ็ตเป็นมุมมองเต็มหน้าจอ |
| **แก้ไข** | เปิดตัวแก้ไขวิดเจ็ตเพื่อปรับแก้ผ่านแชทกับเอเจนต์ |
| **ลบ** | นำวิดเจ็ตออกจากแดชบอร์ด (มีการยืนยัน) |

**ส่วนหัวของวิดเจ็ตในแชท** (วิดเจ็ตที่แสดงในแชท):

| ปุ่ม | คำอธิบาย |
|--------|-------------|
| **ปักหมุดที่แดชบอร์ด** | บันทึกวิดเจ็ตนี้ลงในแดชบอร์ดของคุณ |
| **แก้ไขโค้ด** | ดูและแก้ไขโค้ด HTML/CSS/JS ของวิดเจ็ตโดยตรง |
| **ขยาย/ยุบ** | สลับการแสดงเนื้อหาของวิดเจ็ต |

## ปรับขนาดและย้ายวิดเจ็ต {#adv-resize-move}

**การปรับขนาดวิดเจ็ต:**

- วิดเจ็ตแต่ละตัวมี **จุดจับปรับขนาด** ที่มุมขวาล่าง
- คลิกแล้วลากจุดจับเพื่อปรับขนาดวิดเจ็ต
- ความกว้างจะจัดให้พอดีกับกริด 12 คอลัมน์ (อย่างน้อย 3 คอลัมน์)
- ความสูงวัดเป็นหน่วยละ 50px (อย่างน้อย 2 หน่วย = 100px)

**การย้ายวิดเจ็ต:**

- เปิดสวิตช์ **ส่วนหัว** เพื่อแสดงส่วนหัวของวิดเจ็ต
- คลิกแล้วลาก **ไอคอนวิดเจ็ต** (จุดจับสำหรับลาก) เพื่อจัดลำดับใหม่
- วางวิดเจ็ตลงบนวิดเจ็ตอื่นเพื่อสลับตำแหน่ง
- ลำดับวิดเจ็ตจะถูกบันทึกโดยอัตโนมัติ

## รูปแบบการนำเข้า/ส่งออก {#adv-import-export}

**การส่งออกแดชบอร์ด** (`dashboard-YYYY-MM-DD.json`):

```
{
  "type": "appagent-dashboard",
  "version": 1,
  "widgets": [
    {
      "id": "widget_123",
      "title": "Widget Title",
      "html": "<html>...</html>",
      "width": 6,
      "height": 8,
      "order": 0,
      "conversation": [...]
    }
  ]
}
```

**การส่งออกวิดเจ็ตเดียว:**

```
{
  "type": "appagent-dashboard-widget",
  "version": 1,
  "widget": { ... }
}
```

**การส่งออกแชทเดียว** (`chat-title-YYYY-MM-DD.json`):

```
{
  "exportType": "single_chat",
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chat": {
    "id": "chat_123",
    "title": "Chat Title",
    "messages": [
      {
        "role": "user",
        "content": "User message text"
      },
      {
        "role": "assistant",
        "content": "Agent response text"
      }
    ],
    "createdAt": 1705312200000
  }
}
```

การส่งออกแชทจะเก็บประวัติการสนทนาทั้งหมด รวมถึงข้อความของผู้ใช้และคำตอบของเอเจนต์ทุกข้อความ ใช้เมนูดรอปดาวน์ของแชท (···) แล้วเลือก **ดาวน์โหลด** เพื่อส่งออกแชทแต่ละรายการ

**การส่งออกทักษะ** (โครงสร้างโฟลเดอร์):

```
skill-name/
├── SKILL.md      # Main skill definition
├── sample.xml    # Optional XML assets
├── helper.js     # Optional JS assets
└── notes.md      # Optional MD assets
```

:::tip
**หมายเหตุ:** การนำเข้า/ส่งออกทักษะใช้ File System Access API และ **ใช้ได้เฉพาะในเบราว์เซอร์ Chrome หรือ Edge** เท่านั้น
:::

**การส่งออกข้อมูลทั้งหมด** (`appagent-backup-YYYY-MM-DD.json`):

```
{
  "version": 3,
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chats": [...],
  "settings": [...],
  "dashboardWidgets": [...],
  "apiProviders": [...]
}
```

ข้อมูลสำรองแบบเต็มประกอบด้วยประวัติแชททั้งหมด การตั้งค่า สิทธิ์ของเครื่องมือ วิดเจ็ตบนแดชบอร์ด และการกำหนดค่าผู้ให้บริการ API

## สถิติ API {#adv-api-stats}

เมื่อเปิดใช้งานในการตั้งค่า สถิติ API จะแสดงหลังคำตอบแต่ละครั้งของเอเจนต์:

| ตัวชี้วัด | คำอธิบาย |
|--------|-------------|
| **เข้า** | โทเค็นขาเข้า — ขนาดของพรอมต์ที่ส่งไปยังเอเจนต์ |
| **ออก** | โทเค็นขาออก — ขนาดของคำตอบจากเอเจนต์ |
| **รวม** | โทเค็นขาเข้า + ขาออกรวมกัน |
| **อ่าน/เขียนแคช** | โทเค็นที่อ่านจากหรือเขียนลงในแคชพรอมต์ (ช่วยลดค่าใช้จ่าย) |
| **การให้เหตุผล** | โทเค็นที่ใช้สำหรับการให้เหตุผลภายใน (บางโมเดล) |
| **ค่าใช้จ่าย** | ค่าใช้จ่ายโดยประมาณของการเรียก API เป็น USD |
| **ระยะเวลา** | เวลาที่ใช้ในการเรียก API |

สำหรับการสนทนาหลายรอบ สถิติรวมจะแสดงยอดรวมของการเรียกทั้งหมด

:::tip
เปิดหรือปิดการแสดงสถิติ API ได้ใน [การตั้งค่า](app:openSettingsPageView) → การแสดงผล → แสดงสถิติ API
:::

## การแก้ไขทักษะด้วยตนเอง {#adv-skills-manual}

คุณสร้างและแก้ไขทักษะได้ด้วยตนเองหรือให้เอเจนต์ช่วย:

**การสร้างทักษะด้วยตนเอง:**

1. ไปที่ [ทักษะ](app:openSkillsView) แล้วคลิก **ทักษะใหม่**
2. ป้อนชื่อและคำอธิบายของทักษะ
3. เขียนเนื้อหาของทักษะในรูปแบบ Markdown
4. คลิก **บันทึก** เพื่อสร้างทักษะ

**รูปแบบ SKILL.md:**

```
# Skill Name

Description of what this skill does.

## Instructions

Detailed instructions for the Agent...

## Examples

- Example usage 1
- Example usage 2
```

**การแก้ไขด้วยเอเจนต์:**

1. คลิก **แก้ไขด้วยเอเจนต์** ที่ทักษะใดก็ได้
2. อธิบายการเปลี่ยนแปลงที่คุณต้องการ
3. เอเจนต์จะแก้ไขเนื้อหาของทักษะ
4. ตรวจทานและบันทึกการเปลี่ยนแปลง

**ไฟล์ประกอบของทักษะ:** ทักษะสามารถมีไฟล์เพิ่มเติม (XML, JS, MD) ที่ให้บริบทหรือโค้ดเพิ่มเติมแก่เอเจนต์

## พรอมต์ระบบ {#adv-system-prompt}

พรอมต์ระบบกำหนดพฤติกรรมและความสามารถของเอเจนต์ คุณปรับแต่งได้ใน [การตั้งค่า](app:openSettingsPageView)

**การแก้ไขพรอมต์ระบบ:**

1. ไปที่การตั้งค่า → ส่วนพรอมต์ระบบ
2. คลิก **แก้ไข** เพื่อเข้าสู่โหมดแก้ไข
3. ปรับเทมเพลตตามต้องการ
4. คลิก **บันทึก** เพื่อใช้การเปลี่ยนแปลง

**ตัวยึดตำแหน่งที่ใช้ได้:**

| ตัวยึดตำแหน่ง | คำอธิบาย |
|-------------|-------------|
| `{{CURRENT_DATE}}` | วันที่วันนี้ (วันในสัปดาห์ เดือน วัน ปี) |
| `{{ORCHESTRATOR_POLICY}}` | นโยบายการมอบหมายงานให้เอเจนต์ย่อย — ใส่ไว้ในแชทหลัก และเว้นว่างในแชทของเอเจนต์ย่อย |
| `{{DISABLED_TOOLS}}` | รายการเครื่องมือที่ถูกปิดใช้งาน |
| `{{TOOL_CATALOG}}` | แคตตาล็อกเครื่องมือแบบโหลดภายหลัง (ว่างเมื่อปิดการโหลดเครื่องมือภายหลัง) |
| `{{SKILLS_SUMMARY}}` | เนื้อหาของทักษะที่เปิดใช้งานอยู่ |

ตัวยึดตำแหน่งจะถูกแทนที่ด้วยค่าจริงโดยอัตโนมัติเมื่อส่งไปยัง AI ตัวแสดงจำนวนโทเค็นจะแสดงทั้งขนาดของเทมเพลตและขนาดหลังแทนค่าแล้ว

:::tip
คลิก **คืนค่าเริ่มต้น** เพื่อกู้คืนพรอมต์ระบบเดิมหากจำเป็น
:::

## การเรียก API ของเอเจนต์ {#adv-agent-api}

AppAgent ทำงานเป็น **ส่วนขยายของ Chrome**:

- การเรียก AI API จะส่ง **ตรงจากเบราว์เซอร์ของคุณไปยังผู้ให้บริการ AI** (เช่น Anthropic, OpenRouter)
- การเรียกเหล่านี้ **ไม่** ผ่านอินสแตนซ์ของคุณหรือเซิร์ฟเวอร์ใดๆ ของ AppAgent
- คีย์ API (หรือโทเค็น OAuth) ของคุณถูกเก็บไว้ในเบราว์เซอร์ของคุณ
- ข้อมูลการสนทนาจะถูกส่งไปยังผู้ให้บริการ AI เพื่อประมวลผล

**วิธีการทำงาน:**

1. คุณพิมพ์ข้อความในแชท
2. AppAgent สร้างพรอมต์ที่มีคำสั่งระบบ เครื่องมือ และประวัติการสนทนา
3. พรอมต์ถูกส่งไปยัง API ของผู้ให้บริการ AI
4. คำตอบของเอเจนต์จะสตรีมกลับมายังเบราว์เซอร์ของคุณ
5. การเรียกเครื่องมือจะทำงานในเบราว์เซอร์ของคุณ โดยใช้เซสชันอินสแตนซ์ของคุณสำหรับการเรียก API

:::tip
**ความเป็นส่วนตัว:** คีย์ API และข้อมูลการสนทนาของคุณได้รับการจัดการฝั่งไคลเอนต์ การเรียกเครื่องมือที่โต้ตอบกับอินสแตนซ์ของคุณจะใช้ข้อมูลรับรองเซสชันที่คุณมีอยู่
:::

## เอนด์พอยต์ LLM {#adv-endpoints}

โมเดลเชื่อมต่อผ่าน **เอนด์พอยต์ LLM ที่ตั้งชื่อไว้** ซึ่งเป็นคู่ `URL + API key` ที่นำกลับมาใช้ซ้ำได้ ทำให้คุณชี้ AppAgent ไปยัง **API แบบ chat-completions ใดก็ได้ที่เข้ากันได้กับ OpenAI**: OpenRouter, เกตเวย์ในเครื่อง, พร็อกซี หรือโมเดลที่คุณโฮสต์เอง

1. ใน [การตั้งค่า → เอนด์พอยต์ LLM](app:openSettingsPageView) คลิก **เพิ่มเอนด์พอยต์**
2. ตั้งชื่อ ใส่ URL ของ API และคีย์ API
3. แต่ละโมเดล (ผู้ให้บริการ API) จะเลือกเอนด์พอยต์หนึ่งรายการ อัปเดตคีย์เพียงครั้งเดียว ทุกโมเดลที่ใช้เอนด์พอยต์นั้นก็จะอัปเดตตาม

:::tip
ผู้ให้บริการ Claude แบบ **OAuth** ไม่ใช้เอนด์พอยต์ แต่เชื่อมต่อกับ `api.anthropic.com` โดยตรง
:::

## ลงชื่อเข้าใช้ด้วย Claude (OAuth) {#adv-oauth}

แทนที่จะวางคีย์ API คุณสามารถลงชื่อเข้าใช้ผู้ให้บริการ Anthropic ด้วยเซสชัน claude.ai ที่มีอยู่:

1. ใน [การตั้งค่า → ผู้ให้บริการ API](app:openSettingsPageView) เพิ่มหรือแก้ไขผู้ให้บริการ Anthropic แล้วเปิดใช้ **OAuth**
2. ส่วนขยายจะใช้การลงชื่อเข้าใช้ claude.ai จากโปรไฟล์ Chrome เดียวกันเพื่อเชื่อมต่อกับ Anthropic โดยตรง
3. ไม่มีหน้าต่างลงชื่อเข้าใช้เพิ่มเติม และไม่มีเซิร์ฟเวอร์ของ AppAgent อยู่ตรงกลาง

**ข้อกำหนด:**

- คุณต้องลงชื่อเข้าใช้ `claude.ai` ในโปรไฟล์ Chrome เดียวกัน
- ใช้ได้กับบัญชีแบบลงชื่อเข้าใช้ครั้งเดียว (SSO)

:::tip
โทเค็น OAuth จะรีเฟรชโดยอัตโนมัติ หากลงชื่อเข้าใช้ไม่สำเร็จ ให้เปิด `claude.ai` ในโปรไฟล์เดียวกันแล้วลงชื่อเข้าใช้อีกครั้ง
:::

## ข้อควรพิจารณาด้านความปลอดภัย {#adv-security}

**การจัดเก็บคีย์ API:**

- **คีย์ API ของคุณถูกเก็บไว้ในเครื่อง** ใน IndexedDB ของเบราว์เซอร์
- คีย์จะไม่ถูกส่งไปยังอินสแตนซ์ของคุณหรือเซิร์ฟเวอร์ใดๆ นอกจากผู้ให้บริการ AI
- การล้างข้อมูลเบราว์เซอร์จะลบคีย์ API ที่เก็บไว้

**เซสชันและสิทธิ์:**

- เอเจนต์ทำงานด้วย **เซสชันผู้ใช้ปัจจุบันของคุณ** โดยสืบทอดสิทธิ์การเข้าถึงและบทบาทของคุณ
- การเรียก API ทั้งหมดไปยังอินสแตนซ์ของคุณใช้ข้อมูลรับรองเซสชันของคุณ
- เอเจนต์เข้าถึงได้เฉพาะสิ่งที่บัญชีผู้ใช้ของคุณเข้าถึงได้

**สภาพแวดล้อมการรันเครื่องมือ:**

- **โค้ดเบราว์เซอร์ (js_eval)** รัน JavaScript ใน **แซนด์บ็อกซ์แยก** ที่เข้าถึงได้เฉพาะ `executeTool()`
- **สคริปต์ของวิดเจ็ต** ทำงานใน **iframe แยก** ที่เข้าถึงได้เฉพาะ `executeTool()` สำหรับการเรียก API
- **เครื่องมือของทักษะ** ทำงานใน **แซนด์บ็อกซ์แยก** ที่เข้าถึงได้เฉพาะ `executeTool()`
- การเข้าถึง API ทั้งหมดต้องผ่าน **ระบบสิทธิ์** ผ่าน `executeTool("servicenow_api", {...})`
- เอเจนต์โต้ตอบกับหน้าต่างๆ ใน **แท็บเบราว์เซอร์** บนอินสแตนซ์ ServiceNow ของคุณ

**ความสามารถในการแก้ไขเรกคอร์ด:**

- เครื่องมือ **ServiceNow API** รองรับเมธอด POST, PATCH, PUT และ DELETE ที่เปลี่ยนแปลงเรกคอร์ดได้
- เอเจนต์สร้างและแก้ไขเรกคอร์ดผ่าน **เบราว์เซอร์ในตัว** ได้ หากได้รับสิทธิ์สำหรับเครื่องมือกรอกและคลิก
- กำหนดค่า [สิทธิ์ของเครื่องมือ](app:openSettingsPageView) เพื่อควบคุมว่าการดำเนินการใดต้องได้รับการอนุมัติ

**การพัฒนาตนเอง:**

- เอเจนต์สามารถ **จัดการทักษะของตัวเอง** ได้ ทั้งสร้าง แก้ไข และเปิดใช้งานทักษะ
- ทำให้เอเจนต์เรียนรู้และพัฒนาตัวเองได้เมื่อเวลาผ่านไป
- ตรวจทานการเปลี่ยนแปลงทักษะเป็นระยะเพื่อให้แน่ใจว่าตรงตามความคาดหวังของคุณ

## การจัดเก็บข้อมูล {#adv-data-storage}

AppAgent จัดเก็บข้อมูลไว้ในเบราว์เซอร์ของคุณโดยใช้ **IndexedDB**:

| ประเภทข้อมูล | ที่จัดเก็บ | คำอธิบาย |
|-----------|---------|-------------|
| **แชท** | IndexedDB | ประวัติการสนทนา ข้อความ และผลลัพธ์ของเครื่องมือทั้งหมด |
| **การตั้งค่า** | IndexedDB | สิทธิ์ของเครื่องมือ คีย์ API และค่ากำหนดของโมเดล |
| **วิดเจ็ตบนแดชบอร์ด** | IndexedDB | HTML ของวิดเจ็ต ชื่อ ขนาด และประวัติการสนทนา |
| **ทักษะ** | IndexedDB | คำจำกัดความ เนื้อหา และไฟล์ประกอบของทักษะ |
| **ผู้ให้บริการ API** | IndexedDB | การกำหนดค่าผู้ให้บริการ API แบบกำหนดเองและเอนด์พอยต์ |
| **สถานะ UI** | localStorage | สถานะแถบด้านข้าง มุมมองปัจจุบัน และตำแหน่งการเลื่อน |

**การดาวน์โหลดข้อมูลของคุณ:**

1. ไปที่ [การตั้งค่า](app:openSettingsPageView) → การจัดการข้อมูล
2. คลิก **ส่งออกข้อมูล**
3. ไฟล์สำรอง JSON จะถูกดาวน์โหลด

**การลบข้อมูลของคุณ:**

1. ไปที่ [การตั้งค่า](app:openSettingsPageView) → การจัดการข้อมูล
2. คลิก **ลบข้อมูลทั้งหมด**
3. ยืนยันสองครั้งเพื่อลบทุกอย่างอย่างถาวร

:::tip
**สำคัญ:** ข้อมูลถูกจัดเก็บไว้ในส่วนขยายภายในเครื่อง การล้างข้อมูลเบราว์เซอร์ การถอนการติดตั้งส่วนขยาย หรือการใช้โปรไฟล์เบราว์เซอร์อื่น จะทำให้มีที่จัดเก็บข้อมูลแยกจากกัน
:::
