# תחילת העבודה {#getting-started}

AppAgent הוא סוכן AI עבור ServiceNow שפועל כתוסף ל-Chrome. תארו במילים פשוטות מה אתם צריכים, והסוכן ישלוף נתונים, יערוך רשומות, יבנה אפליקציות ווידג'טים, יבדוק דפים בדפדפן שלכם וידווח לכם בחזרה.

:::tip
**התחלה מהירה:** הגדירו מודל, פתחו לשונית במופע ה-ServiceNow שלכם, ואז הקלידו בקשה בצ'אט והקישו <kbd>Enter</kbd>.
:::

## הגדרת מודל {#guide-setup}

1. פתחו את [הגדרות](app:openSettingsPageView) ועברו אל **ספקי API**
2. הוסיפו ספק (Anthropic, OpenRouter או API מותאם אישית התואם ל-OpenAI) עם מפתח ה-API שלכם — או הפעילו **OAuth** בספק Anthropic כדי להתחבר עם חשבון ה-Claude שלכם
3. בחרו את המודל לשימוש תחת **מודל הסוכן**

מפתח ה-API שלכם נשמר רק בדפדפן שלכם. קריאות ה-AI נשלחות ישירות מהדפדפן שלכם אל הספק.

## חיבור המופעים שלכם {#guide-instances}

AppAgent **מזהה אוטומטית כל מופע ServiceNow** שפתוח אצלכם באותו פרופיל Chrome — אין צורך להזין מחרוזת חיבור. התחברו למופע בלשונית רגילה, והסוכן יוכל לעבוד עליו עם התפקידים וההרשאות של המשתמש שלכם. בקשו *"הצג את רשימת המופעים"* כדי לראות את כל המופעים שזוהו, את התפקידים שלכם ואת מצב החיבור.

לכל מופע יש **רמת הרשאה**, שנבחרת מהתפריט הנפתח של המופע:

- **ידני** — אתם מאשרים כל פעולת כתיבה (יצירה, עדכון, מחיקה, מילוי טפסים)
- **אוטומטי** — הסוכן מחליט על פעולות כתיבה בלי לשאול
- **פיתוח** — ללא אישורים בכלל: כל קריאה לכלי במופע הזה רצה בלי לשאול. השתמשו בה רק במופעי פיתוח

פעולות קריאה מותרות תמיד. לשליטה מדויקת יותר, ראו [הרשאות כלים](#feature-permissions).

## פתיחת צ'אט {#guide-chat}

1. לחצו על **צ'אט חדש** בסרגל הצד [פתיחת צ'אט חדש ←](app:startNewChat)
2. הקלידו את הבקשה שלכם, למשל *"הצג לי את כל התקלות שנפתחו היום"*
3. הקישו <kbd>Enter</kbd> כדי לשלוח
4. עקבו אחרי הסוכן בזמן שהוא עובד: כל קריאה לכלי מופיעה בצ'אט, ובקשות אישור מופיעות כששלב מסוים דורש את האישור שלכם

אפשר להמשיך להקליד בזמן שהסוכן עובד: שליחת הודעה חדשה קוטעת את השלב הנוכחי, ו-**השהיה** עוצרת את הריצה.

## צירוף תמונות וקבצים {#guide-images}

1. לחצו על הכפתור **צירוף קובץ** באזור ההקלדה כדי להוסיף תמונה, PDF, קובץ CSV או קובץ טקסט
2. לחלופין, הדביקו תמונה מהלוח או גררו ושחררו אותה אל הצ'אט
3. הקלידו את השאלה שלכם לגבי הקובץ המצורף

:::tip
צרפו צילומי מסך של שגיאות, סקיצות של ממשק או נתונים מיוצאים, כדי שהסוכן יראה בדיוק את מה שאתם רואים.
:::

# תכונות עיקריות {#features}

## צ'אט {#page-chat}

תצוגת השיחה הראשית. [פתיחת צ'אט חדש ←](app:startNewChat)

- **אזור ההודעות** — השיחה, כולל קריאות לכלים והתוצאות שלהן
- **תיבת ההקלדה** — הקלדת הודעות; צירוף קבצים; שליחה בזמן שהסוכן עובד כדי לקטוע אותו
- **השהיה / המשך / ניסיון חוזר** — עצירת הסוכן, חידוש העבודה או ניסיון חוזר של השלב האחרון
- **מחוון ההקשר** — מראה עד כמה השיחה מלאה; לחיצה עליו מסכמת אותה לצ'אט חדש
- **כרטיסי תשובה** — כרטיס **תקציר** וכרטיס **קישורים** (רשומות, בקשות משיכה, מסמכים) יכולים להופיע מתחת לתשובה
- **כותרת הצ'אט** — שינוי שם הצ'אט או הצמדתו, או פתיחת AppAgent בלשונית דפדפן מלאה באמצעות **הרחבה לדף מלא**

## שליטה בדפדפן {#feature-browser}

הסוכן יכול לפתוח לשוניות דפדפן במופע שלכם ולשלוט בהן כדי לראות ולבדוק דפים:

- **ניווט, לחיצה, מילוי ובחירה** — אירועים מציאותיים, כך שטפסים ושדות השלמה אוטומטית מתנהגים כאילו הקלדתם בעצמכם
- **המתנה** — המתנה לרכיב, לטקסט או לכתובת URL במקום לנחש זמני השהיה
- **צילומי מסך** — צילום הדף, וידג'ט או רכיב בודד לבדיקות חזותיות
- **בדיקה** — קריאת מאפיינים וסגנונות של רכיבים, שגיאות במסוף ובקשות רשת
- **התחזות** — בדיקה בתור משתמש אחר, ולאחר מכן חזרה למשתמש שלכם

## עריכת רשומות והיסטוריית גרסאות {#feature-history}

כל שינוי שהסוכן מבצע במופע שלכם מתועד בסרגל הצד של הצ'אט:

- **ביטול** — ביטול של שינוי בודד
- **ביצוע מחדש** — שחזור של שינוי שבוטל
- **הורדת XML** — ייצוא כל השינויים, למשל כדי להעביר אותם למופע אחר

## סוכני משנה {#feature-subagents}

לעבודה כבדה או מקבילית, הסוכן יכול להפעיל **סוכני משנה**: עובדי רקע שרצים בצ'אט ובהקשר משלהם, ואז מדווחים תוצאה קצרה בחזרה לצ'אט הראשי.

- **רמות מודלים** — כל סוכן משנה רץ ברמה **קטנה**, **בינונית** או **גדולה**, או ברמה **זהה** כדי להשתמש במודל של הצ'אט הראשי. שייכו רמות למודלים ב[הגדרות](app:openSettingsPageView) ← **רמות מודלים לסוכני משנה**
- **רצועת העובדים** — סוכני משנה פעילים מופיעים כתגיות חיות מעל תיבת ההקלדה; פתחו אחד מהם כדי לעקוב אחר ההתקדמות שלו או לקרוא את התמליל שלו
- **מאגר** — מספר סוכני המשנה שרצים במקביל מוגבל; הנוספים ממתינים בתור

## לוח בקרה ווידג'טים {#page-dashboard}

לוח בקרה של וידג'טים אינטראקטיביים שהסוכן יוצר. [פתיחת לוח הבקרה ←](app:openDashboardView)

1. לחצו על **הוספת וידג'ט**
2. תארו מה אתם רוצים, למשל *"תרשים של תקלות פתוחות לפי עדיפות"*
3. הסוכן בונה את הווידג'ט; בקשו שינויים או לחצו על **יצירה מחדש** בכל עת

וידג'טים יכולים לשלוף נתונים חיים מהמופע שלכם, כך שהם תמיד מעודכנים. אפשר לגרור אותם, לשנות את גודלם, לייבא ולייצא אותם (ראו [מתקדם](#advanced)). וידג'טים שהסוכן מציג בתוך הצ'אט אפשר לשמור באמצעות **הצמדה ללוח הבקרה**.

## מסמכים חכמים {#page-documents}

**מסמכים חכמים** הם מסמכי Markdown קבועים עם ניהול גרסאות, שהסוכן כותב ומעדכן — תוכניות, דוחות, אפיונים, ממצאים. הם מוצגים בתוך הצ'אט, שומרים כל גרסה, ואתם יכולים לערוך אותם ישירות. פתחו אותם מ-**מסמכים** בסרגל הצד. [פתיחת המסמכים ←](app:openDocumentsView)

## מיומנויות {#page-skills}

מיומנויות מעניקות לסוכן ידע וכלים נוספים. [פתיחת המיומנויות ←](app:openSkillsView)

- **הפעלה / השבתה** — הפעלה או כיבוי של מיומנויות; השביתו את אלה שאינכם צריכים כדי לשמור על תשובות ממוקדות
- **מיומנות חדשה** — כתבו מיומנות משלכם ב-Markdown, או השתמשו ב-**עריכה עם הסוכן**
- **ייבוא / ייצוא** — שיתוף מיומנויות כתיקיות
- **פעולות מיומנות** — חלק מהמיומנויות מוסיפות לדף הבית כפתורים שמפעילים בלחיצה אחת תהליך עבודה מוגדר מראש

מיומנות יכולה לספק **ידע** (הנחיות, שיטות עבודה מומלצות) ו-**כלים מותאמים אישית** (פונקציות JavaScript שרצות בארגז חול מבודד).

## סביבת עבודה ו-GitHub {#feature-workspace}

לכל צ'אט יש **סביבת עבודה** — אזור קבצים שבו הסוכן יכול לקרוא, לכתוב, לערוך ולהשוות קבצים.

- **GitHub** — חברו חשבון GitHub ב[הגדרות](app:openSettingsPageView) כדי לשכפל מאגרים לסביבת עבודה. הסוכן יכול ליצור ענפים, לדחוף קומיטים ולפתוח בקשות משיכה ישירות מהצ'אט
- **בקשות משיכה** — בקשות משיכה שנפתחו מצ'אט מופיעות בסרגל הצד של הצ'אט, עם כפתור **מיזוג**
- **הגנה בין צ'אטים** — כל קובץ זוכר איזה צ'אט שינה אותו, כך ששני צ'אטים שעובדים במקביל לא דורסים בשקט זה את העבודה של זה
- **סנכרון אוטומטי** — סביבות עבודה משוכפלות מסתנכרנות עם GitHub כשאתם מנווטים, עוברים בין צ'אטים או חוזרים ללשונית

## סרגל הצד של הצ'אט {#feature-sidebar}

סרגל הצד הימני מרכז את כל מה שהצ'אט הנוכחי הפיק:

- **בקשות משיכה** — כותרת, ענף היעד וכפתור **מיזוג**
- **קבצי סביבת העבודה** — פתחו קובץ כדי לצפות בו, לראות את ההבדלים שלו או לעיין בגרסאות קודמות
- **היסטוריית גרסאות** — שינויים במופע, עם **ביטול**, **ביצוע מחדש** ו-**הורדת XML**
- **עובדים** — סוכני משנה פעילים ושהסתיימו, עם מונים של קריאות לכלים, קבצים שנערכו ובקשות משיכה שנפתחו

## פעולות והתקדמות חיה {#feature-actions}

משימות ארוכות מציגות התקדמות חיה במקום לשתוק:

- **כרטיס התקדמות** — כרטיס יחיד עם מצב צבעוני (בריצה, תקוע, הסתיים, שגיאה) ורשימת שלבים
- **כפתורי פעולה** — כפתורים שמפעילים בלחיצה אחת תהליכי המשך
- **מחוון ריצה** — רשימת הצ'אטים מסמנת צ'אטים שבהם הסוכן עובד
- **התראת "הסוכן סיים"** — אם עברתם ללשונית או לחלון אחרים במהלך ריצה, התראה בשולחן העבודה תודיע לכם כשהסוכן יסיים

## צ'אטים פעילים ומשימות {#feature-jobs}

תגית המשימות בכותרת פותחת תצוגה חיה של הצ'אטים ושל העבודה ברקע:

- **צ'אטים פעילים** — צ'אטים בריצה וצ'אטים עם תוצאות שלא נקראו (מוצגים ב**הדגשה**), כל אחד עם טבעת של ניצול ההקשר
- **סוכני משנה** — מופיעים תחת צ'אט האב שלהם; פתחו אחד מהם כדי לקרוא את התמליל שלו
- **הרחבה** — פתיחת הרשימה כחלונית גדולה יותר, בפריסת עמודות או מקטעים

## הרשאות כלים {#feature-permissions}

מלבד רמת ההרשאה של כל מופע (**ידני**, **אוטומטי**, **פיתוח**), לכל כלי יש הגדרה משלו ב[הגדרות](app:openSettingsPageView) ← **הרשאות כלים**:

- **אישור** — הכלי תמיד רץ בלי לשאול
- **אוטומטי** — הכלי רץ בלי לשאול, אלא אם הסוכן מסמן קריאה כזו שדורשת את האישור שלכם
- **לשאול** — תקבלו בקשת אישור לפני כל קריאה
- **כבוי** — הסוכן לא יכול להשתמש בכלי

לחלק מהכלים יש בקרות מדויקות יותר: ה-API של ServiceNow לפי שיטת HTTP (GET, POST, PUT, PATCH, DELETE), השליטה בדפדפן לפי פעולה (ניווט, לחיצה, מילוי, התחזות…), וניהול המיומנויות לפי פעולה. חלונות האישור מסומנים בצבע לפי רמת הסיכון: **כחול** (שגרתי), **כתום** (זהירות), **אדום** (הרסני).

:::tip
השאירו את DELETE ופעולות הרסניות אחרות על **לשאול**, והשתמשו ב-**פיתוח** רק במופעי פיתוח.
:::

## הכלים של הסוכן {#feature-tools}

הכלים העיקריים שהסוכן משתמש בהם:

| כלי | מה הוא עושה |
|------|--------------|
| **ServiceNow API** (`servicenow_api`) | קריאה, יצירה, עדכון ומחיקה של רשומות |
| **סקריפט רקע** (`servicenow_run_script`) | הרצת סקריפט בצד השרת במופע (דורש את תפקיד ה-admin) |
| **עריכות סקריפטים** (`servicenow_diff_edit`) | שינוי סקריפטים באמצעות עריכות חיפוש-והחלפה מדויקות |
| **שליטה בדפדפן** (`iframe_tool`) | ניווט, לחיצה, מילוי, בדיקה והתחזות בלשוניות הדפדפן |
| **קוד דפדפן** (`js_eval`) | הרצת JavaScript בארגז חול מבודד שיכול לקרוא לכלים אחרים |
| **צילומי מסך** (`take_screenshot`) | צילום הדף, וידג'ט או רכיב |
| **וידג'טים וכרטיסים** (`html_widget`, `display`) | הצגת וידג'טים אינטראקטיביים, טבלאות, כרטיסים וצירי זמן בצ'אט |
| **מסמכים חכמים** (`document`) | יצירה ועדכון של מסמכי Markdown קבועים |
| **שאלה למשתמש** (`prompt_user`) | בקשת קלט מכם באמצעות טופס בתוך הצ'אט |
| **סוכני משנה** (`spawn_sub_agent`) | האצלת עבודה לעובדי רקע |
| **סביבת עבודה** (`workspace`) | עבודה עם קבצים ועם מאגרי GitHub |
| **שליפה מהאינטרנט** (`web_fetch`) | קריאת דפים מהאינטרנט הציבורי |
| **מיומנויות** (`get_skill`, `manage_skill`) | קריאה וניהול של מיומנויות |

פתחו את [הגדרות](app:openSettingsPageView) ← **הרשאות כלים** כדי לראות כל כלי, את המקור שלו ואת ההרשאה שלו.

## שמירת תוכן גדול במטמון {#feature-caching}

כשתוצאה של כלי גדולה מדי עבור השיחה (יותר מ-4K טוקנים כברירת מחדל), AppAgent שומר אותה במטמון. הסוכן מקבל מתאר, ואז קורא, מחפש או מעיין רק בחלקים שהוא צריך. כך הצ'אטים נשארים מהירים וממוקדים. שנו את הסף (1K עד 100K טוקנים) ב[הגדרות](app:openSettingsPageView) ← **שמירת תוכן גדול במטמון**.

## מחוון ההקשר {#feature-saturation}

**מחוון ההקשר** שליד תיבת ההקלדה מראה עד כמה השיחה מלאה. מעבר ל-50%, הסוכן מתבקש לסכם ולהעביר את העבודה הכבדה שנותרה לסוכני משנה; ב-100% הוא עוצר ומדווח. לחצו על המחוון בכל עת כדי לסכם את השיחה לצ'אט חדש.

## שימוש ומגבלות קצב {#feature-usage}

- **תגית השימוש** — הכותרת מציגה את השימוש שלכם ב-API ואת המגבלות שנותרו; לחצו עליה לפרטים
- **ניסיונות חוזרים אוטומטיים** — כשהספק מגביל את הקצב או עמוס (HTTP 429 / 529), AppAgent ממתין ומנסה שוב אוטומטית, ומציג ספירה לאחור בצ'אט
- **נגמרו הקרדיטים** — כששגיאת 429 פירושה בפועל שהקרדיטים שלכם נוצלו עד תום, הצ'אט אומר זאת בבירור

## שפות {#feature-languages}

הממשק זמין באנגלית ובעוד 24 שפות: ערבית, סינית (מפושטת, מסורתית), צ'כית, דנית, הולנדית, פינית, צרפתית (צרפת, קנדה), גרמנית, עברית, הונגרית, איטלקית, יפנית, קוריאנית, נורווגית, פולנית, פורטוגזית (ברזיל, פורטוגל), רוסית, ספרדית, שוודית, תאית וטורקית.

בחרו שפה ב[הגדרות](app:openSettingsPageView) ← **שפה**, או מתפריט ההגדרות המהירות בכותרת. **אוטומטי** עוקב אחר שפת הדפדפן שלכם, ואם היא אינה זמינה – חוזר לאנגלית. השינוי חל מיד, בלי טעינה מחדש.

- **מימין לשמאל** — ערבית ועברית משתמשות בפריסה מימין לשמאל
- **תבניות מקומיות** — תאריכים, שעות ומספרים מוצגים לפי השפה שלכם
- **תשובות הסוכן** — הסוכן עונה בשפה שנבחרה, אלא אם אתם כותבים בשפה אחרת. קוד, שמות טבלאות ושמות שדות נשארים ללא שינוי
- **דף העזרה הזה** — מוצג בשפה שלכם; יומן השינויים נשאר באנגלית

# פתרון בעיות ושאלות נפוצות {#faq}

### הסוכן לא רואה את המופע שלי

פתחו את המופע בלשונית באותו פרופיל Chrome וודאו שאתם מחוברים, ואז בקשו *"הצג את רשימת המופעים"*. אם הוא עדיין לא מופיע, טענו מחדש את הלשונית של המופע.

### אני מקבל שגיאת API או שגיאת אימות

בדקו את הספק שלכם ב[הגדרות](app:openSettingsPageView) ← **ספקי API**: את מפתח ה-API, את נקודת הקצה שנבחרה ואת שם המודל. עבור OAuth, התחברו שוב ל-claude.ai באותו פרופיל Chrome.

### הסוכן אומר שהקצב שלו מוגבל

AppAgent מנסה שוב אוטומטית ומציג ספירה לאחור. אם זה ממשיך לקרות, בדקו בתגית השימוש כמה קרדיטים נותרו, או השתמשו ברמת מודל קטנה יותר עבור סוכני המשנה.

### יותר מדי בקשות אישור, או מעט מדי

שנו את רמת ההרשאה של המופע (**ידני**, **אוטומטי**, **פיתוח**) מהתפריט הנפתח של המופע, וכווננו כלים בודדים ב[הגדרות](app:openSettingsPageView) ← **הרשאות כלים**.

### בצ'אט ארוך התשובות נעשות איטיות או מדויקות פחות

השיחה ממלאת את ההקשר שלה. לחצו על מחוון ההקשר כדי להמשיך בצ'אט חדש עם סיכום.

### איך מבטלים שינוי?

פתחו את סרגל הצד של הצ'אט ולחצו על **ביטול** ליד השינוי בהיסטוריית הגרסאות. **הורדת XML** מייצאת את כל השינויים.

### איפה הנתונים שלי נשמרים?

באופן מקומי בדפדפן שלכם (IndexedDB). הצ'אטים אף פעם לא נשלחים לשרת של AppAgent — רק לספק ה-AI שלכם ולמופע ה-ServiceNow שלכם. ראו [אחסון נתונים](#adv-data-storage).

### הממשק או הדף הזה מוצגים בשפה הלא נכונה

בחרו את השפה ב[הגדרות](app:openSettingsPageView) ← **שפה**. **אוטומטי** עוקב אחר שפת הדפדפן שלכם.

## שינוי גודל והזזה של וידג'טים {#adv-resize-move}

**שינוי גודל של וידג'טים:**

- לכל וידג'ט יש **ידית שינוי גודל** בפינה הימנית התחתונה
- לחצו על הידית וגררו אותה כדי לשנות את גודל הווידג'ט
- הרוחב נצמד לרשת של 12 עמודות (מינימום 3 עמודות)
- הגובה נמדד ביחידות של 50px (מינימום 2 יחידות = 100px)

**הזזת וידג'טים:**

- הפעילו את המתג **כותרות** כדי להציג את כותרות הווידג'טים
- לחצו על **סמל הווידג'ט** (ידית הגרירה) וגררו אותו כדי לשנות את הסדר
- שחררו את הווידג'ט על וידג'ט אחר כדי להחליף ביניהם מקומות
- סדר הווידג'טים נשמר אוטומטית

ייצוא צ'אט שומר את היסטוריית השיחה המלאה, כולל כל הודעות המשתמש ותשובות הסוכן. כדי לייצא צ'אט בודד, פתחו את התפריט הנפתח של הצ'אט (···) ובחרו **הורדה**.

```
├── SKILL.md      # Main skill definition

├── helper.js     # Optional JS assets
└── notes.md      # Optional MD assets
```

:::tip
**הערה:** ייבוא וייצוא של מיומנויות משתמשים ב-File System Access API ו**פועלים רק בדפדפני Chrome או Edge**.

**ייצוא כל הנתונים** (`appagent-backup-YYYY-MM-DD.json`):

```
{
  "version": 3,
  "exportDate": "2024-01-15T10:30:00.000Z",
  "chats": [...],
  "settings": [...],
  "dashboardWidgets": [...],
  "apiProviders": [...]
}
```

הגיבוי המלא כולל את כל היסטוריית הצ'אטים, ההגדרות, הרשאות הכלים, הווידג'טים של לוח הבקרה והגדרות ספקי ה-API.

## סטטיסטיקות API {#adv-api-stats}

כשהאפשרות מופעלת בהגדרות, סטטיסטיקות API מוצגות אחרי כל תשובה של הסוכן:

| מדד | תיאור |
|--------|-------------|
| **קלט** | טוקני קלט — גודל ההנחיה שנשלחה לסוכן |
| **פלט** | טוקני פלט — גודל התשובה של הסוכן |
| **סה"כ** | סך טוקני הקלט והפלט יחד |
| **קריאה/כתיבה במטמון** | טוקנים שנקראו ממטמון ההנחיות או נכתבו אליו (מפחית עלויות) |
| **חשיבה** | טוקנים ששימשו לחשיבה פנימית (בחלק מהמודלים) |
| **עלות** | העלות המשוערת של קריאת ה-API בדולרים (USD) |
| **משך** | הזמן שנמשכה קריאת ה-API |

בשיחות מרובות סבבים, סטטיסטיקות מצטברות מציגות את הסך הכולל של כל הקריאות.

:::tip
הפעילו או כבו את תצוגת סטטיסטיקות ה-API ב[הגדרות](app:openSettingsPageView) ← תצוגה ← הצגת סטטיסטיקות API.

## עריכה ידנית של מיומנויות {#adv-skills-manual}

אפשר ליצור ולערוך מיומנויות באופן ידני או בעזרת הסוכן:

**יצירת מיומנות באופן ידני:**

1. עברו אל [מיומנויות](app:openSkillsView) ולחצו על **מיומנות חדשה**
2. הזינו שם ותיאור למיומנות
3. כתבו את תוכן המיומנות בפורמט Markdown
4. לחצו על **שמירה** כדי ליצור את המיומנות

**פורמט SKILL.md:**

```
# Skill Name

Description of what this skill does.

## Instructions

Detailed instructions for the Agent...

## Examples

- Example usage 1
- Example usage 2
```

**עריכה עם הסוכן:**

1. לחצו על **עריכה עם הסוכן** בכל מיומנות
2. תארו אילו שינויים אתם רוצים
3. הסוכן ישנה את תוכן המיומנות
4. עיינו בשינויים ושמרו אותם

**נכסי מיומנות:** מיומנויות יכולות לכלול קבצים נוספים (XML, JS, MD) שמספקים לסוכן הקשר או קוד נוסף.

## הנחיית מערכת {#adv-system-prompt}

הנחיית המערכת מגדירה את ההתנהגות והיכולות של הסוכן. אפשר להתאים אותה אישית ב[הגדרות](app:openSettingsPageView).

**עריכת הנחיית המערכת:**

1. עברו אל הגדרות ← המקטע הנחיית מערכת
2. לחצו על **עריכה** כדי לעבור למצב עריכה
3. שנו את התבנית לפי הצורך
4. לחצו על **שמירה** כדי להחיל את השינויים

**ממלאי מקום זמינים:**

| מציין מיקום | תיאור |
|-------------|-------------|
| `{{CURRENT_DATE}}` | התאריך של היום (יום בשבוע, חודש, יום, שנה) |
| `{{ORCHESTRATOR_POLICY}}` | מדיניות ההאצלה לסוכני משנה — נכללת בצ'אטים ראשיים, ונשארת ריקה בצ'אטים של סוכני משנה |
| `{{DISABLED_TOOLS}}` | רשימת הכלים המושבתים |
| `{{TOOL_CATALOG}}` | קטלוג הכלים הנטענים לפי דרישה (ריק כשטעינת כלים לפי דרישה כבויה) |
| `{{SKILLS_SUMMARY}}` | התוכן של המיומנויות הפעילות |

מצייני המיקום מוחלפים אוטומטית בערכים בפועל בעת השליחה ל-AI. תצוגת ספירת הטוקנים מראה גם את גודל התבנית וגם את הגודל לאחר ההרחבה.

:::tip
לחצו על **חזרה לברירת המחדל** כדי לשחזר את הנחיית המערכת המקורית במקרה הצורך.
:::

## קריאות API של הסוכן {#adv-agent-api}

AppAgent פועל כ**תוסף ל-Chrome**:

- קריאות ה-API ל-AI נשלחות **ישירות מהדפדפן שלכם אל ספק ה-AI** (למשל Anthropic, OpenRouter)
- הן **לא** עוברות דרך המופע שלכם או דרך שרת כלשהו של AppAgent
- מפתח ה-API שלכם (או אסימון ה-OAuth) נשמר באופן מקומי בדפדפן שלכם
- נתוני השיחה נשלחים לספק ה-AI לעיבוד

**איך זה עובד:**

1. אתם מקלידים הודעה בצ'אט
2. AppAgent בונה הנחיה עם הנחיות מערכת, כלים והיסטוריית השיחה
3. ההנחיה נשלחת ל-API של ספק ה-AI
4. התשובה של הסוכן מוזרמת בחזרה לדפדפן שלכם
5. הקריאות לכלים מבוצעות בדפדפן שלכם, תוך שימוש בהפעלה שלכם במופע עבור קריאות API

:::tip
**פרטיות:** מפתח ה-API ונתוני השיחה שלכם מטופלים בצד הלקוח. קריאות לכלים שפונות למופע שלכם משתמשות בפרטי ההתחברות של ההפעלה הקיימת שלכם.
:::

## נקודות קצה של LLM {#adv-endpoints}

מודלים מתחברים דרך **נקודות קצה של LLM בעלות שם** — צמדי `URL + API key` לשימוש חוזר. כך אפשר לכוון את AppAgent ל**כל API של chat completions התואם ל-OpenAI**: OpenRouter, שער מקומי, שרת proxy או מודל שאתם מארחים בעצמכם.

1. ב[הגדרות ← נקודות קצה של LLM](app:openSettingsPageView), לחצו על **הוספת נקודת קצה**
2. תנו לה שם, כתובת URL של ה-API ומפתח API
3. כל מודל (ספק API) בוחר נקודת קצה — עדכנו מפתח פעם אחת, וכל המודלים שמשתמשים בו יתעדכנו

:::tip
ספקי **OAuth** של Claude לא משתמשים בנקודות קצה — הם פונים ישירות אל `api.anthropic.com`.
:::

## התחברות עם Claude (OAuth) {#adv-oauth}

במקום להדביק מפתח API, אפשר להתחבר לספקי Anthropic באמצעות ההפעלה הקיימת שלכם ב-claude.ai:

1. ב[הגדרות ← ספקי API](app:openSettingsPageView), הוסיפו או ערכו ספק Anthropic והפעילו **OAuth**
2. התוסף משתמש בהתחברות שלכם ל-claude.ai מאותו פרופיל Chrome כדי להתחבר ישירות ל-Anthropic
3. אין חלון התחברות נוסף, ואין שרת של AppAgent באמצע

**דרישות:**

- עליכם להיות מחוברים ל-`claude.ai` באותו פרופיל Chrome
- עובד עם חשבונות התחברות יחידה (SSO)

:::tip
אסימוני OAuth מתרעננים אוטומטית. אם ההתחברות נכשלת, פתחו את `claude.ai` באותו פרופיל והתחברו שוב.
:::

## שיקולי אבטחה {#adv-security}

**אחסון מפתח ה-API:**

- **מפתח ה-API שלכם נשמר באופן מקומי** ב-IndexedDB של הדפדפן שלכם
- המפתח אף פעם לא נשלח למופע שלכם או לשרת כלשהו מלבד ספק ה-AI
- ניקוי נתוני הדפדפן יסיר את מפתח ה-API השמור שלכם

**הפעלה והרשאות:**

- הסוכן פועל עם **הפעלת המשתמש הנוכחית שלכם**, ויורש את הרשאות הגישה והתפקידים שלכם
- כל קריאות ה-API למופע שלכם משתמשות בפרטי ההתחברות של ההפעלה שלכם
- הסוכן יכול לגשת רק למה שחשבון המשתמש שלכם יכול לגשת אליו

**סביבת ההרצה של הכלים:**

- **קוד דפדפן (js_eval)** מריץ JavaScript ב**ארגז חול מבודד** עם גישה ל-`executeTool()` בלבד
- **סקריפטים של וידג'טים** רצים ב-**iframes מבודדים** עם גישה ל-`executeTool()` בלבד עבור קריאות API
- **כלי מיומנויות** רצים ב**ארגזי חול מבודדים** עם גישה ל-`executeTool()` בלבד
- כל הגישה ל-API עוברת דרך **מערכת ההרשאות** באמצעות `executeTool("servicenow_api", {...})`
- הסוכן מקיים אינטראקציה עם דפים ב**לשוניות הדפדפן** במופע ה-ServiceNow שלכם

**יכולות שינוי רשומות:**

- הכלי **ServiceNow API** תומך בשיטות POST, PATCH, PUT ו-DELETE, שיכולות לשנות רשומות
- הסוכן יכול ליצור ולערוך רשומות דרך **הדפדפן המשולב** אם ניתנו לו הרשאות לכלי המילוי והלחיצה
- הגדירו [הרשאות כלים](app:openSettingsPageView) כדי לקבוע אילו פעולות דורשות אישור

**שיפור עצמי:**

- הסוכן יכול **לנהל את המיומנויות של עצמו** — ליצור, לערוך ולהפעיל מיומנויות
- כך הסוכן יכול ללמוד ולהשתפר עם הזמן
- עיינו מדי פעם בשינויים במיומנויות כדי לוודא שהם תואמים את הציפיות שלכם

## אחסון נתונים {#adv-data-storage}

AppAgent שומר נתונים באופן מקומי בדפדפן שלכם באמצעות **IndexedDB**:

| סוג נתונים | אחסון | תיאור |
|-----------|---------|-------------|
| **צ'אטים** | IndexedDB | כל היסטוריית השיחות, ההודעות ותוצאות הכלים |
| **הגדרות** | IndexedDB | הרשאות כלים, מפתחות API, העדפות מודלים |
| **וידג'טים של לוח הבקרה** | IndexedDB | קוד ה-HTML, הכותרות, הגדלים והיסטוריית השיחה של הווידג'טים |
| **מיומנויות** | IndexedDB | הגדרות המיומנויות, התוכן והנכסים שלהן |
| **ספקי API** | IndexedDB | הגדרות ונקודות קצה של ספקי API מותאמים אישית |
| **מצב הממשק** | localStorage | מצב סרגל הצד, התצוגה הנוכחית, מיקומי הגלילה |

**הורדת הנתונים שלכם:**

1. עברו אל [הגדרות](app:openSettingsPageView) ← ניהול נתונים
2. לחצו על **ייצוא נתונים**
3. קובץ גיבוי בפורמט JSON יורד למחשב

**מחיקת הנתונים שלכם:**

1. עברו אל [הגדרות](app:openSettingsPageView) ← ניהול נתונים
2. לחצו על **מחיקת כל הנתונים**
3. אשרו פעמיים כדי למחוק הכול לצמיתות

:::tip
**חשוב:** הנתונים נשמרים באופן מקומי בתוסף. ניקוי נתוני הדפדפן, הסרת התוסף או שימוש בפרופיל דפדפן אחר יובילו למאגרי נתונים נפרדים.
:::
