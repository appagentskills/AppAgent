# AppAgent

**בנו ותחזקו אפליקציות ServiceNow בעזרת סוכן. כתוסף ל-Chrome.**

AppAgent הוא שותף הפיתוח שלכם ל-ServiceNow. הוא יכול ליצור ולתחזק אפליקציות, ולהריץ עבורן בדיקות. הוא בודק על ידי מילוי טפסים וצילום מסכים. לא נדרש ידע טכני.

אתם מביאים מפתח API משלכם (BYOK), וזהו! הוא תואם ל-OpenAI, ל-OpenRouter, ל-Claude API ואפילו למנויי Claude Code (צרו איתנו קשר באופן פרטי).

זהו תוסף ל-Chrome ששומר את כל הצ'אט בדפדפן שלכם (הוא אפילו לא יוצא מהדפדפן). הוא מתקשר רק עם מופע ה-ServiceNow שלכם ועם ספק ה-API של המודל שלכם.

![דוגמה ל-AppAgent](AppAgentExample.png)

הוא צורך פחות טוקנים מ-Claude Code, כי הוא נשען במידה רבה על מטמון ה-API, על שמירת כלים במטמון ועל שרשור כלים (מובנה מראש).

אפשר להוסיף לו מיומנויות, יש לו שליטה בדפדפן באמצעות לשוניות, ויש לו כפתורי ביטול מכניים לכל השינויים שהוא מבצע במופע שלכם.

> **הערה:** בשלב זה, AppAgent מיועד לשימוש במופעי פיתוח בלבד.

## התקנה והגדרה

1. **התקנה** — התקינו את התוסף AppAgent מחנות האינטרנט של Chrome (או טענו אותו כתוסף לא ארוז לצורכי פיתוח)
2. **השגת מפתח API** — הירשמו ב-[OpenRouter](https://openrouter.ai), השתמשו ישירות ב-Anthropic/OpenAI, או חברו את מנוי ה-Claude Code שלכם (Enterprise או Personal)
3. **הגדרה** — פתחו את התוסף והוסיפו את מפתח ה-API שלכם (או התחברו עם Claude) בהגדרות ← ספקי API
4. **התחילו לבנות** — פתחו את מופע ה-ServiceNow שלכם בלשונית (הוא מזוהה אוטומטית) והתחילו לשוחח

## דוגמאות

### "בנה לי אפליקציה פשוטה למעקב אחר משימות הצוות"
AppAgent ייצור את הטבלה, יוסיף את השדות, יבנה פריסות של טופס ורשימה ויגדיר מודול בנווט. הנחיה אחת, אפליקציה שלמה.

### "בצע ביקורת מלאה על המופע הזה"
AppAgent יסרוק פרצות אבטחה, חשבונות מנהל לא פעילים, רשומות ישנות ושיטות עבודה מומלצות בתצורה, ואז יגיש לכם דוח עם המלצות.

### "בדוק את הדף הזה ודווח על כל בעיה שתמצא"
AppAgent יפתח את הדף בלשונית דפדפן, ימלא טפסים, ילחץ על כפתורים, יצלם מסכים ויחבר דוח על כל מה שהוא מוצא.

### "יש באג בטופס הזה, אתה יכול לתקן אותו?"
AppAgent יפתח את הטופס, יבדוק את הסקריפטים שמאחוריו, יזהה את הבאג, יתקן את הקוד ויראה לכם בדיוק מה השתנה. לחיצה אחת לביטול, אם צריך.

### "צור וידג'ט ללוח הבקרה עבור הקריאות הפתוחות שלי"
AppAgent ייצור וידג'ט חי שמושך נתונים בזמן אמת מהמופע שלכם ומציג אותם בלוח הבקרה שלכם.

### "ייבא את קובץ ה-Excel הזה לטבלת המשתמשים"
AppAgent יקרא את הקובץ, ימפה עמודות לשדות וייבא את הנתונים למופע שלכם.

### "בדוק את היסטוריית השדרוגים ותקן בעיות בהתאמות אישיות"
AppAgent יבדוק מה השתנה בשדרוג, ימצא התאמות אישיות שנשברו ויתקן אותן.

### "הודע לצוות כשנפתחת תקלת P1"
AppAgent ייצור כלל התראה שמופעל בתקלות P1 ושולח התראה לצוות שלכם.
